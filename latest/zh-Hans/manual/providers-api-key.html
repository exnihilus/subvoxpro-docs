粘贴密钥后

在 SubVox Pro 窗口中，一旦检测到有效密钥，每个提供商面板都会显示一个 API Ready 状态徽标。如果请求失败，再次核对以下几点：密钥是否已完整复制、账户是否还有余额/配额，以及设备是否可以访问网络。要清除该设备上存储的所有密钥，点击 Tools ▸ SubVox Pro ▸ Settings 中的 Clear API Keys 按钮。
