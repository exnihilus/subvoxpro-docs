SubVox Pro 的 API 入口：播放台词资源，设置语言和字幕显示方式，并触发全局事件（字幕、台词资源、台词资源事件）。所有播放源均遵循这些设置：包括 VoiceLineEmitter 组件和 Timeline 集成。

AudioLanguage

要播放的配音语言代码（例如“ja”），源音频留空，玩家可以听一种语言、读另一种语言的字幕。设置之前跟随 CurrentLanguage；设为 null 则重新跟随。配音从下一句台词开始；没有该语言配音的台词播放其源音频。

public static string AudioLanguage { get; set; }

属性值

string

Examples

SubVox.AudioLanguage = "";
SubVox.CurrentLanguage = "fr";

SubVox.AudioLanguage = null;

CurrentLanguage

PublishSubtitle(SubtitleInfo)

在每个字幕显示组件上显示一条字幕，如同由台词资源发布一样，例如显示视频过场动画的文本。字幕会保留到下一条字幕发布；发布一个空的 SubtitleInfo 可清除字幕。处于活动状态的 Timeline 台词资源保持显示优先级，因此在其剪辑处于活动状态时，自定义发布会被忽略。

public static void PublishSubtitle(SubtitleInfo subtitle)

参数

subtitle SubtitleInfo

Examples

SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, "Somewhere in the north, ten years ago."));
SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, string.Empty));

Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)

每当带有此信号的台词资源事件触发时，都会调用该处理程序。使用 <xref href="SubVoxPro.SubVox.Unsubscribe(SubVoxPro.VoiceLineEventSignalData%2cSystem.Action%7bSubVoxPro.VoiceLineEventContext%7d)" data-throw-if-not-resolved="false"></xref> 取消订阅，通常在 OnDisable 中执行。该信号资源本身绝不会被修改。

public static void Subscribe(VoiceLineEventSignalData signal, Action<VoiceLineEventContext> handler)

参数

signal VoiceLineEventSignalData
handler Action<VoiceLineEventContext>

Examples

[SerializeField] private VoiceLineEventSignalData _cameraShake = null;

private void OnEnable() => SubVox.Subscribe(_cameraShake, Shake);
private void OnDisable() => SubVox.Unsubscribe(_cameraShake, Shake);

private void Shake(VoiceLineEventContext context)
{
    _camera.Shake(0.3f);
}
