GetDisplayName(string)

在指定语言中显示的名称：若已设置 Unity Localization 条目且安装了该包，则使用该条目；否则使用匹配的 LocalizedNames 条目（先查找完全匹配，再查找基础语言相同的条目）；最后回退到 DisplayName。

public string GetDisplayName(string language_code)

参数

language_code string

返回值

string

Examples

string name = speaker.GetDisplayName(SubVox.CurrentLanguage);
