类 VoiceLineEventAttribute

命名空间
SubVoxPro
程序集
SubVoxPro.dll

台词资源中信号键与此键匹配的事件触发时，调用标记的方法。该方法所属的组件需由 VoiceLineEventDispatcher 缓存，或与 VoiceLineEventListener 位于同一 GameObject 上。方法返回 void，不接受参数，或接受一个 VoiceLineEventContext 参数，或接受一个与事件附带数据类型相同的参数。键匹配时忽略大小写、空格和标点：“Camera Shake”可匹配“camera-shake”。

[AttributeUsage(AttributeTargets.Method, AllowMultiple = true)]
public sealed class VoiceLineEventAttribute : PreserveAttribute

[VoiceLineEvent(SubVoxEvents.CAMERA_SHAKE)]
private void ShakeCamera()
{
    _camera.Shake();
}

[VoiceLineEvent("Play Sound")]
private void PlaySound(AudioClip sound)
{
    AudioSource.PlayClipAtPoint(sound, transform.position);
}
