类 VoiceLinePlayback

命名空间
SubVoxPro
程序集
SubVoxPro.dll

一次台词资源播放请求，由 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 和 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 返回：通过 State 跟踪其状态、停止播放，或使用 yield return 在协程中等待其完成。

public sealed class VoiceLinePlayback : CustomYieldInstruction
继承
object
VoiceLinePlayback

Examples

private IEnumerator Dialogue()
{
    yield return SubVox.Play(question);
    yield return new WaitForSeconds(0.5f);

    VoiceLinePlayback answer = SubVox.Play(reply);
    answer.Finished += done => Debug.Log($"Answer ended: {done.State}");
    yield return answer;
}
