当碰撞体进入此触发区域时，播放一条台词资源（或台词库中的下一条台词资源）。支持 2D 或 3D 碰撞体：只会触发与此对象上的碰撞体类型匹配的回调，因此一个组件即可支持这两种类型。可按图层和可选的标签进行筛选，设置仅播放一次或按冷却时间限制播放，选择台词播放源忙碌时的处理方式，还可在玩家离开时停止播放台词或让触发区域重新待命。Play() 是公共方法，其他系统（如交互系统、UI 按钮）均可通过 UnityEvent 复用它。

Play()

在其台词播放源上播放已分配的台词资源（或台词库中的下一条台词资源）；未设置台词播放源时，使用管理器的台词播放源。播放时遵循仅播放一次、冷却时间、播放模式和优先级设置。
