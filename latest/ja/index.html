SubVox Pro API

SubVox.RevealMode = EVoiceLineSubtitleRevealMode.Karaoke; SubVox.Play(gateSealed);

音声はSubVox ProのオフラインChatterboxエンジンで生成されています。単語のタイミング情報は、SubVox ProのオフラインWhisperによる文字起こしから取得しています。

はじめに

SubVox
コードから操作するためのエントリーポイントです。ボイスラインの再生、再生中のすべてのボイスラインの一時停止や停止、言語と字幕オプションの設定、再生状況の監視ができます。
VoiceLineEmitter
優先度とキューを使用してボイスラインを1つずつ再生し、3D空間でキャラクターに話させます。
VoiceLinePlayback
再生を呼び出すたびに返されるオブジェクトです。ボイスラインの再生状況を確認したり、再生を停止したり、コルーチンで再生終了を待ったりできます。
VoiceLineData
字幕、翻訳、吹き替え音声、話者、イベントを含むボイスラインアセットです。

タスクから探す

ボイスラインを再生し、終了まで待つ
SubVox.Play
会話を中断せずにキャラクターに話させる
EVoiceLinePlayMode.Queue
単語が発話されたときにコードを実行する
SubVox.Subscribe
字幕と吹き替え音声の言語を切り替える
SubVox.CurrentLanguage
プレイヤーに字幕オプションを提供する
SubVox.SubtitleScale
FMOD、Wwise、または動画に字幕を同期する
IVoiceLineAudioClock
キャラクターの上に吹き出しを表示する
SubtitleBubbleDisplayer
会話ログを作成する
SubVox.History
