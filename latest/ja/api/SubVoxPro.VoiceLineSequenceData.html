ボイスラインを順番に再生するための、再利用可能な順序付きリストです。このアセットには定義（どのボイスラインを再生するか、および各ボイスラインがどのように次のボイスラインへと移行するか）のみが含まれています。シーン内のVoiceLineSequencePlayerが実行時にこれを制御するため、複数のプレイヤー間で同じシーケンスを安全に再利用することができます。
