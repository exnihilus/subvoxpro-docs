名前空間
SubVoxPro

シグナルが発生すると、読み込まれているシーン内で、そのシグナルに対応するVoiceLineEventAttributeが付いたメソッドを呼び出します。起動シーンに1つ追加します（[SubVox Pro]プレハブに含まれています）。

public sealed class VoiceLineEventDispatcher : MonoBehaviour
継承
object
VoiceLineEventDispatcher

コンストラクター

VoiceLineEventDispatcher() 

public VoiceLineEventDispatcher()

プロパティ

ScanScenesAutomatically

true（デフォルト）の場合、ディスパッチャーは有効になった時点で読み込まれているシーンをスキャンし、その後は各シーンが読み込まれるたびにスキャンします。falseの場合、Register(MonoBehaviour)に渡された、またはRefresh()で検出されたコンポーネントのメソッドのみを呼び出します。

public bool ScanScenesAutomatically { get; set; }

プロパティ値

bool

メソッド

Refresh()

実行時にオブジェクトが作成または破棄された後、キャッシュされたコードリスナーを再構築します。

public void Refresh()

Register(MonoBehaviour)

シーン全体を再スキャンせずに、実行時に作成されたコンポーネントのVoiceLineEventAttributeが付いたメソッドを登録します。コンポーネントを破棄する際は、Unregister(MonoBehaviour)を呼び出してください。

public static void Register(MonoBehaviour behaviour)

パラメーター

behaviour MonoBehaviour

Unregister(MonoBehaviour)

Register(MonoBehaviour)で追加された、またはRefresh()で検出されたコンポーネントのメソッドの登録を解除します。
