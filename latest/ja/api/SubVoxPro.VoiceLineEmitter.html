クラス VoiceLineEmitter

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

自身のAudioSourceで、ボイスラインを1つずつ、イベントおよび音声と同期した字幕とともに再生します。発話するキャラクターごとに配置し、AudioSourceを3Dに設定すると、そのキャラクターの位置から声が聞こえます。複数のエミッターで同時に再生でき、VoiceLineManagerが再生中の最も優先度の高いボイスラインの字幕を表示します。

Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)

ボイスラインを再生します（CurrentLanguageの吹き替え版が存在する場合はそれを再生します）。ここで既にボイスラインが再生中の場合、モードによって動作が決まります：Replaceは、優先度が同等以上の場合にそれを置き換えます（優先度が低い場合は拒否されます）、Queueは、待機中のボイスラインの後に再生します、IfIdleはそれを拒否します。

PlayExternal(VoiceLineData, IVoiceLineAudioClock, EVoiceLinePriority, EVoiceLinePlayMode)

オーディオを開発者側で再生するボイスラインを再生します（FMOD、Wwise、動画など）。字幕とイベントは、このエミッターのAudioSourceではなくaudio_clockに追従し、クロックが再生中でなくなるとボイスラインの再生が完了します。ボイスラインの再生が開始されたら、CurrentAudioLanguageのオーディオを再生してください。Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)と同じルールが適用されます。Pause()、Seek(float)、Stop()は字幕とイベントにのみ作用するため、オーディオも併せて制御してください。

public VoiceLinePlayback PlayExternal(VoiceLineData voice_line, IVoiceLineAudioClock audio_clock, EVoiceLinePriority priority = EVoiceLinePriority.Normal, EVoiceLinePlayMode mode = EVoiceLinePlayMode.Replace)

Seek(float)

現在のボイスラインを指定時刻（秒単位）に移動します。移動前と移動後の時刻の間にあるイベントは発生しません。PlayExternal(VoiceLineData, IVoiceLineAudioClock, EVoiceLinePriority, EVoiceLinePlayMode)で再生中のボイスラインには作用しません。その場合はオーディオをシークしてください。ボイスラインはオーディオに追従します。

public void Seek(float time)

パラメーター

time float

Skip()

現在のボイスラインを、あたかも最後まで再生されたかのように終了させます。残りのイベントが発火し、VoiceLineCompletedが発生し、キューに登録されている次のボイスラインが開始されます。「セリフをスキップ」ボタン用です。

public void Skip()

Stop()

現在のボイスラインを停止し、キューを空にします。残りのイベント（Voice Endを含む）は発生せず、VoiceLineCompletedの代わりにVoiceLineInterruptedが発生します。

public void Stop()
