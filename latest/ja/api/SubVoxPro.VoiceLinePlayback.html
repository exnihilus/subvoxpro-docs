クラス VoiceLinePlayback

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)およびPlay(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)が返す、ボイスラインの1回の再生リクエストです。Stateで状態を確認したり、再生を停止したり、コルーチン内でyield returnを使って終了を待機したりできます。

public sealed class VoiceLinePlayback : CustomYieldInstruction
継承
object
VoiceLinePlayback

Examples

private IEnumerator Dialogue()
{
    yield return SubVox.Play(question);
    yield return new WaitForSeconds(0.5f);

    VoiceLinePlayback answer = SubVox.Play(reply);
    answer.Finished += done => Debug.Log($"Answer ended: {done.State}");
    yield return answer;
}

プロパティ

Duration

ボイスラインの長さ（秒単位）です。再生開始時に確定します。キューで待機中、または再生が拒否された場合は0です。

public float Duration { get; }
