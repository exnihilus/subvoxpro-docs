ソースオーディオと字幕、翻訳、生成された吹き替え音声、話者、イベントを含むボイスラインです。SubVox Proウィンドウで作成・編集します。コードからは読み取り専用です。

DefaultSpeaker

グローバルな話者です。設定すると、このボイスラインのすべての字幕に適用され、字幕ごとの話者設定より優先されます。字幕ごとのオーバーライド設定は変更されずに保持されるため、この値をnullに戻すと再び適用されます。

NoAudioDuration

オーディオがない場合のボイスラインの長さ（秒単位）です。この長さを超える字幕がある場合は、ボイスラインの長さも延長されます。そのため、字幕のみのボイスラインは、設定ウィンドウに表示されるタイムラインと同じ長さだけ再生されます。

public float NoAudioDuration { get; }

ソースオーディオと字幕の言語（例：「fr」）です。不明の場合は空文字列です。この言語を指定すると、常にソースが再生され、同じ言語のトラックは使用されません。

GetLoudness(float, string)

指定した言語でラインを再生したときの、ある時刻（秒）における声の大きさ：無音（-60 dB 以下）の 0 からフルスケール（0 dB）の 1 まで。オーディオ保存時に 10 ms ごとに計測されます。オーディオがなければ 0、AudioSource の音量には左右されません。声に合わせてハロー、ライト、口を動かすのに便利です。

public float GetLoudness(float time, string language_code)

パラメーター

time float
language_code string

戻り値

float

Examples

float level = voiceLine.GetLoudness(_video.time, SubVox.CurrentLanguage);
_halo.intensity = Mathf.Lerp(0.2f, 2f, level);

GetSubtitleAt(float, string)

ボイスラインを指定した言語で再生したときに、指定時刻（秒単位）で表示される字幕です。VoiceLineEmitterが表示する字幕と同じで、吹き替えのタイミングとAuto blanksを反映し、全文とスタイルを含みます。最初の字幕より前、発話の合間、または字幕のテキストを消去するブランクマーカー（blank）の後は空の字幕になります。

public SubtitleInfo GetSubtitleAt(float time, string language_code)

パラメーター

time float
language_code string

戻り値

SubtitleInfo

Examples

SubtitleInfo line = voiceLine.GetSubtitleAt(_video.time, SubVox.CurrentLanguage);
_caption.text = line.SubtitleText;

このボイスラインで字幕を表示できる言語です。ソース言語（不明の場合は空の言語コード）が先頭で、その後に各翻訳言語が続きます。
