クラス VoiceLineZone

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

コライダーがこのトリガー領域に入ると、ボイスライン（またはバンク内の次のボイスライン）を再生します。2Dまたは3Dのコライダーに対応します。このオブジェクト上のコライダーの種類に対応するコールバックのみが呼び出されるため、1つのコンポーネントで両方に対応できます。レイヤーと任意のタグによるフィルター、1回限りの再生またはクールダウン時間を設けた再生、エミッターが再生中の場合の動作を設定できます。プレイヤーが領域を離れたときに、ボイスラインを停止したり、領域を再びトリガー可能にしたりする設定も可能です。Play()はpublicなので、他のシステム（インタラクションやUIボタンなど）からもUnityEventを通じて再利用できます。

public class VoiceLineZone : MonoBehaviour

Play()

割り当てられたボイスライン（またはバンク内の次のボイスライン）を、指定されたエミッターで再生します。エミッターが未設定の場合は、マネージャーのエミッターを使用します。1回限りの再生、クールダウン時間、再生モード、優先度の設定に従います。

public void Play()

ResetZone()

ゾーンで再び再生できるように、「Play Once」の再生済み状態とクールダウン時間をリセットします。例えば、チェックポイントのリロード後に使用します。

public void ResetZone()
