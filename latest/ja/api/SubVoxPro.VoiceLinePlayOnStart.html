名前空間

アセンブリ

このオブジェクトが開始（または再有効化）された際、オプションの遅延時間を経て、ボイスラインを自動的に再生します。レベル導入部のナレーションや冒頭のセリフなどに適しています。Play()は、手動での再利用が可能となるようpublicのままにされています。

Play()

割り当てられたボイスライン（またはバンク内の次のボイスライン）を、指定されたエミッターで即座に再生します。エミッターが設定されていない場合は、マネージャーのエミッターを使用します。
