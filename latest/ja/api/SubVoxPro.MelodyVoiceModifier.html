クラス MelodyVoiceModifier

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

エミッターが話す音節（または単語）ごとに「どうぶつの森」風の短いブリップ音を鳴らします。すべての言語に対応し、何も生成する必要はありません。各ブリップは再生中の音声（ソースまたは吹き替え）での声のイントネーションに沿い、音声がない、または声がはっきりしないラインでは軽いランダムな音程になります。VoiceLineEmitter の隣に追加し、キャラクターごとに音域を選んでください。

public class MelodyVoiceModifier : MonoBehaviour
継承
object
MelodyVoiceModifier

Examples

MelodyVoiceModifier voice = _villager.GetComponent<MelodyVoiceModifier>();
voice.Mode = EVoiceLineMelodyMode.Replace;
voice.BasePitch = 5f;
_villager.GetComponent<VoiceLineEmitter>().Play(greeting);
