Class SubtitleDisplayer

Namespace

Shows the subtitles published on SubVox in a TextMeshPro text (UI or 3D), with the speaker's name and font, and follows the display settings of SubVox (on/off, size, background opacity, fade). Works the same whether playback comes from the emitters or from Timeline.

public sealed class UppercaseSubtitleDisplayer : SubtitleDisplayer
{
    protected override string ComposeText(SubtitleInfo subtitle_info)
    {
        return base.ComposeText(subtitle_info).ToUpperInvariant();
    }
