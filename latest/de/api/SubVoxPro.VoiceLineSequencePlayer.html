Spielt zur Laufzeit eine VoiceLineSequenceData ab, Zeile für Zeile. Jeder Schritt wird entweder automatisch fortgesetzt, sobald die jeweilige Zeile beendet ist (nach einer optionalen Verzögerung), oder manuell über Advance() – das mit jedem beliebigen UnityEvent, einer Interaktion oder einer UI-Schaltfläche verknüpft werden kann – und Previous() springt eine Zeile zurück. Die Schritte werden in der Reihenfolge Direction abgespielt. Ein Schritt, der von einem ausgelasteten Emitter abgelehnt wird, wartet, bis dieser wieder frei ist. Stellt UnityEvents bereit, damit die Szenenlogik ohne Programmcode reagieren kann, sowie dieselben C#-Ereignisse für den Programmcode.
