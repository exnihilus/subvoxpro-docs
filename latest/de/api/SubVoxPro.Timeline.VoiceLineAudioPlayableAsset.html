Ein Audio-Clip, der mit einem VoiceLineClip auf einer nativen Audiospur verknüpft ist. Er zeigt das Quell-Audio im Editor an und ermöglicht eine Vorschau; außerdem wird das Dubbing von AudioLanguage abgespielt, sofern eine vorhanden ist. Die Sprache wird beim Erstellen des Timeline-Diagramms (wenn der Regisseur die Wiedergabe startet) ausgelesen, sodass ein Dubbing niemals mitten in einer Zwischensequenz wechselt.
