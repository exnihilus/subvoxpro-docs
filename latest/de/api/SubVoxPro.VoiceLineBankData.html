Eine Reihe austauschbarer Voice Lines, wie beispielsweise das Bellen eines Wächters: Bei jedem Spielzug wird eine der folgenden Voice Lines ausgewählt: Order. Das Asset enthält lediglich die Voice Lines; welche als Nächstes an der Reihe ist, wird von SubVox Pro zur Laufzeit verfolgt.
