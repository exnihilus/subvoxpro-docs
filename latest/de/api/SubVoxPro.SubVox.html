Der Code-Einstiegspunkt von SubVox Pro: Er spielt Sprachzeilen ab, legt die Sprache und den Einblendmodus für Untertitel fest und löst die globalen Ereignisse aus (Untertitel, Sprachzeilen, Sprachzeilen-Ereignisse). Jede Wiedergabequelle berücksichtigt dies: die Komponenten VoiceLineEmitter sowie die Timeline-Integration.

AudioLanguage

Sprachcode der abzuspielenden Sprachfassung (z. B. „ja“) oder leer für das Quell-Audio, sodass Spieler eine Sprache hören und eine andere lesen können. Folgt CurrentLanguage, bis es gesetzt wird; mit null folgt es wieder. Eine Sprachfassung beginnt mit der nächsten Sprachzeile; eine Sprachzeile ohne Fassung in dieser Sprache spielt ihr Quell-Audio.

PublishSubtitle(SubtitleInfo)

Zeigt auf jedem Display einen Untertitel an, als wäre dieser von einer Sprachzeile veröffentlicht worden, beispielsweise den Text einer Video-Zwischensequenz. Er bleibt bis zum nächsten Untertitel sichtbar; veröffentlichen Sie einen leeren SubtitleInfo, um ihn zu löschen. Eine aktive Sprachzeile in der Timeline hat Priority, sodass benutzerdefinierte Veröffentlichungen ignoriert werden, solange ihr Clip aktiv ist.

public static void PublishSubtitle(SubtitleInfo subtitle)

Parameter

subtitle SubtitleInfo

Examples

SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, "Somewhere in the north, ten years ago."));
SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, string.Empty));

Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)

Ruft den Handler auf, sobald ein Voice Line-Event mit diesem Signal ausgelöst wird. Die Abmeldung erfolgt über Unsubscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>), in der Regel in „OnDisable“. Das Signal-Asset selbst wird dabei niemals verändert.

public static void Subscribe(VoiceLineEventSignalData signal, Action<VoiceLineEventContext> handler)

Parameter

signal VoiceLineEventSignalData
handler Action<VoiceLineEventContext>

Examples

[SerializeField] private VoiceLineEventSignalData _cameraShake = null;

private void OnEnable() => SubVox.Subscribe(_cameraShake, Shake);
private void OnDisable() => SubVox.Unsubscribe(_cameraShake, Shake);

private void Shake(VoiceLineEventContext context)
{
    _camera.Shake(0.3f);
}
