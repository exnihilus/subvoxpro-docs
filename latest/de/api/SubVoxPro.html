Namespace SubVoxPro

Classes

LanguageCodeAttribute

Kennzeichnet ein Zeichenfolgenfeld als Sprachcode. Der Inspector zeigt daraufhin ein Dropdown-Menü mit den Sprachen an, die tatsächlich in den VoiceLineData-Assets des Projekts vorhanden sind (zuzüglich der Ausgangssprache), anstatt eines Freitextfeldes, in das ein Code manuell eingegeben werden muss.

LocalizedAudioTrack

Eine Sprachvertonung einer Voice Line in einer Sprache mit eigenen Timings.

LocalizedSubtitleTrack

Die Übersetzung der Untertitel einer Voice Line in eine Sprache.

LocalizedVoiceLineEventBinding

Eine ereignisspezifische Position innerhalb einer einzelnen Synchronisation.

SpeakerData

Ein benannter, stilistisch definierter Speaker, dem Untertitel zugeordnet werden können. Jeder Speaker ist ein eigenständiges Asset und kann daher für verschiedene Voice Lines wiederverwendet werden; das Geschlecht dient lediglich dazu, Speaker in der Editor-Auswahl zu gruppieren.

SpeakerLocalizedName

The name, under which a Speaker appears in a language.

SpeakerSelectorAttribute

Markiert ein SpeakerData-Feld, sodass der Inspector anstelle des standardmäßigen Objektreferenzfeldes dasselbe Popup-Fenster zur Speaker-Auswahl anzeigt, das auch im Voice Line-Fenster verwendet wird (Speaker nach Geschlecht gruppiert, mit einem Eintrag „Keine“ und einer Verknüpfung „New speaker“).

SubVox

Der Code-Einstiegspunkt von SubVox Pro: Er spielt Sprachzeilen ab, legt die Sprache und den Einblendmodus für Untertitel fest und löst die globalen Ereignisse aus (Untertitel, Sprachzeilen, Sprachzeilen-Ereignisse). Jede Wiedergabequelle berücksichtigt dies: die Komponenten VoiceLineEmitter sowie die Timeline-Integration.

SubVoxEvents

Generated Voice Line Event Keys for this Project.

SubtitleBubbleDisplayer

Eine Sprechblase für eine Figur: Zeigt nur die Zeilen ihres VoiceLineEmitter an, beispielsweise über dem Kopf eines NPCs, während die Anzeige am unteren Bildschirmrand den Dialog beibehält. Gleiche Settings wie bei SubtitleDisplayer. Deaktivieren Sie die Option „Show Subtitles“ des Emitters, um dessen Zeilen ausschließlich in der Sprechblase anzuzeigen.

SubtitleDisplayer

Zeigt die auf SubVox veröffentlichten Untertitel in einem TextMeshPro-Text (UI oder 3D) an, einschließlich des Namens des Speakers und der Schriftart, und orientiert sich dabei an den Einstellungen für die Anzeige von SubVox (Ein/Aus, Größe, Hintergrundtransparenz, Ein- oder Ausblenden). Die Funktionsweise ist identisch, unabhängig davon, ob die Wiedergabe über Emitter oder über die Timeline erfolgt.

SubtitleDocumentDisplayer

Zeigt die auf SubVox veröffentlichten Untertitel in einer UI-Toolkit-UnityEngine.UIElements.Label-Ansicht ihrer UnityEngine.UIElements.UIDocument an, einschließlich des Namens des Speakers und der UI-Toolkit-Schriftart. Das UI-Toolkit-Äquivalent zu SubtitleDisplayer: gleiche Modi für den Namen des Speakers, gleiche Rich-Text-Formatierung, gleiche Anzeigeeinstellungen.

VoiceLineBankData

Eine Reihe austauschbarer Voice Lines, wie beispielsweise das Bellen eines Wächters: Bei jedem Spielzug wird eine der folgenden Voice Lines ausgewählt: Order. Das Asset enthält lediglich die Voice Lines; welche als Nächstes an der Reihe ist, wird von SubVox Pro zur Laufzeit verfolgt.

VoiceLineData

Eine Sprachzeile: ihr Quellton sowie Untertitel, Übersetzungen, Synchronisationen, Speaker und Events. Erstellt und bearbeitet im SubVox Pro-Fenster; im Code schreibgeschützt.

VoiceLineDataEvent

A UnityEvent that contains a Voice Line and is provided so that it is displayed in the Inspector.

VoiceLineEmitter

Spielt Sprachzeilen nacheinander über eine eigene AudioSource ab, zusammen mit den zugehörigen Ereignissen und synchronisierten Untertiteln. Weisen Sie jedem sprechenden Charakter eine solche zu und stellen Sie deren „AudioSource“ auf „3D“ ein, um die Stimme von dort zu hören: Mehrere Emitter spielen gleichzeitig ab, und die VoiceLineManager zeigt den Untertitel der gerade abgespielten wichtigsten Zeile an.

VoiceLineEventAttribute

Ruft die markierte Methode auf, sobald ein Voice Line-Ereignis ausgelöst wird, dessen Signal diesen Schlüssel enthält. Die Methode gehört zu einer Komponente, die von einem VoiceLineEventDispatcher zwischengespeichert wird oder deren GameObject mit einem VoiceLineEventListener geteilt wird; sie gibt „void“ zurück und erwartet keine Parameter, einen VoiceLineEventContext oder den Typ der Ereignisdaten. Bei Schlüsseln werden Groß- und Kleinschreibung, Leerzeichen und Satzzeichen ignoriert: „Camera Shake“ entspricht „camera-shake“.

VoiceLineEventBinding

Die Position eines Ereignisses innerhalb einer Voice Line: ein Anker plus ein Versatz.

VoiceLineEventContext

Alles über ein Ereignis, das ausgelöst wird: die Voice Line, das Signal, die Ereignisdaten, wann und wo.

VoiceLineEventCue

Ein Ereignis, das auf eine Voice Line angewendet wird: ein Signal, der Ort, an dem es ausgelöst wird, und eine optionale Payload.

VoiceLineEventDispatcher

Ruft die Methoden VoiceLineEventAttribute der geladenen Szenen auf, sobald deren Signal ausgelöst wird. Fügen Sie eine solche Methode zur Startszene hinzu (sie befindet sich im Prefab [SubVox Pro]).

VoiceLineEventListener

Ruft die Methoden VoiceLineEventAttribute aller Komponenten dieses GameObjects auf, wenn ein Voice Line-Ereignis mit dem entsprechenden Signal-Key ausgelöst wird. Deaktivierte Komponenten werden übersprungen.

VoiceLineEventReaction

Eine Reaktion eines VoiceLineEventReceiver: ein Signal, eine optionale Voice Line und was aufgerufen werden soll.

VoiceLineEventReceiver

Ruft UnityEvents auf, die im Inspector festgelegt wurden, wenn Voice Line-Ereignisse ausgelöst werden: eine Reaktion pro Signal, optional auf eine Voice Line beschränkt.

VoiceLineEventSignalData

Ein wiederverwendbarer Ereignistyp (z. B. „Camera Shake“), der auf Voice Lines angewendet wird; der Code reagiert darauf über die Methoden Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>), „Receiver“ oder VoiceLineEventAttribute.

VoiceLineEventUnityEvent

Ein UnityEvent, das einen VoiceLineEventContext enthält, dargestellt im Inspector.

VoiceLineManager

Die Szenenkomponente hinter SubVox: Sie enthält die 2D-VoiceLineEmitter, die von Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) verwendet wird (Erzählung, Dialoge), hält jeden Emitter gleichzeitig an oder stoppt ihn, dämpft die Musik, während eine Stimme abgespielt wird, und veröffentlicht den Untertitel der wichtigsten gerade abgespielten Zeile – zuerst die mit der höchsten Priorität, dann die zuletzt gestartete.

VoiceLinePlayOnStart

Spielt eine Voice Line automatisch ab, wenn dieses Objekt gestartet (oder wieder aktiviert) wird, nach einer optionalen Verzögerung. Typisch für eine Einführungserzählung zu einem Level oder eine Eröffnungszeile. Play() bleibt öffentlich zugänglich, um eine manuelle Wiederverwendung zu ermöglichen.

VoiceLinePlayback

Eine Anfrage zum Abspielen einer Voice Line, die von Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) und Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) zurückgegeben wird: Verfolgen Sie deren Status unter State, stoppen Sie sie oder warten Sie in einer Coroutine mit yield return darauf.

VoiceLineSequenceData

Eine wiederverwendbare, geordnete Liste von Voice Lines, die nacheinander abgespielt werden sollen. Dieses Asset enthält lediglich die Definition (welche Voice Lines und wie jeweils zur nächsten übergegangen wird); ein VoiceLineSequencePlayer in der Szene steuert die Wiedergabe zur Laufzeit, sodass dieselbe Sequenz von mehreren Spielern sicher wiederverwendet werden kann.

VoiceLineSequencePlayer

Spielt zur Laufzeit eine VoiceLineSequenceData ab, Zeile für Zeile. Jeder Schritt wird entweder automatisch fortgesetzt, sobald die jeweilige Zeile beendet ist (nach einer optionalen Verzögerung), oder manuell über Advance() – das mit jedem beliebigen UnityEvent, einer Interaktion oder einer UI-Schaltfläche verknüpft werden kann – und Previous() springt eine Zeile zurück. Die Schritte werden in der Reihenfolge Direction abgespielt. Ein Schritt, der von einem ausgelasteten Emitter abgelehnt wird, wartet, bis dieser wieder frei ist. Stellt UnityEvents bereit, damit die Szenenlogik ohne Programmcode reagieren kann, sowie dieselben C#-Ereignisse für den Programmcode.

VoiceLineSequenceStep

Ein Schritt einer Sequenz: eine Zeile und wie die Sequenz danach weiterverläuft.

VoiceLineZone

Spielt eine Voice Line (oder die nächste Zeile einer Bank) ab, wenn ein Kollidierer diesen Trigger-Bereich betritt. Funktioniert mit einem 2D- oder einem 3D-Kollidierer: Es wird immer nur der Callback ausgelöst, der zu dem auf diesem Objekt vorhandenen Kollidierer passt, sodass eine einzige Komponente beide Fälle abdeckt. Filtern Sie nach Ebene und (optional) Tag, spielen Sie die Sprachzeile einmalig oder mit einem Cooldown ab, legen Sie fest, was geschieht, wenn der Emitter ausgelastet ist, und stoppen Sie optional die Sprachzeile oder aktivieren Sie die Zone erneut, wenn der Spieler den Bereich verlässt. Play() ist öffentlich, sodass jedes andere System (Interaktion, UI-Schaltfläche) es über ein UnityEvent wiederverwenden kann.

VoicePersonalityData

Eine wiederverwendbare Voreinstellung für Sprachstil und Persönlichkeit (ein Name sowie frei formulierte Sprechanweisungen). Diese wird als Stilvorgabe an Text-to-Speech-Provider übermittelt, die eine solche akzeptieren (Google Gemini-TTS, InWorld), sodass dieselbe Figur in vielen Sprachzeilen als „ruhig“, „wütend“, „flüsternd“ … synchronisiert werden kann. Speaker geben die zu ihnen passenden Persönlichkeiten an, und für einzelne Untertitel kann eine davon ausgewählt werden.
