Spielt eine Voice Line automatisch ab, wenn dieses Objekt gestartet (oder wieder aktiviert) wird, nach einer optionalen Verzögerung. Typisch für eine Einführungserzählung zu einem Level oder eine Eröffnungszeile. Play() bleibt öffentlich zugänglich, um eine manuelle Wiederverwendung zu ermöglichen.
