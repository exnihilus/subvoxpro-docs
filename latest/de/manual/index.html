SubVox Pro

SubVox Pro wandelt Ihre Voice Lines direkt in Unity in synchronisierte Untertitel und Sprachfassungen um:

  • Transkribieren Sie einen Audio-Clip in Untertitel mit Zeitangaben – über einen Cloud-Dienst oder vollständig offline.
  • Bearbeiten Sie das Timing anhand einer Wellenform, formatieren Sie Wörter und überprüfen Sie die Lesegeschwindigkeit.
  • Übersetzen Sie in 48 Sprachen und vertonen Sie die Texte per Sprachsynthese, optional mit der jeweiligen Stimme der Figur.
  • Spielen Sie alles mit wenigen Komponenten im Spiel ab, lösen Sie über eine Voice Line Gameplay-Ereignisse aus und ziehen Sie Voice Lines in die Unity Timeline.

Vor dem Start

  • Unity 2022.3 LTS oder neuer, einschließlich Unity 6, mit beliebiger Render-Pipeline: Built-in, URP oder HDRP.
  • TextMesh Pro: Importieren Sie TMP Essentials einmalig, falls dies noch nicht geschehen ist. Unter Unity 2022.3 installieren Sie zunächst das Package TextMeshPro über den Package Manager. Unity 6 enthält es bereits.
  • Unity Timeline ist optional: Die Timeline-Funktionen stehen zur Verfügung, sobald das Package installiert ist.
  • Im Spiel läuft SubVox Pro auf jeder von Unity unterstützten Plattform.
  • Im Editor wurde SubVox Pro unter Windows getestet. Die Cloud-Dienste mit Ihren eigenen API-Schlüsseln sollten auch unter macOS und Linux funktionieren, wurden dort jedoch noch nicht getestet. Die Offline-Engines (Transkription, Übersetzung und Vertonung ohne Account) setzen den Editor unter Windows voraus.

Schnellstart

Von einem Audio-Clip zu synchronisierten Untertiteln auf dem Bildschirm in wenigen Minuten.

Der Hub

Alle Funktionen von SubVox Pro erreichen Sie mit einem Klick über Tools ▸ SubVox Pro ▸ Hub. Seine neun Kacheln öffnen den Voice Line Editor (und die Stapelverarbeitung), die Dub Booth, Google Sheets, den MCP-Server für KI-Assistenten, die zusätzlichen Offline-Modelle, den Anbietervergleich, die Dokumentation, die Beispielszenen und die Einstellungen.

Voice Line Editor öffnet einen zweiten Bildschirm mit dem Voice Line Editor selbst und Batch Processing für viele Dateien auf einmal (Back führt zu den Kacheln zurück). Documentation öffnet einen weiteren:

Fünf Schritte

1. Transkriptionsmethode wählen. Fügen Sie den API-Schlüssel eines Spracherkennungsdienstes unter Tools ▸ SubVox Pro ▸ Settings ein (wo Sie einen erhalten) oder verwenden Sie unter Windows Whisper oder Parakeet, kostenlos und offline (beide bieten bei der ersten Verwendung den Download ihres Modells an).

2. Eine Voice Line erstellen. Assets ▸ Create ▸ SubVox Pro ▸ Voice Line, wählen Sie sie aus und klicken Sie im Inspector auf Edit Voice Line. Das SubVox Pro-Fenster öffnet sich mit einer neuen Voice Line: Überprüfen Sie Language (beim ersten Mal Englisch, danach die zuletzt gewählte Sprache), wählen Sie Add an audio track und Ihren Clip aus oder nehmen Sie einen auf.

Alternativ klicken Sie im Project-Fenster mit der rechten Maustaste auf eine Audiodatei und wählen SubVox Pro ▸ Create Voice Line. Legen Sie den Speicherort der neuen Voice Line fest: Der Editor öffnet sich mit dem bereits zugewiesenen Clip.

3. Transkribieren. Wählen Sie unter AI Tools ▸ Transcription den Anbieter und die gesprochene Sprache aus und klicken Sie auf Transcribe. Die Untertitel erscheinen auf der Wellenform.

4. Anpassen. Ziehen Sie die Marker auf der Wellenform, korrigieren Sie den Text in der Liste und drücken Sie Space, um zuzuhören.

5. Im Spiel anzeigen. Fügen Sie die Prefabs [SubVox Pro] und Subtitle Displayer (SubVoxPro/Prefabs) in Ihre Szene ein und spielen Sie die Voice Line ab:

using SubVoxPro;

SubVox.Play(myVoiceLine);

Möchten Sie es zuerst in Aktion sehen? Öffnen Sie Examples im Hub (oder Tools ▸ SubVox Pro ▸ Example Scenes) und drücken Sie auf Play. Vier fertige Szenen mit Voice Lines in vier Sprachen, Sprechblasen, Dialogsequenzen, Voice-Events und Untertiteloptionen:

  • ein 3D-Tempel;
  • eine 2D-Neonstation;
  • eine Noir-Visual-Novel;
  • eine Sandbox in der Ego-Perspektive mit einem Stand pro Funktion.

Das SubVox Pro-Fenster

Öffnen Sie es über Tools ▸ SubVox Pro ▸ Voice Line Editor oder über Edit Voice Line im Inspector einer Voice Line. Von oben nach unten:

  • Voice Line Data: die aktuelle Voice Line, mit Schaltflächen zum Erstellen, Durchsuchen, Aufteilen und Löschen. Der farbige Punkt ist ein Tag, das auf dem Symbol des Assets im Project-Fenster erscheint und beim Sortieren Ihrer Voice Lines hilft. Die Voice Lines der Beispielszenen liegen getrennt in einem eingeklappten Ordner Examples am Ende der Liste.
  • Source: die Auswahlfelder AUDIO und SUBTITLES. Jede Voice Line hat eine Ausgangssprache (die Flagge; klicken Sie darauf, um sie zu ändern) und eine Spur pro übersetzter oder vertonter Sprache. Die beiden Auswahlfelder sind unabhängig: Sie können zum Beispiel französische Untertitel lesen und dabei den englischen Ton hören.
  • AI Tools: Transkription, Übersetzung und Vertonung (siehe unten).
  • Timeline: die Wellenform mit den Untertitel-Markern. Jeder Marker kennzeichnet den Beginn eines Untertitels; ein Marker ohne Text leert die Anzeige (ein Leermarker). Marker gehören zum Audio: Die Quelle und jede Vertonung haben eigene Marker auf ihrem eigenen Audio.
  • Live preview: der Untertitel an der Position des Abspielkopfs, so wie er im Spiel erscheint. Wählen Sie darüber eine Farbe oder einen Stil und ziehen Sie dann über Wörter, um sie zu formatieren (Ziehen mit der rechten Maustaste entfernt die Formatierung).
  • Subtitles: eine Zeile pro Untertitel mit Name, Dauer, Speaker, Text und einer Schaltfläche zum Abspielen.

Tags und Sprachen

Klicken Sie auf das Tag neben Voice Line Data, um Farbe und Form zu wählen. Clear tag entfernt es. Dank der Form lassen sich Voice Lines auch ohne Farbunterscheidung auseinanderhalten. Klicken Sie auf A-Z oder 0-9, um einen Buchstaben oder eine Ziffer als Form zu verwenden.

Klicken Sie auf die Flagge der Ausgangssprache, um die gesprochene Sprache zu wählen.

  • Flaggen stehen für Sprachen, nicht für die Nationalität der Figuren: Die Auswahl zeigt Namen und Code jeder Sprache, Sie müssen die Flagge also nicht erkennen.
  • Sprachen, die bereits von einer Übersetzung oder Vertonung belegt sind, sind ausgegraut.
  • Um die Originaluntertitel zu löschen, verwenden Sie das Kreuz in der Quellzeile der Auswahl SUBTITLES.

Ohne Audio beginnen

Eine Voice Line kann statt mit Audio auch mit Text beginnen. Wählen Sie Add a subtitles track und dann:

Auswahl Ergebnis
.srt-Datei importieren Untertitel mit ihren Zeitangaben
.txt-Datei importieren Ein Untertitel pro Zeile, mit Dauern, die genug Zeit zum Lesen lassen
Zeilen von Hand hinzufügen Die Zeilen, die Sie selbst eingeben

Legen Sie Length fest: So lange wird die Voice Line im Spiel wiedergegeben, bis Sie Audio hinzufügen oder aus dem Text eine Sprachfassung generieren.

Audio aufnehmen

Record with a microphone (unter Add an audio track oder über das + neben dem AUDIO-Auswahlfeld) öffnet ein kleines Aufnahmefenster:

  1. Wählen Sie das Mikrofon und achten Sie auf den Pegel. Um ihn einzustellen, klicken Sie neben Gain auf Calibrate und sprechen Sie 3 Sekunden lang normal.
  2. Nehmen Sie auf und hören Sie sich die Aufnahme an.
  3. Klicken Sie auf Use recording. Die Aufnahme wird als WAV-Datei neben der Voice Line gespeichert.

Gestatten Sie Unity unter macOS in den Systemeinstellungen die Nutzung des Mikrofons.

Beim Aufnehmen mitlesen

Hat die Voice Line bereits Untertitel, zeigt das Aufnahmefenster sie unter Read along an: Sie können eine Synchronisation aufnehmen und dabei den Text lesen. Wählen Sie die Sprache in der Liste (oder Off).

Während Sie sprechen, werden Wörter grün, sobald sie erkannt werden, und rot, wenn sie übersprungen wurden. Der Text scrollt Zeile für Zeile mit, die vorige Zeile bleibt sichtbar.

  • Alles läuft kostenlos auf Ihrem Computer: Dafür wird Parakeet oder ein lokales Whisper-Modell benötigt (Tools ▸ SubVox Pro ▸ Additional Models). Sind mehrere installiert, wählen Sie im Menü neben der Sprache aus, welches verwendet wird.
  • Retake verwirft die Aufnahme und startet sofort eine neue.
  • Listen spielt die Aufnahme ab der Wiedergabemarke ab. Klicken oder ziehen Sie in der Wellenform, um sie zu verschieben; Stop lässt sie dort, wo die Wiedergabe angehalten wurde. Die Leertaste startet und stoppt die Wiedergabe ebenfalls.
  • Nach Stop wird die ganze Aufnahme noch einmal geprüft. Rote Wörter, die Sie doch gesagt haben, können Sie anklicken, um sie zu übernehmen.
  • Use recording fügt die Aufnahme wie gewohnt hinzu (Spur ersetzen oder Synchronisation hinzufügen), wobei jedes Wort anhand Ihrer Aufnahme getimt wird. Ist das Qwen3-Wort-Timing installiert, verfeinert es diese Zeiten. Undo stellt die vorherigen Zeiten wieder her.

Synchron zum Original synchronisieren (Dub Booth)

Die Dub Booth nimmt eine Synchronisation so auf, wie Sprecher es tun: Zeile für Zeile, über die Originalaufnahme, damit Ihre Aufnahme genau dort liegt, wo die Originalzeile ist. Öffnen Sie sie über + Add audio ▸ Dub over the original, den Hub oder Tools ▸ SubVox Pro ▸ Dub Booth. Tragen Sie Kopfhörer, damit das Original nicht ins Mikrofon gelangt.

  1. Wählen Sie die Voice Line und die zu synchronisierende Sprache. Original (ADR) nimmt die Originalsprache neu auf.
  2. Drücken Sie die Leertaste. Das Original spielt einige Sekunden vor der Zeile, drei Pieptöne zählen herunter, und die Aufnahme beginnt auf dem vierten, stummen Schlag. Der Text läuft Wort für Wort am Abspielkopf vorbei, zwischen den Marken IN und OUT.
  3. Die Aufnahme endet am Ende der Zeile von selbst (oder drücken Sie die Leertaste).
    • Plaketten zeigen, ob Sie on cue (im Timing) begonnen haben und um wie viel Sie länger (longer) oder kürzer (shorter) als das Original waren. Fahren Sie mit der Maus darüber, um beide Dauern zu sehen.
    • Schon während der Aufnahme daneben? Discard (oder Esc) verwirft sie sofort, ohne das Ende abzuwarten.
  4. Hören Sie und vergleichen Sie (siehe Tabelle unten) oder nehmen Sie mit Redo neu auf.
  5. Validate & next (oder Eingabe) bestätigt die Aufnahme und geht zur nächsten aufzunehmenden Zeile. Unvalidate nimmt die Bestätigung zurück.
  6. Build dub legt die behaltenen Aufnahmen auf die Zeitleiste des Originals und fügt sie als Synchronisation dieser Sprache hinzu (bei Original (ADR): Replace original). Anschließend werden die Wörter Zeile für Zeile auf Ihre Aufnahmen getimt, ohne dass ein Modell installiert werden muss. Installieren Sie das Qwen3-Wort-Timing (Additional Models) für noch genauere Timings.

Zeile zu lang oder zu kurz

  • Shorten: Eine Übersetzung ist oft 20 bis 30 % länger als das Original. Wenn eine Zeile in der Zeit des Originals schwer zu sprechen ist, erscheint vor der Aufnahme ein Hinweis unter ihrem Text. Shorten bittet Ihren Übersetzer (OpenAI, Claude, Gemini oder DeepSeek) um eine kürzere Zeile mit derselben Bedeutung, die in diese Zeit passt; Undo stellt den vorherigen Text wieder her.
  • Fit to original: Neben den Plaketten dehnt oder staucht es eine Aufnahme um höchstens 10 %, ohne die Tonhöhe der Stimme zu ändern, und verschiebt sie so, dass sie mit dem Original beginnt. Das Ergebnis ist eine neue Aufnahme, bereit zur Bestätigung. Mehr als 10 % Abweichung? Nehmen Sie die Zeile neu auf: Stärkeres Dehnen würde unnatürlich klingen.

Einstellungen und Speichern

  • Booth settings stellt Mikrofon, Verstärkung (Calibrate funktioniert wie im Aufnahmefenster), den Vorlauf des Originals vor der Zeile, die Pieptöne, das während der Aufnahme Gehörte und die Laufgeschwindigkeit ein (ein Mindestwert: Der Text läuft schneller, wenn eine Zeile sonst nicht passt).
  • Aufnahmen werden laufend gespeichert: Schließen Sie das Fenster und machen Sie später dort weiter, wo Sie aufgehört haben.

Eigene Synchronisationen hinzufügen

Sie haben bereits aufgenommene Synchronisationen? Klicken Sie auf das + neben der AUDIO-Auswahl und wählen oder nehmen Sie den Clip auf. Ein Fenster fragt dann nach seiner Sprache:

  • Replace a track: ersetzt das Originalaudio oder eine vorhandene Synchronisation;
  • Add a new track: Wählen Sie seine Sprache, um ihn als neue Synchronisation hinzuzufügen.

Die Zeilen werden proportional auf dem neuen Audio platziert (oder nach der Aufnahme getimt, wenn Sie mitgelesen haben): Ziehen Sie die Marker zur Feinabstimmung. Übersetzte Zeilen in dieser Sprache werden über der Synchronisation angezeigt, sofern vorhanden.

Untertitel in einer anderen Sprache importieren

Das + neben der Auswahl SUBTITLES importiert eine .srt- oder .txt-Datei. Bei einer Voice Line, die bereits Inhalt hat, fragt ein Fenster, in welcher Sprache die Datei ist:

  • Replace a track: ersetzt die Originaluntertitel (mit den Timings der Datei) oder eine vorhandene Übersetzung;
  • Add a new track: Wählen Sie ihre Sprache, um sie als neue Übersetzung hinzuzufügen.

Eine Übersetzung behält das Timing der Originalzeilen. Jede importierte Zeile geht an die Originalzeile an derselben Position oder, bei einer .srt mit anderer Zeilenanzahl, an die Originalzeile, die zu diesem Zeitpunkt läuft.

Untertitel überprüfen

  • Show CPS (unter Settings) zeigt die Lesegeschwindigkeit jeder Zeile an und markiert zu schnelle Zeilen.
  • Check Subtitles, zusammen mit Show CPS angezeigt, geht alle Probleme nacheinander durch (leere oder doppelte Namen, Zeilen außerhalb des Clips, Überlappungen, zu schnell zu lesende Zeilen) und bietet Korrekturen per Klick. Alles lässt sich rückgängig machen.
  • Auto blanks blendet den Untertitel aus, solange niemand spricht, ohne Marker hinzuzufügen. Klicken Sie auf seine Schaltfläche (nach den Registerkarten für Zuschneiden, Zeitbearbeitung und Effekte, rechts in der Leiste der Timeline), aktivieren Sie die Funktion im Popup und legen Sie die Mindestdauer einer Pause fest; ausgeblendete Bereiche werden in der Wellenform schattiert.
  • Export SRT speichert die Untertitel als .srt-Datei.

Einstellung von Auto blanks Funktion

Die SYNC-Chips

Jede Zeile der Liste Subtitles beginnt in der Spalte SYNC mit einem farbigen Chip, der den Zustand dieser Zeile anzeigt. Fahren Sie mit der Maus über einen Chip, um Details zu sehen; ist ein Chip anklickbar, beschreibt sein Tooltip, was der Klick bewirkt.

Bei den Originaluntertiteln zeigt der Chip, wie gut die Wörter auf das Audio abgestimmt sind:

Chip Bedeutung Was tun
SYNC Jedes Wort ist auf das Audio abgestimmt: Die Wörter erscheinen genau dann, wenn sie gesprochen werden. Nichts.
FIX n n Wörter haben eine geschätzte Zeit: Sie wurden im Audio nicht erkannt. Prüfen Sie ihre Wortmarker auf der Wellenform (Modus Words) und verschieben Sie sie bei Bedarf.
TEXT + Die Zeile hat keine Wort-Timings und erscheint daher auf einmal. Klicken Sie auf den Chip, um die Zeit jedes Wortes aus dem Text zu schätzen. Die Zeile zeigt danach FIX, da diese Zeiten geschätzt sind.
BLANK Ein Marker ohne Text: Er leert den Bildschirm bis zum nächsten Untertitel. Nichts.

Bei einer Übersetzung (wählen Sie ihre Sprache im Auswahlfeld SUBTITLES) zeigt der Chip, ob die Zeile noch zum Original und zu ihrer Sprachfassung passt:

Chip Bedeutung Was tun
FR Der Sprachcode (FR, EN-US …): Die Übersetzung ist auf dem Stand des Originals. Der Tooltip zeigt auch, ob ihre Sprachfassung aktuell ist. Nichts.
OUT Die Originalzeile oder ihr Übersetzungshinweis wurde nach der Übersetzung geändert. Klicken Sie auf Synchronize translations (Registerkarte Translation), um sie neu zu übersetzen, oder klicken Sie nach dem Prüfen der Zeile auf den Chip, um sie als aktuell zu markieren.
CUT Ein Originalmarker wurde verschoben: Die übersetzte Zeile wurde automatisch neu geteilt und bricht womöglich mitten in einer Wendung um. Klicken Sie auf Fix splits (Registerkarte Translation), um sie mit KI neu zu teilen, oder klicken Sie auf den Chip, um diese Teilung zu behalten.
REGEN Die Sprachfassung passt nicht mehr zur Zeile: Text, Stimme, Persönlichkeit, Sounds oder Gruppen wurden geändert, der Anbieter, das Modell oder der Generierungsmodus wurde geändert, oder die Zeile wurde nie vertont. Fahren Sie darüber, um den Grund zu sehen, und klicken Sie darauf, um nur das Nötige neu zu erzeugen.
DUBBING Die Sprachfassung dieser Zeile wird gerade erzeugt (der Chip ist animiert). Warten Sie.

Eine Zeile zeigt immer nur einen Chip, in dieser Rangfolge:

OUT dann CUT dann REGEN

Eine BLANK-Zeile zeigt immer BLANK.

Eine Voice Line löschen

Die Papierkorbschaltfläche löscht die Voice Line und listet die dazugehörigen Dateien auf: Die von SubVox Pro generierten Dateien (Sprachfassungen, Aufnahmen) sind ausgewählt, Ihre eigenen Dateien nicht, und eine Datei, die an anderer Stelle noch verwendet wird, ist gesperrt. Alles wird in den Papierkorb des Betriebssystems verschoben: Nichts geht endgültig verloren.

Eine Voice Line aufteilen

Wenn eine Voice Line mehrere Momente enthält, die Sie getrennt abspielen möchten, teilt die Schaltfläche zum Aufteilen (neben dem Papierkorb) sie in mehrere Voice Lines auf:

  1. Klicken Sie zwischen zwei Untertitel, um dort zu schneiden. Ein Schnitt liegt immer zwischen zwei Untertiteln, in der Pause, die sie trennt.
  2. Fügen Sie so viele Schnitte wie nötig hinzu.
  3. Benennen Sie die neuen Voice Lines.

Was aus den Teilen wird:

  • Jeder Teil behält alles, was zu seinen Untertiteln gehört: Audio, Übersetzungen, Sprachfassungen, Speaker, Audioeffekte und Events.
  • Der erste Teil bleibt in der aktuellen Voice Line: Ihre Szenen und Timelines verweisen weiterhin auf sie. Die anderen Teile werden daneben erstellt.
  • Jeder Teil erhält eigene Audiodateien, und Ihre Originaldateien bleiben erhalten.
  • Das Aufteilen kann nicht rückgängig gemacht werden.

Transkribieren

  1. Wählen Sie einen Provider und, falls dieser mehrere anbietet, ein Model. Die Statusanzeige rechts zeigt, ob er einsatzbereit ist (Schlüssel eingerichtet oder Modell heruntergeladen).
  2. Die transkribierte Sprache ist die Flagge der ausgewählten Audiospur; um die Ausgangssprache zu ändern, klicken Sie auf ihre Flagge. Kann der Anbieter diese Sprache nicht transkribieren, erscheint ein Hinweis mit den Anbietern, die es können. Hat die Quelle noch keine Sprache, tragen Anbieter mit automatischer Erkennung sie für Sie ein; bei den anderen fragt Transcribe zuerst danach.
  3. Klicken Sie auf Transcribe: Das Audio wird in Wörter umgewandelt, die anschließend zu Untertiteln gruppiert werden. Die Split settings legen fest, wie lange ein Untertitel höchstens dauert, wie früh er vor seinem ersten Wort erscheint und ob Zeilen an Satzzeichen enden sollen. Hat die Voice Line bereits Untertitel, werden Sie vor dem Ersetzen gefragt.
  4. Passt die Aufteilung nicht? Ändern Sie die Split settings: Am Ende der Zeile Smart split erscheint eine kleine Schaltfläche Re-split. Klicken Sie darauf: Dieselben Wörter werden neu gruppiert, ohne erneute Transkription (und ohne erneute Kosten).

Wort-Timing

Word timing legt fest, woher die Zeitangabe jedes Wortes stammt:

Option Funktion
From the provider (Standard) Behält die von der Transkription gelieferten Zeitangaben bei.
Built-in aligner Ordnet jedes Wort vor dem Aufteilen erneut dem Audio zu, damit die Schnitte auf den echten Pausen liegen. Keine Installation nötig, funktioniert in jeder Sprache.
Qwen3 aligner (local) Ebenso, mit den genauesten Zeitangaben für wortweise angezeigte Untertitel (einmal installieren). Bei einer Sprache, die Qwen3 nicht unterstützt, bleiben die Zeitangaben des Anbieters erhalten.

Die Aligner ändern den Text nie. Die Schaltfläche Re-align am Ende dieser Zeile funktioniert mit beiden Alignern (bei From the provider ist sie ausgegraut): Wenn Sie ein Wort korrigiert oder einen Schnitt von Hand verschoben haben, ordnet sie die Wörter erneut dem Audio zu und behält dabei Ihren Text und Ihre Schnitte bei.

Anbieter

AssemblyAI, Gladia, Deepgram, Speechmatics, ElevenLabs, Rev AI, Cartesia, OpenAI oder Whisper und Parakeet offline.

Unsicher, welchen Sie wählen sollen? Tools ▸ SubVox Pro ▸ Provider Comparison vergleicht sie direkt miteinander: Preis, kostenloser Tarif, kommerzielle Nutzung, Sprachen.

Tipp: OpenAI gpt-transcribe liefert Text ohne Zeitstempel für die einzelnen Wörter; die Zeitangaben werden über die Dauer des Clips geschätzt. Nutzen Sie die lokale Zuordnung oder einen Anbieter mit Wortzeitstempeln, wenn das Timing wichtig ist.

Übersetzen

  1. Wählen Sie einen Provider: DeepL, Google Translate, OpenAI, Claude, Gemini, DeepSeek oder Hy-MT2 offline.
  2. Haken Sie unter Target eine oder mehrere Sprachen an oder wählen Sie eine Voreinstellung, um mehrere Sprachen auf einmal zu erstellen.
  3. Legen Sie unter Formality die Anrede fest (formell oder informell), sofern die Sprache diese Unterscheidung kennt.
  4. Klicken Sie auf Translate. Jede Sprache erhält eine eigene Spur; wechseln Sie mit dem SUBTITLES-Auswahlfeld zwischen ihnen.

Groups-Modus

Wenn Sie Groups wählen, wird das Werkzeug Groups oberhalb der Wellenform aktiviert. Jede Gruppe wird in einem Take gesprochen, mit der Stimme und dem Stimmprofil ihres ersten Wortes, und der Untertiteltext erhält die Farbe der Gruppe. Anfangs umfasst eine einzige Gruppe alles.

Optionen

  • Word timing: wie die Wörter der Vertonung getimt werden:

Speaker und Stimmprofile

Speaker

Ein Speaker ist eine Figur: ein Name, der in ihrer eigenen Farbe vor ihren Untertiteln angezeigt wird, und ihre Stimmen für die Vertonung. Erstellen Sie einen Speaker über Assets ▸ Create ▸ SubVox Pro ▸ Speaker oder über die Speaker-Auswahl im Fenster.

  • Legen Sie den Speaker einer ganzen Voice Line im Feld Speaker oberhalb der Liste fest: Er gilt für alle Zeilen. Jede Zeile kann trotzdem in ihrer eigenen Reihe einen Speaker wählen; das Feld zeigt dann Mixed.
  • Im Inspector des Speakers wählen Sie unter Text-to-speech voices die Stimme pro Anbieter, mit einer Standardstimme für alle Sprachen und optionalen Abweichungen pro Sprache.
  • Im Subtitle Displayer (oder Subtitle Document Displayer) legt Speaker Name Mode fest, ob der Name vor der Zeile (Inline), darüber (Above) oder gar nicht (Hidden) angezeigt wird. Ein Speaker kann auch eine eigene Schriftart haben: Font (TextMeshPro) für den Subtitle Displayer, Font (UI Toolkit) für den Subtitle Document Displayer.
  • Mit Keep Background Between Subtitles bleibt während eines Leermarkers zwischen zwei Zeilen nur das Untertitelpanel sichtbar. Die Option ist standardmäßig aktiviert; ein Leermarker vor der ersten oder nach der letzten Zeile blendet das Panel trotzdem aus.

Die Speaker-Auswahl gruppiert Figuren nach Geschlecht. Der Bleistift bearbeitet einen vorhandenen Speaker; New speaker erstellt einen neuen.

Stimmprofile

Ein Stimmprofil ist eine wiederverwendbare Sprechanweisung: Angry, Mysterious, Whispering …

  1. Erstellen Sie eines über einen Speaker (New personality) oder über Assets ▸ Create ▸ SubVox Pro ▸ Voice Personality.
  2. Formulieren Sie die Anweisung selbst oder kombinieren Sie eine Emotion und eine Sprechweise mit ihrer Intensität, dann Sprechtempo, Lautstärke, Tonhöhe und Artikulation.
  3. Klicken Sie auf sein Symbol, um eines von etwa vierzig Symbolen zu wählen (Emotionen, Stimmungen, Stimme und Charakter), damit Sie es in den Listen auf einen Blick erkennen.

Weisen Sie jeder Zeile über ihren Chip in der Liste ein Stimmprofil zu (im Modus Each subtitle) oder verwenden Sie standardmäßig das des Speakers.

  • Jeder Anbieter setzt um, was er kann, in der Form, die er versteht: geschriebene Anweisung, Audio-Tags oder Sprechstile. Andere befolgen nur das Sprechtempo.
  • Der Tooltip des Chips zeigt, was die gewählte Stimme davon verwendet.
  • Ein Stimmprofil legt fest, wie eine Zeile gesprochen wird, nicht wer spricht: Das Alter einer Stimme gehört zu ihrer Beschreibung (siehe unten).

Das Ereignis WordChanged eines Emitters wird bei jedem neu gesprochenen Wort ausgelöst (und zwischen den Wörtern), und CurrentWord enthält das aktuelle Wort: Das reicht, um den Mund einer Figur zu animieren oder eine Geste auszulösen.

Stimmgesteuerte Effekte

Loudness eines Emitters gibt an, wie laut die Stimme gerade ist, von 0 (Stille) bis 1. Damit pulsiert ein Schein, flackert ein Licht oder leuchtet ein Sprechersymbol, während eine Figur spricht.

halo.intensity = Mathf.Lerp(halo.intensity, emitter.Loudness * 3f, Time.deltaTime * 20f);

Es folgt der gehörten Sprache und wird beim Speichern einer Voice Line oder ihres Audios automatisch gemessen: Es gibt nichts einzurichten.

Sprache wechseln

Beim Ändern der Sprache wechseln die angezeigten Untertitel sofort. Die Sprachfassung folgt ab der nächsten Voice Line, da eine Voice Line die Sprache nicht mitten im Satz wechseln kann.

  • Audio in einer anderen Sprache: Standardmäßig folgen die Stimmen der Untertitelsprache. Damit Spieler eine Sprache hören und eine andere lesen (zum Beispiel japanische Stimmen mit französischen Untertiteln), setzen Sie SubVox.AudioLanguage; mit null folgt es wieder den Untertiteln. Die Beispielszenen bieten beide Auswahlen.
  • Unity Localization: Wenn Ihr Projekt das Localization-Paket von Unity verwendet, folgt SubVox Pro automatisch der dort gewählten Sprache. Um die Sprache selbst festzulegen, setzen Sie Language Source im Voice Line Manager auf Manual.
  • Sprechernamen: Ein Speaker kann in jeder Sprache einen anderen Namen anzeigen. Tragen Sie seine Localized Names ein oder verweisen Sie mit Unity Localization über Localization Table und Localization Entry auf eine Zeichenfolge.
  • Verwandte Sprachen: Ein Spieler mit pt-BR hört und liest eine Übersetzung in pt, wenn keine in pt-BR vorhanden ist (und umgekehrt).
  • Sprachauswahlmenü: myVoiceLine.GetSubtitleLanguages() und GetAudioLanguages() listen auf, was eine Voice Line anbietet.

Spielaktionen durch eine Voice Line auslösen

Eine Tür bei „Lauf!“ öffnen, die Kamera bei einem Schrei wackeln lassen: Ereignisse werden zu einem bestimmten Zeitpunkt einer Voice Line ausgelöst.

  1. Schalten Sie die Zeitleiste auf Events um und klicken Sie auf + Event (oder mit der mittleren Maustaste auf die Wellenform).
  2. Weisen Sie ihm ein Signal zu: ein kleines, wiederverwendbares Asset, das das Ereignis benennt, zum Beispiel Camera Shake.
  3. Wählen Sie, wann es ausgelöst wird: zu Beginn oder am Ende der Stimme, zu einem bestimmten Zeitpunkt oder bei einem Untertitel oder Wort (es folgt dann diesem Wort, falls sich dessen Timing ändert). Ziehen Sie die Raute, um es zu verschieben.

Reagieren Sie anschließend auf eine dieser drei Arten darauf:

  • Ohne Code: Fügen Sie einem Objekt einen Voice Line Event Receiver hinzu, wählen Sie das Signal und verbinden Sie ein UnityEvent.

  • Mit einem Attribut: Kennzeichnen Sie eine beliebige Methode eines MonoBehaviour mit der generierten Signalkonstante (der Signal-Inspector kopiert sie):

    [VoiceLineEvent(SubVoxEvents.CAMERA_SHAKE)]
private void Shake()
{
    // ...
}

    Legen Sie die optionale Category des Signals als durch / getrennte Hierarchie fest, zum Beispiel Camera/Effects, um SubVoxEvents.Camera.Effects.CAMERA_SHAKE zu generieren. Die Konstanten werden neu generiert, wenn ein Signal gespeichert, umbenannt, erstellt oder gelöscht wird. Das Umbenennen eines Schlüssels oder einer Kategorie lässt alte Verweise bewusst als Compilerfehler stehen; String-Schlüssel wie [VoiceLineEvent("Camera Shake")] werden weiterhin unterstützt.

    Die Konstanten liegen in Ihrem Datenordner (Generated/SubVoxEvents.g.cs): Plugin-Updates überschreiben sie nie. Skripte ohne Assembly-Definition sehen sie direkt; haben Ihre Skripte eine, fügen Sie einen Verweis auf SubVoxPro.Events hinzu.

    Das Prefab [SubVox Pro] findet diese Methoden selbstständig. Wenn Sie Objekte zur Laufzeit erstellen, rufen Sie VoiceLineEventDispatcher.Register(this) aus diesen Objekten auf. Bei einer sehr großen Szene können Sie Scan Scenes Automatically im Dispatcher deaktivieren und Ihre Objekte selbst registrieren.

  • In C#: SubVox.Subscribe(signal, MyMethod) ruft Ihre Methode bei jedem Auslösen dieses Signals auf (SubVox.Unsubscribe beendet das Abonnement).

Ein Ereignis kann außerdem:

  • eine Payload mitführen: ein beliebiges Asset, das mit dem Ereignis übermittelt wird; eine Methode, die diesen Asset-Typ als Parameter entgegennimmt, erhält es;
  • auf einmal pro Wiedergabe beschränkt werden.

Ereignisse werden nur im Play mode ausgelöst, nie während der Bearbeitung oder beim Verschieben des Abspielkopfs.

Unity Timeline

  1. Wählen Sie in Ihrer Timeline Add ▸ Voice Line Track.
  2. Ziehen Sie eine Voice Line darauf. Es wird ein Untertitelclip erstellt, dessen Audio auf einer separaten Voice Line Audio-Spur liegt.
  3. Binden Sie diese Audiospur wie jede andere Audio Track an eine AudioSource.
  4. Stellen Sie sicher, dass die Szene einen Subtitle Displayer hat (am schnellsten mit dem Prefab).

Audio und Untertitel bleiben synchron, auch wenn Sie den Abspielkopf verschieben.

  • Sequenzen: Eine abgelegte Voice Line Sequence ordnet alle ihre Voice Lines hintereinander an.
  • Ereignisse: Die Ereignisse der Voice Line werden während der Wiedergabe ausgelöst. Um sie wie Timeline-Marker zu verschieben, klicken Sie mit der rechten Maustaste auf den Clip und wählen Sie SubVox Pro ▸ Bake Voice Events to Timeline.
  • Sprache: Die Zwischensequenz spielt die Sprachfassung der Audiosprache ab (der aktuellen Sprache, sofern SubVox.AudioLanguage nicht gesetzt ist), wenn die Voice Line eine hat, mit synchronen Untertiteln. Die Sprache wird beim Start der Timeline festgelegt.
  • Einblendmodus: Ein Clip folgt dem Subtitle Reveal Mode des Managers, es sei denn, Sie aktivieren seine Option Override Reveal Mode.

Timeline-Clips und andere Voice Lines

Ein aktiver SubVox-Clip hat Vorrang bei der globalen Untertitelanzeige:

  • Andere Voice Lines werden weiter abgespielt, doch ihre Untertitel können den Text des Clips nicht ersetzen, auch nicht während einer Untertitelpause oder vor seinem ersten Untertitel. Eine Untertitelpause innerhalb des Clips folgt wie gewohnt Keep Background Between Subtitles.
  • Endet der Clip oder wird der Director gestoppt, wechselt die Anzeige sofort zum Emitter mit der höchsten Priorität, der noch spielt, an dessen aktueller Position; sein Audio wird nicht neu gestartet. Spielt kein Emitter, wird das Panel ausgeblendet.
  • Überlappen sich mehrere SubVox-Timeline-Spuren oder Directors, hat der zuletzt begonnene Clip Vorrang; das Ende eines anderen Clips löscht seine Untertitel nicht.
  • Ein pausierter Director behält seinen Untertitel, bis die Wiedergabe fortgesetzt oder der Director gestoppt wird.

  2. Aktivieren Sie die benötigten Schritte (Transcription, Translation, Dubbing) und richten Sie sie einmal für alle Dateien ein:
    • Transkription und Übersetzung haben jeweils eine Model-Auswahl, die mit dem Hauptfenster geteilt wird.

Um bereits in Ihrem Projekt vorhandene Assets in die Warteschlange aufzunehmen, wählen Sie mehrere Audiodateien oder eine oder mehrere Voice Lines aus, klicken Sie mit der rechten Maustaste und wählen Sie SubVox Pro ▸ Batch Processing. Sie werden der aktuellen Warteschlange hinzugefügt, ohne die Verarbeitung zu starten; doppelte Einträge werden ignoriert. Warten Sie, bis eine laufende Verarbeitung abgeschlossen ist, bevor Sie auf diese Weise Dateien hinzufügen.

Vorhandene Voice Lines fortsetzen

Eine im Editor begonnene Voice Line lässt sich in der Stapelverarbeitung fertigstellen:

  • Ihre Untertitel bleiben unverändert. Sie wird nur transkribiert, wenn sie Audio, aber noch keine Untertitel hat.
  • Sie erhält nur die Sprachen, die ihr fehlen: vorhandene Übersetzungen und Vertonungen werden übersprungen. Die Spalte LANGUAGES zeigt, was sie bereits hat und was die Stapelverarbeitung hinzufügt: Der Code ist grau, wenn die Untertitel schon vorhanden sind, und violett, wenn sie übersetzt werden; ein grauer Lautsprecher bedeutet vorhandenes Audio, ein blauer eine kommende Vertonung. Fahren Sie mit der Maus darüber, um die Details zu sehen.
  • Um ihre Übersetzungen und Vertonungen neu zu erstellen, aktivieren Sie Replace the translations and dubs voice lines already have. Dabei werden auch Ihre manuellen Änderungen ersetzt, daher fragt die Stapelverarbeitung zuerst nach einer Bestätigung. Die Option ist beim nächsten Öffnen des Fensters wieder deaktiviert.
  • Wenn Sie eine Voice Line aus der Warteschlange entfernen, wird sie nie aus Ihrem Projekt gelöscht. Ist sie im Editor geöffnet, zeigt der Editor die neuen Sprachen an, sobald ein Schritt abgeschlossen ist.

Während und nach der Verarbeitung

  • Sie können jederzeit abbrechen und einen Bericht über den Durchlauf exportieren.
  • Ein erneuter Klick auf Run batch setzt jede Datei dort fort, wo sie unterbrochen wurde, auch nach einem Neustart von Unity, ohne das Audio ein zweites Mal zu kopieren.
  • Wird ein Schritt übersprungen (zum Beispiel eine Sprache, die der Vertonungsanbieter nicht sprechen kann), erklärt eine ⚠-Zeile unter der Datei den Grund, und die Datei zeigt Done with warnings.
  • Ist eine Datei fertig, öffnet Open ihre Voice Line im Editor, und Re-run stellt ihre Übersetzung und Vertonung erneut in die Warteschlange (zum Beispiel nach dem Hinzufügen einer Sprache).

Einrichtung (einmalig)

  1. Google Cloud: Erstellen Sie unter https://console.cloud.google.com ein Projekt und aktivieren Sie die Google Sheets API. Wählen Sie unter OAuth consent screen die Option External und fügen Sie sich selbst sowie Ihre Übersetzer als Test users hinzu. Erstellen Sie dann eine OAuth client ID vom Typ Desktop app und kopieren Sie deren Client ID und Client secret.
  2. Die Tabelle: Erstellen Sie eine leere Google-Sheets-Tabelle, notieren Sie ihre ID aus der URL (zwischen /d/ und /edit) und geben Sie sie Ihren Übersetzern mit der Rolle Editor frei.
  3. Unity: Öffnen Sie Tools ▸ SubVox Pro ▸ Google Sheets Localization, fügen Sie die drei Werte ein, klicken Sie auf Connect und melden Sie sich im Browser an.

Täglicher Ablauf

  1. Die Übersetzer füllen die Sprachspalten aus und markieren jede Zeile als reviewed oder final.
  2. Klicken Sie auf Sync with Sheet: SubVox Pro zeigt jeden Unterschied an, Unity auf der einen und die Tabelle auf der anderen Seite.
  3. Wählen Sie die Version, die Sie behalten möchten. Vorher wird nichts geschrieben.

In der Tabelle:

  • Die Schlüsselspalten sind gesperrt: Übersetzer können nur die Übersetzungen bearbeiten.
  • Die Status sind farblich markiert (reviewed bernsteinfarben, final grün), und leere Übersetzungen sind farbig hinterlegt: Die verbleibende Arbeit fällt sofort auf.
  • Jede Voice Line beginnt mit einer dunklen Titelzeile; mit der Schaltfläche + / − am linken Rand klappen Sie ihre Zeilen ein oder aus.

Eine nur in der Tabelle hinzugefügte Zeile wird nie importiert (ein Untertitel braucht ein Timing), aber auch nie ohne Ihre Zustimmung gelöscht. Zwei Arten von Zeilen stehen standardmäßig auf Drop, damit eine einzige Synchronisierung aufräumt:

Zeile Warum
Duplicate Dieselbe Zeile erscheint zweimal in der Tabelle
Removed Die Zeile existiert in Unity nicht mehr, zum Beispiel nach einer neuen Aufteilung der Untertitel

Klicken Sie auf Keep, um eine davon in der Tabelle zu behalten. Die Schaltfläche neben Spreadsheet ID öffnet die Tabelle in Ihrem Browser.

Einstellungen

Unter Tools ▸ SubVox Pro ▸ Settings:

  • API Keys: ein Schlüssel pro Dienst. Die Schlüssel bleiben auf diesem Computer: Sie werden nie im Projekt gespeichert, committet oder ausgeliefert. Das Augensymbol am Ende der Zeile blendet den Schlüssel ein oder aus; das rote Kreuz entfernt ihn.
  • Preferences:
    • Native language names: zeigt Sprachen unter ihrem eigenen Namen an, wie Deutsch oder 日本語, statt auf Englisch (standardmäßig aus);
    • Show CPS: Lesegeschwindigkeit;
    • Custom inspectors;
    • Auto blanks on new lines;
    • Start MCP server with Unity (standardmäßig aus);
    • Assistants ask before paid runs und Assistants ask before overwriting (standardmäßig an).
  • Project languages: die Sprachen Ihres Spiels. Sie stehen überall dort an erster Stelle, wo Sie eine Sprache wählen (zum Beispiel die Current Language des Voice Line Managers); alle anderen bleiben darunter verfügbar. Standardmäßig ist Englisch eingestellt. Klicken Sie auf Add languages und haken Sie so viele Sprachen an wie nötig; entfernen Sie den Haken, um eine zu entfernen.
  • Data folder: hier werden neue Voice Lines, Speaker und Sprachfassungen erstellt.
  • Cloud Model Catalog: Cloud-KI-Modelle und ihre Preise, online aktuell gehalten. Über Manage models fügen Sie ein Modell hinzu, das noch nicht aufgeführt ist. Lokale Modelle wählen und installieren Sie in Additional Models und mit den Schaltflächen ihres Anbieters.
  • Local models & services: jede installierte Offline-Engine mit ihren Optionen (Grafikkarte, Ausdruckskraft von Chatterbox) und einer kleinen Einstellungsschaltfläche, die ihre Einrichtung öffnet; Additional Models… installiert die anderen. Dazu kommt die Bereinigung der ElevenLabs-Stimmklone.

Ihre Daten und Online-Dienste

SubVox Pro sendet nur dann Daten an einen Online-Dienst, wenn Sie eine Aktion starten, die diesen nutzt. Die Übertragung erfolgt direkt von Ihrem Computer aus, mit Ihrem eigenen API-Schlüssel und ausschließlich mit den Daten, die diese Aktion benötigt:

Aktion Was der Anbieter erhält
Transkribieren Die Audiodaten der Voice Line
Translate, Fix splits Den Untertiteltext, die Sprachnamen und die von Ihnen verfassten Kontexthinweise
Vertonen, Stimmvorschau Den zu sprechenden Text, die Einstellungen für Stimme und Stimmprofil sowie die Referenzaufnahme, wenn Sie eine Stimme klonen
Google Sheets Den Untertiteltext, der an ein Tabellenblatt in Ihrem eigenen Google-Konto gesendet wird

Es werden keine Daten an den Herausgeber von SubVox Pro gesendet: Es gibt kein Konto und keine Nutzungserfassung. SubVox Pro lädt lediglich die Modellliste von GitHub herunter und die Modelle selbst, wenn Sie auf Download klicken. Die Offline-Engines behalten alle Daten auf Ihrem Computer.

Wie ein Anbieter mit Ihren Daten umgeht (Speicherung, Verwendung zu Trainingszwecken, kommerzielle Nutzung bei kostenlosen Tarifen), richtet sich nach seinen eigenen Nutzungsbedingungen, die unter Provider Setup zusammengefasst sind. Nutzen Sie für Skripte oder Aufnahmen, die Sie nicht weitergeben dürfen, die Offline-Engines.

KI-generierte Stimmen in Ihrem Spiel

  • Informieren Sie Ihre Spieler. OpenAI verlangt, dass Sie Spieler darauf hinweisen, dass die gehörten Stimmen KI-generiert sind, und einige Stores, etwa Steam, verlangen, dass Sie bei der Veröffentlichung KI-generierte Inhalte deklarieren. Ein Hinweis im Abspann oder im Einstellungsmenü ist dafür üblich.
  • Klonen Sie nur Stimmen, für deren Nutzung Sie die Rechte besitzen. Holen Sie die schriftliche Einwilligung der Schauspieler ein, deren Stimmen Sie klonen. Die mit den Offline-Engines mitgelieferten Referenzstimmen dürfen frei verwendet werden.
  • Prüfen Sie Ihren Tarif. Einige kostenlose Tarife verbieten die kommerzielle Nutzung: siehe die Tabelle zu den kostenlosen Tarifen unter Provider Setup.
  • Lassen Sie Übersetzungen überprüfen. Vor der Veröffentlichung kann ein Muttersprachler sie in Google Sheets prüfen.

Aktualisieren und Deinstallieren

Aktualisieren

  1. Committen Sie Ihr Projekt oder erstellen Sie eine Sicherungskopie.
  2. Importieren Sie die neue Version über Window ▸ Package Manager ▸ My Assets. Ihr Datenordner, Ihre Einstellungen, API-Schlüssel und heruntergeladenen Modelle bleiben erhalten. Falls Sie den SubVox Pro-Ordner verschoben haben, wird die Aktualisierung dort installiert.
  3. Starten Sie Unity neu, damit die neuen Dateien der Offline-Engines verwendet werden.

Deinstallieren

Committen Sie Ihr Projekt oder erstellen Sie eine Sicherungskopie, und öffnen Sie dann Tools ▸ SubVox Pro ▸ Uninstall… (auch unten in den Einstellungen). Das Fenster führt durch vier Schritte:

  1. Where SubVox Pro is used: die Szenen, Prefabs, Timelines, Assets und Skripte Ihres Projekts, die SubVox Pro verwenden. Klicken Sie auf einen Eintrag, um ihn zu finden.
    • Aktivieren Sie Remove SubVox Pro from these scenes, prefabs and assets (standardmäßig deaktiviert), um sie bei der Deinstallation zu bereinigen: Ihre SubVox-Pro-Komponenten, die SubVox-Pro-Spuren, -Clips und -Marker ihrer Timelines und die Event-Listener, die SubVox Pro aufrufen, werden entfernt, und die hier aufgeführten SubVox-Pro-Assets werden gelöscht. Ihre anderen Listener und Referenzen bleiben unberührt. Die Felder, die auf SubVox Pro verwiesen, werden in der Console aufgeführt. Speichern Sie zuerst Ihre geöffneten Szenen.
    • Bleibt die Option deaktiviert, werden die SubVox-Pro-Komponenten zu Missing Scripts. Eine Neuinstallation von SubVox Pro stellt sie wieder her.
    • Skripte werden nie geändert: Passen Sie sie zuerst an, sonst kompilieren sie nicht mehr. Klicken Sie dann auf Scan again.
  2. API keys and Google accounts (standardmäßig aktiviert): löscht Ihre Schlüssel und trennt Google von diesem Computer. Deaktivieren Sie es, wenn ein anderes Projekt SubVox Pro noch verwendet.
  3. Local models (standardmäßig deaktiviert): löscht die Offline-Engines. Sie werden von allen Ihren Projekten gemeinsam genutzt.
  4. Project files: Der SubVox Pro-Ordner, seine Einstellungen, der Ordner Generated und sein Cache werden immer gelöscht. Ihr Datenordner (Voice Lines, Synchronisationen, Aufnahmen, Speaker, Event-Signale) wird nur gelöscht, wenn Sie ihn ankreuzen.

Klicken Sie auf Uninstall SubVox Pro und bestätigen Sie. Ein Fortschrittsbalken zeigt jeden Schritt an. Falls eine Datei nicht gelöscht werden konnte, starten Sie Unity neu und löschen Sie sie von Hand.

Problem Lösung
Eine Offline-Engine lässt sich nicht laden und meldet eine fehlende DLL Installieren Sie die neueste Version von Microsoft Visual C++ Redistributable (x64) von Microsoft und starten Sie Unity neu.
