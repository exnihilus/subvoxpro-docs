SubVox Pro — Leitfaden zur Anbieter-Einrichtung

SubVox Pro liefert niemals einen API-Schlüssel mit. Der Zugriff auf jeden der unten aufgeführten Anbieter erfolgt über Ihren eigenen Schlüssel, den Sie unter Tools ▸ SubVox Pro ▸ Settings (oder im Anbieter-Panel innerhalb des SubVox Pro-Fensters) einfügen. Die Schlüssel werden ausschließlich in den Unity-Editor-Einstellungen auf Ihrem Rechner gespeichert (EditorPrefs) — niemals in die Versionsverwaltung Ihres Projekts aufgenommen und niemals mit einem Build gebündelt. Die rechtlichen Bestimmungen der einzelnen Dienste finden Sie in Third-Party Notices.md.

⚠️ Kostenlose Tarife und Preise ändern sich häufig. Die unten aufgeführten Angaben waren zum Zeitpunkt der Erstellung korrekt; überprüfen Sie stets das aktuelle Angebot auf der Preisseite des jeweiligen Anbieters, bevor Sie sich darauf verlassen.

Die Sprach- und Modellkataloge der Anbieter können sich unabhängig von SubVox Pro weiterentwickeln. Aktualisieren Sie den Modell- oder Stimmenkatalog im Editor, wenn ein Anbieter weitere Sprachen unterstützt; für Qwen, Kokoro, Chatterbox, Qwen3 TTS und VoxCPM2 entsprechen die festen Listen oben den lokalen Modellen mit festgelegter Version.

Chatterbox: Zuverlässigkeit der einzelnen Sprachen

  • Sehr zuverlässig: Portugiesisch, Italienisch, Spanisch, Hindi, Englisch, Deutsch, Malaiisch, Russisch und Niederländisch.
  • Zuverlässig: Finnisch, Griechisch, Arabisch, Schwedisch, Französisch, Japanisch und Chinesisch — gelegentlich kann das erste Wort fehlerhaft gesprochen werden.
  • Schwankend: Dänisch, Polnisch, Norwegisch, Koreanisch, Swahili und Türkisch — hören Sie sich die synchronisierten Sprachfassungen an und generieren Sie eine fehlerhafte Zeile über den zugehörigen REGEN-Chip neu.

Bewährte Vorgehensweisen

API-Schlüssel sind Passwörter für Online-Dienste. Behandeln Sie sie vertraulich, auch wenn Sie nur testen.

  • Erstellen Sie einen Schlüssel pro Tool oder Projekt. Ein dedizierter SubVoxPro-Schlüssel lässt sich später leichter widerrufen, ohne dass andere Tools beeinträchtigt werden.
  • Fügen Sie API-Schlüssel niemals in Quelldateien, Szenen, Prefabs, Support-Nachrichten, Discord, GitHub-Issues oder Commits ein. SubVox Pro speichert Schlüssel in Unity EditorPrefs, ausschließlich auf Ihrem Rechner, sodass sie nicht Teil des Unity-Projekts werden.
  • Kopieren Sie Schlüssel sofort, wenn der Anbieter darauf hinweist, dass sie nur einmal angezeigt werden. Speichern Sie sie in einem Passwortmanager, falls Sie eine Sicherungskopie benötigen. Sollten Sie einen Schlüssel verlieren, widerrufen Sie ihn und erstellen Sie einen neuen.
  • Vergeben Sie nur die Berechtigungen, die tatsächlich nötig sind. Wenn ein Anbieter Ihnen erlaubt, einen Schlüssel einzuschränken, aktivieren Sie nur die Funktionen, die SubVox Pro benötigt: Spracherkennung für Transkriptionsanbieter, Übersetzung für Übersetzungsanbieter und Sprachsynthese (TTS) ausschließlich für die Sprachvertonung.
  • Wählen Sie eine Gültigkeitsdauer, die zu Ihrem Arbeitsablauf passt. Kurzlebige Schlüssel sind sicherer für Tests und Demos; länger gültige Schlüssel sind praktischer für laufende Produktionsarbeiten. Einige Anbieter erlauben auch Schlüssel, die niemals ablaufen.
  • Legen Sie Budgets, Nutzungslimits oder Kostenwarnungen fest, sofern der Anbieter sie unterstützt. So schützen Sie sich vor versehentlichen Schleifen, wiederholten Importen oder der Verwendung des falschen Schlüssels durch ein Teammitglied.
  • Tauschen Sie Schlüssel aus, wenn sie möglicherweise offengelegt wurden. Sollte ein Schlüssel in einem Screenshot, einem Commit, einer Chat-Nachricht oder einem Build-Artefakt erscheinen, widerrufen Sie ihn im Dashboard des Anbieters und fügen Sie den neuen in SubVox Pro ein.
  • Geben Sie einen persönlichen Schlüssel nicht innerhalb eines Teams weiter. Jedes Teammitglied sollte sein eigenes Anbieterkonto oder einen vom Team verwalteten Schlüssel verwenden, je nachdem, wie der Anbieter Abrechnung und Zugriff handhabt.
  • Löschen Sie nicht mehr verwendete Schlüssel aus SubVox Pro. Verwenden Sie die Schaltfläche Clear API Keys unter Tools ▸ SubVox Pro ▸ Settings, wenn Sie die Tests auf einem gemeinsam genutzten Rechner abgeschlossen haben.

Kommerzielle Nutzung bedeutet, dass Sie das vom Anbieter Erzeugte — Untertitel, Übersetzungen oder vertonte Audiodateien — in einem von Ihnen verkauften Spiel oder Produkt verwenden. Für ein Spiel, das mit Stimmen von ElevenLabs oder Azure vertont wurde, ist der jeweilige kostenpflichtige Tarif erforderlich. Diese Spalte fasst die Bedingungen der einzelnen Anbieter mit Stand September 2026 zusammen; sie stellt keine Rechtsberatung dar, und es gelten stets die aktuellen Bedingungen des jeweiligen Anbieters. Die Offline-Engines (Whisper, Parakeet, Hy-MT2, Kokoro, Chatterbox, Qwen3, VoxCPM2) sind für die kommerzielle Nutzung kostenlos (die Nennung von NVIDIA als Quelle für Parakeet gilt als bewährte Praxis) — siehe Third-Party Notices.md.

Wo Sie Ihren Schlüssel in SubVox Pro einfügen

Sobald Sie einen Schlüssel von einem der unten aufgeführten Anbieter haben, bietet Ihnen SubVox Pro zwei gleichwertige Möglichkeiten, ihn zu speichern. Schlüssel werden ausschließlich auf diesem Rechner in den Einstellungen des Unity-Editors (EditorPrefs) gespeichert – niemals im Projekt.

Öffnen Sie Tools ▸ SubVox Pro ▸ Settings, um alle Anbieter in einer gemeinsamen Übersicht anzuzeigen. Fügen Sie jeden Schlüssel in die entsprechende Zeile ein (das Feld verbirgt den Wert) und nutzen Sie die Typkennzeichnungen – STT (Transkription), TR (Übersetzung), TTS (Synchronisation) –, um den passenden Anbieter zu finden. Clear API Keys löscht alle Schlüssel von diesem Rechner.

Sie können einen Schlüssel auch direkt im Anbieterbereich des SubVox Pro-Fensters einfügen. Geben Sie den Schlüssel ein, klicken Sie auf Save, und die Statusanzeige API Ready bestätigt, dass er akzeptiert wurde (Clear entfernt ihn).
