Synchronisation / Text-to-Speech

ElevenLabs TTS verwendet denselben oben dokumentierten ElevenLabs-Schlüssel. Falls Ihr Schlüssel eingeschränkt ist, muss er Text to Speech: Access enthalten. Um die Optionen zur Stimmklonung von ElevenLabs (Instant Voice Cloning, kostenpflichtiger ElevenLabs-Tarif) nutzen zu können, benötigt der Schlüssel zudem die Berechtigung Voices mit Schreibzugriff, damit SubVox Pro seine Klone erstellen, finden und löschen kann. Gemini TTS verwendet denselben Gemini-Schlüssel wie die Übersetzung (siehe Google (Gemini)): kein OAuth und kein Abrechnungskonto, im Gegensatz zu den Gemini-Stimmen von Google Cloud Text-to-Speech weiter unten. OpenAI TTS verwendet denselben OpenAI-Schlüssel wie die Übersetzung (siehe OpenAI). Die Anleitung zur Einrichtung von InWorld finden Sie weiter unten.

InWorld AI

Verwendungszweck: Erzeugen einer Sprachvertonung (TTS) für eine übersetzte Spur.

1 Rufen Sie Inworld Studio (https://studio.inworld.ai) auf und erstellen Sie ein Konto.

2 Öffnen Sie in Ihrem Arbeitsbereich über die linke Seitenleiste API Keys.

3 Klicken Sie auf Generate new key.

4 Geben Sie dem Schlüssel einen aussagekräftigen Anzeigenamen. Verwenden Sie Standard, sofern Sie nicht ausdrücklich einen ausschließlich für Echtzeitanwendungen vorgesehenen Schlüssel benötigen, und behalten Sie die für Ihren Inworld-TTS-Workflow erforderlichen Berechtigungen bei.

5 Kopieren Sie den Schlüsselwert Basic (Base64).

Der Schlüssel erscheint auch in der Liste API Keys, wo Sie ihn bei Bedarf später erneut kopieren können.

6 Fügen Sie ihn in SubVox Pro ein (Settings ▸ InWorld).

Der kostenlose Tarif umfasst ein einmaliges Kontingent von etwa 70 Minuten TTS und beinhaltet eine kommerzielle Lizenz. Sie können die Stimmen zunächst im TTS Playground anhören. Dokumentation für den Einstieg: https://docs.inworld.ai/docs/tts-api/getting-started/

Google Cloud Text-to-Speech

Verwendungszweck: Erzeugen einer Sprachvertonung (TTS) für eine übersetzte Spur. Zwei Stimmenfamilien nutzen dieselbe Verbindung: die klassischen Stimmen (Standard, WaveNet, Neural2, Chirp/Chirp3-HD) über die Cloud Text-to-Speech API und die Gemini-Stimmen (vordefinierte Namen wie Leda, Achird, Aoede), die mehrsprachig sind und eine frei formulierte Stilanweisung akzeptieren – diese laufen über die separate Vertex AI-API.

Im Gegensatz zu den anderen Anbietern verwendet Google Cloud TTS die OAuth-Anmeldung statt eines API-Schlüssels. Der Grund: Gemini- Stimmen laufen über Vertex AI, dessen Zugriff durch IAM geregelt wird (aiplatform.endpoints.predict); ein API-Schlüssel enthält keine IAM-Berechtigungen, Ihr angemeldetes Google-Konto hingegen schon (sofern es Eigentümer des Projekts ist oder dieses bearbeiten darf). Eine Anmeldung deckt beide Stimmenfamilien ab.

  1. Öffnen Sie die Google Cloud Console unter https://console.cloud.google.com und erstellen Sie ein Projekt (oder wählen Sie eines aus). Neue Konten erhalten 300 $ Testguthaben (90 Tage); ein Abrechnungskonto ist auch in der kostenlosen Stufe erforderlich.
  2. Aktivieren Sie unter APIs & Services ▸ Library die Cloud Text-to-Speech API (klassische Stimmen) und – für die Gemini-Stimmen – die Vertex AI API (aiplatform.googleapis.com, nicht die veraltete "AI Platform" ml.googleapis.com). Überspringen Sie Vertex AI, wenn Sie nur klassische Stimmen benötigen.
  3. APIs & Services ▸ OAuth consent screen: Stellen Sie User type / Audience auf External ein (Internal blockiert persönliche Gmail-Konten mit 403: org_internal) und fügen Sie Ihr Google-Konto unter Test users hinzu.
  4. APIs & Services ▸ Credentials ▸ Create credentials ▸ OAuth client ID, Anwendungstyp Desktop app. Kopieren Sie Client ID und Client secret. (Ein Desktop-Client ist für die Loopback-Anmeldung über http://127.0.0.1 erforderlich – genau wie bei der Google Sheets-Integration.)
  5. Öffnen Sie in SubVox Pro die Registerkarte Text-to-Speech, wählen Sie Google Cloud aus, fügen Sie Client ID und Client secret ein, klicken Sie dann auf Connect… und melden Sie sich im Browser an. Wählen Sie bei der Warnung "app not verified" (im Testmodus normal) Continue. (Das Abrechnungs-/Kontingentprojekt wird aus der Client-ID abgeleitet, sodass keine weiteren Angaben erforderlich sind.) Die Anmeldedaten und das Aktualisierungstoken bleiben auf diesem Rechner (Editor-Einstellungen) – niemals im Projekt.

Wählen Sie anschließend eine Stimme aus. Klassische Stimmen werden als Tier Leaf (locale) angezeigt (z. B. Neural2 A (fr-FR)); Gemini-Stimmen werden als Name · Gemini angezeigt und ignorieren den Sprachfilter (sie sprechen alle unterstützten Sprachen). Wenn eine Gemini-Stimme ausgewählt ist, wird die Schaltfläche voice direction (Sprechblase neben der Stimmenauswahl) aktiv – geben Sie eine Tonlage wie "sehr traurig, kurz vor einem psychischen Zusammenbruch" ein. Diese wird für jede Zeile als Gemini- Stilanweisung gesendet.

Hinweis zur Abrechnung: Klassische Stimmen nutzen das kostenlose monatliche Kontingent von Cloud Text-to-Speech (≈1 Mio. Zeichen für Neural2/WaveNet, 4 Mio. für Standard); Gemini- und Chirp-Stimmen werden über Vertex AI zu einem anderen Tarif abgerechnet. Richten Sie eine Budgetwarnung ein. TTS-Preise: https://cloud.google.com/text-to-speech/pricing

Azure AI Speech

Verwendungszweck: Erzeugen einer Sprachvertonung (TTS) für eine übersetzte Spur mit hochwertigen mehrsprachigen neuronalen Stimmen. Verwendet einen Abonnementschlüssel + Region (kein OAuth).

  1. Erstellen Sie ein Microsoft Azure-Konto unter https://azure.microsoft.com/free. Azure verlangt eine Kreditkarte zur Identitätsprüfung, doch die kostenlose Stufe (F0) für Speech ist eine tatsächlich kostenlose SKU (sie begrenzt die Nutzung, statt sie abzurechnen), sodass die Karte bei F0 nicht belastet wird.

  2. Klicken Sie im Azure Portal (https://portal.azure.com) auf Create a resource, suchen Sie nach Speech und wählen Sie die von Microsoft veröffentlichte Kachel mit dem Titel Speech aus (sie hat eine Schaltfläche Create – nicht die Marketplace-Angebote von Drittanbietern, bei denen Subscribe steht). Klicken Sie auf Create und wählen Sie dann Ihr Abonnement und Ihre Ressourcengruppe, eine Region (merken Sie sich diese), einen Namen und Pricing tier F0 (free) aus. Klicken Sie auf Review + create.

    Direkter Link zur richtigen Ressource: https://portal.azure.com/#create/Microsoft.CognitiveServicesSpeechServices

  3. Öffnen Sie nach Abschluss der Bereitstellung die Ressource und gehen Sie zu Keys and Endpoint. Kopieren Sie KEY 1 und notieren Sie sich die Location/Region (z. B. westeurope).

  4. Fügen Sie den Schlüssel in SubVox Pro ein (Settings ▸ Azure Speech). Wählen Sie dann auf der Registerkarte Text-to-Speech Azure und in der Dropdown-Liste die gleiche Region aus.

Der Schlüssel und die Region müssen zur gleichen Speech-Ressource gehören, andernfalls lehnt Azure die Anfrage mit einem 401 ab. Die Region ist die Kurzbezeichnung (westeurope, eastus…), die Sie aus der Dropdown-Liste auswählen – nicht der Anzeigename ("West Europe").

Kostenlose Stufe (F0): ~0,5 Mio. Zeichen/Monat für neuronale TTS, ausschließlich zu Evaluierungszwecken – Microsoft gewährt kommerzielle Rechte an den generierten Audiodateien nur bei einer kostenpflichtigen Ressource (S0). Stellen Sie die Ressource auf S0 um, bevor Sie ein Spiel vertonen, das Sie veröffentlichen. Preise: https://azure.microsoft.com/pricing/details/cognitive-services/speech-services/
