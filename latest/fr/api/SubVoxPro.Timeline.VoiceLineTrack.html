Piste Timeline qui synchronise les sous-titres avec l’horloge du director. L’audio est lu sur une Audio Track native créée automatiquement lorsque vous déposez la voiceline ; cette piste publie uniquement les sous-titres sur SubVox, pour les afficheurs. Le clip actif a la priorité sur l’affichage ; à sa fin, le sous-titre de l’émetteur retenu est réaffiché sans relancer l’audio.

[TrackColor(0.85, 0.55, 0.18)]
[TrackClipType(typeof(VoiceLineClip))]
