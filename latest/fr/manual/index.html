SubVox Pro

SubVox Pro transforme vos voicelines en sous-titres synchronisés et en doublages, directement dans Unity :

  • Transcrivez un clip audio en sous-titres datés, avec un service en ligne ou entièrement hors connexion.
  • Ajustez le timing sur une forme d’onde, stylisez les mots et vérifiez la vitesse de lecture.
  • Traduisez dans 37 langues et doublez par synthèse vocale, éventuellement avec la voix propre à chaque personnage.
  • Jouez le résultat en jeu avec quelques composants, déclenchez des événements de gameplay depuis une réplique et placez vos voicelines sur la Timeline Unity.

Les noms des boutons et des champs restent en anglais dans ce guide, comme dans l’interface Unity. Le guide et la référence d’API français sont disponibles en ligne ; les PDF inclus dans le plugin restent en anglais.

Avant de commencer

  • Unity 2022.3 LTS ou plus récent, y compris Unity 6, avec n’importe quel pipeline de rendu : Built-in, URP ou HDRP.
  • TextMesh Pro : importez TMP Essentials une fois si ce n’est pas déjà fait. Avec Unity 2022.3, installez d’abord le package TextMeshPro depuis le Package Manager. Unity 6 l’inclut déjà.
  • Unity Timeline est facultatif : les fonctions Timeline apparaissent dès que son package est installé.
  • En jeu, SubVox Pro fonctionne sur toutes les plateformes prises en charge par Unity.
  • Dans l’éditeur, les services en ligne fonctionnent sous Windows, macOS et Linux avec vos propres clés API. Les moteurs locaux de transcription, traduction et doublage sans compte nécessitent l’éditeur Windows.

Démarrage rapide

Passez d’un clip audio à des sous-titres synchronisés en quelques minutes.

Tools ▸ SubVox Pro ▸ Hub donne accès à tous les outils : éditeur de voicelines, traitement par lot, Google Sheets, comparaison des fournisseurs, modèles locaux supplémentaires, scène d’exemple, documentation, configuration des fournisseurs et réglages. L’accueil contient neuf tuiles.

La tuile Documentation ouvre un écran contenant uniquement Online et Local. Online ouvre le guide, la configuration des fournisseurs et la référence d’API, avec un choix anglais/français. Local ouvre le PDF anglais, disponible hors connexion. Back revient à l’accueil. La tuile Provider Setup ouvre le PDF anglais consacré aux fournisseurs.

1. Choisissez comment transcrire. Collez la clé API d’un service de transcription dans Tools ▸ SubVox Pro ▸ Settings (obtenir une clé), ou utilisez sous Windows Whisper ou Parakeet, gratuits et hors connexion. Ils proposent de télécharger leur modèle à la première utilisation.

2. Créez une voiceline. Assets ▸ Create ▸ SubVox Pro ▸ Voice Line, puis sélectionnez l’asset et cliquez sur Setup Voiceline dans l’Inspector. Vérifiez Language : anglais à la première utilisation, puis votre dernier choix. Cliquez sur Add an audio track pour choisir un clip ou en enregistrer un.

3. Transcrivez. Dans AI Tools ▸ Transcription, choisissez le fournisseur et la langue parlée, cliquez sur Analyze, puis sur Split. Les sous-titres apparaissent sur la forme d’onde.

4. Ajustez. Déplacez les marqueurs, corrigez le texte dans la liste et appuyez sur Space pour écouter.

5. Affichez le résultat en jeu. Placez les prefabs [SubVox Pro] et Subtitle Displayer (SubVoxPro/Prefabs) dans votre scène, puis jouez la réplique :

using SubVoxPro;

SubVox.Play(myVoiceLine);

Pour voir un exemple fonctionnel, ouvrez Tools ▸ SubVox Pro ▸ Open Example Scene et appuyez sur Play. La scène montre des voicelines, une séquence de dialogue, le changement de langue et l’apparition mot par mot.

La fenêtre SubVox Pro

Ouvrez-la avec Tools ▸ SubVox Pro ▸ Voiceline Setup ou Setup Voiceline dans l’Inspector d’une voiceline. De haut en bas :

  • Voice Line Data : la voiceline en cours, avec les boutons pour en créer une, parcourir les autres ou la supprimer. Le point coloré est un tag, également visible sur son icône dans la fenêtre Project.
  • Source : les sélecteurs AUDIO et SUBTITLES. Chaque voiceline a une langue source, représentée par un drapeau, et une piste par langue traduite ou doublée. Les sélecteurs sont indépendants : vous pouvez lire les sous-titres français tout en écoutant l’audio anglais.
  • AI Tools : transcription, traduction et doublage (voir ci-dessous).
  • Timeline : la forme d’onde et les marqueurs de sous-titres. Chaque marqueur indique le début d’un sous-titre ; un marqueur sans texte efface l’affichage, c’est un blank.
  • Live preview : le sous-titre à la position de lecture, tel qu’il apparaîtra en jeu. Choisissez une couleur ou un style, puis glissez sur les mots pour les appliquer. Le glissement avec le bouton droit les efface.
  • Subtitles : une ligne par sous-titre, avec son nom, sa durée, son speaker, son texte et un bouton de lecture.

Tags et langues

Cliquez sur le tag à côté de Voice Line Data pour choisir sa couleur et sa forme. Clear tag le retire. La forme permet de distinguer les voicelines sans dépendre uniquement de la couleur.

Cliquez sur le drapeau source pour choisir la langue parlée. Les drapeaux représentent des langues, pas la nationalité des personnages. Le sélecteur indique aussi le nom de chaque langue et son code.

Commencer sans audio

Une voiceline peut commencer par du texte. Choisissez Add a subtitles track, puis importez un .srt avec ses timings, un .txt avec un sous-titre par ligne, ou saisissez les lignes vous-même. Pour le TXT, les durées sont calculées automatiquement pour une vitesse de lecture confortable. Réglez Length : la voiceline jouera pendant cette durée jusqu’à l’ajout d’audio ou la génération d’un doublage.

Enregistrer de l’audio

Record with a microphone, dans Add an audio track ou dans le + du sélecteur AUDIO, ouvre un enregistreur. Choisissez le microphone, surveillez le niveau, enregistrez, réécoutez, puis cliquez sur Use recording. La prise est enregistrée en WAV à côté de la voiceline. Sur macOS, autorisez Unity à utiliser le microphone dans les Réglages Système.

Vérifier vos sous-titres

  • Show CPS, dans les réglages, affiche la vitesse de lecture et signale les lignes trop rapides.
  • Validate parcourt les problèmes un à un : noms vides ou en double, lignes hors du clip, chevauchements, texte trop rapide. Les corrections proposées peuvent toutes être annulées.
  • Auto blanks masque le texte quand personne ne parle, sans ajouter de marqueurs. Activez-le dans son popup et choisissez la durée minimale du silence. Les parties masquées sont ombrées sur la forme d’onde.
  • Export SRT enregistre les sous-titres dans un fichier .srt.

Silence définit à quel point une pause doit être plus faible que la voix. Min pause ignore les silences trop courts. Hold out conserve brièvement le texte après l’arrêt de la voix, et Lead in le fait réapparaître avant la reprise. Only between two lines évite de masquer puis de réafficher un sous-titre au milieu de sa phrase.

Supprimer une voiceline

Le bouton corbeille liste les fichiers associés à la voiceline. Les fichiers générés par SubVox Pro, comme les doublages et les enregistrements, sont cochés ; vos fichiers d’origine ne le sont pas. Un fichier encore utilisé ailleurs est verrouillé. La suppression utilise la corbeille système et reste récupérable.

Transcrire

  1. Choisissez un Provider et, s’il en propose plusieurs, un Model. Le badge indique si le fournisseur est prêt : clé enregistrée ou modèle téléchargé.
  2. Réglez Audio Language. Certains fournisseurs détectent eux-mêmes la langue.
  3. Cliquez sur Analyze pour obtenir les mots et leurs timings.
  4. Cliquez sur Split pour regrouper les mots en sous-titres. Split settings règle la durée maximale, l’avance avant le premier mot et la coupure sur la ponctuation.

Word timing choisit l’origine du timing de chaque mot. From the provider, par défaut, conserve celui de la transcription. Qwen3 local recale chaque mot sur l’audio après Split, sans modifier le texte : c’est le choix le plus précis pour l’affichage mot par mot (installation). Si Qwen3 ne prend pas la langue en charge, les timings du fournisseur sont conservés.

Fournisseurs : AssemblyAI, Gladia, Deepgram, Speechmatics, ElevenLabs, Rev AI, OpenAI, ou Whisper et Parakeet hors connexion. Tools ▸ SubVox Pro ▸ Provider Comparison compare prix, offre gratuite, utilisation commerciale et langues.

Avec OpenAI, choisissez whisper-1 lorsque le timing compte. Les autres modèles OpenAI fournissent un très bon texte, mais sans timings de mots : ceux-ci sont répartis de façon estimée sur l’audio.

La transcription utilise la piste du sélecteur AUDIO : vous pouvez donc également transcrire un doublage.

Traduire

  1. Choisissez un Provider : DeepL, Google Translate, OpenAI, Claude, Gemini, DeepSeek ou Hy-MT2 local.
  2. Choisissez une langue Target, ou un preset pour traduire vers plusieurs langues à la fois.
  3. Réglez Formality, par exemple tutoiement ou vouvoiement, si la langue le permet.
  4. Cliquez sur Translate. Chaque langue reçoit sa propre piste dans le sélecteur SUBTITLES.

Dans le popup Target, + New crée un groupe. La colonne de droite choisit ses langues. Sélectionner ce preset traduit vers toutes ses langues en une seule opération.

Donnez du contexte. Pour une phrase ambiguë, écrivez un contexte global avec le bouton bulle de la voiceline et, si nécessaire, une note sur une ligne avec son bouton bulle dans la liste.

Gardez les traductions à jour. Après une modification du texte source, les traductions affichent OUT. Synchronize ne retraduit que les lignes modifiées ; cliquez sur le badge si vous avez vérifié la ligne vous-même. Si vous déplacez les marqueurs et coupez autrement une phrase, le badge CUT apparaît. Fix splits demande à un fournisseur IA de recouper la traduction au même sens, sans changer ses mots. Les doublages suivent automatiquement.

Doubler par synthèse vocale

  1. Sélectionnez la langue à doubler dans SUBTITLES.
  2. Dans AI Tools ▸ Dubbing, choisissez un Provider et une Voice. Le bouton ▶ lit un exemple de voix. Use speakers' voices utilise la voix propre au speaker de chaque ligne.
  3. Choisissez Generation :
    • Each subtitle : une prise par sous-titre, facile à corriger ligne par ligne.
    • Per speaker : une prise par groupe de lignes du même personnage, avec un enchaînement plus naturel.
    • All together : une prise continue, la plus fluide, mais tout est régénéré ensemble.
  4. Cliquez sur Generate audio. Une nouvelle piste audio est jouée à la place de l’original quand cette langue est active.

Fournisseurs : InWorld, ElevenLabs, Gemini, OpenAI, Google Cloud, Azure, et les moteurs locaux Kokoro, en anglais, et Chatterbox, dans 21 langues et avec conservation de la voix du personnage.

  • Word timing : Qwen3 local affiche les mots au moment exact où ils sont prononcés (installation). Utilisez Estimated si vous n’affichez pas les mots un à un.
  • Voice direction : le bouton bulle à côté de la voix donne une indication de jeu, comme calm, whispering, aux fournisseurs qui la comprennent.
  • REGEN : un badge orange signale que le doublage ne correspond plus au texte, à la voix ou à la personnalité. Survolez-le pour connaître la raison ; cliquez dessus pour régénérer uniquement ce qui est nécessaire.
  • Voice cloning : avec ElevenLabs, sur une offre payante, ou Chatterbox, Original voice conserve la voix de chaque personnage à partir de l’audio source. Vous pouvez aussi utiliser un clip du dossier Voices de votre dossier de données. Ne clonez que les voix que vous avez le droit d’utiliser.

OpenAI et certains services demandent d’indiquer aux joueurs que les voix sont générées par IA. Consultez le guide des fournisseurs.

Speakers et personnalités vocales

Speakers

Un speaker représente un personnage : son nom peut précéder ses sous-titres, avec sa couleur, et il définit ses voix de doublage. Créez-le avec Assets ▸ Create ▸ SubVox Pro ▸ Speaker ou depuis le sélecteur de speaker.

  • Le champ Speaker au-dessus de la liste s’applique à toute la voiceline. Celui d’une ligne ne concerne que ce sous-titre.
  • Text-to-speech voices, dans son Inspector, choisit la voix par fournisseur : un choix de repli pour toutes les langues et, au besoin, des exceptions par langue.
  • Sur Subtitle Displayer ou Subtitle Document Displayer, Speaker Name Mode place le nom devant le texte (Inline), au-dessus (Above) ou le masque (Hidden). Un speaker peut aussi définir sa propre police : Font (TextMeshPro) ou Font (UI Toolkit) selon l’afficheur.
  • Keep Background Between Subtitles, activé par défaut, conserve uniquement le panneau pendant un blank entre deux sous-titres. Un blank avant le premier ou après le dernier masque toujours le panneau.

Le sélecteur regroupe les personnages par genre. Le crayon modifie un speaker existant ; New speaker en crée un. Pour une exception sur une ligne, l’entrée du haut rétablit le speaker par défaut de la voiceline.

Personnalités vocales

Une personnalité est une direction de jeu réutilisable, comme Angry, Mysterious ou Whispering. Créez-la depuis un speaker avec New personality ou avec Assets ▸ Create ▸ SubVox Pro ▸ Voice Personality. Vous pouvez écrire la direction ou combiner émotion, vitesse, volume et manière de parler.

Choisissez une personnalité avec le badge d’une ligne, en mode Each subtitle, ou utilisez celle du speaker. Chaque fournisseur applique les indications qu’il comprend : toute la direction pour certains, seulement la vitesse pour d’autres. Le survol du badge explique ce que la voix choisie utilisera.

Modifier l’audio

Les boutons à droite de la barre Timeline modifient l’audio lui-même. Chaque modification peut être annulée avec Ctrl+Z.

Audio effects ouvre la liste des effets. Les effets appliqués apparaissent en premier : sélectionnez-en un pour le modifier, ou cliquez sur sa croix pour le réinitialiser et le retirer.

  • Crop : déplacez les poignées de début et de fin, puis cliquez sur Apply crop. Cette opération réécrit le fichier audio source : gardez une copie de la prise complète si vous pourriez en avoir besoin.
  • Insérer une pause ou retirer un passage, bouton |↔| : glissez avec le bouton gauche pour ajouter du silence, avec le bouton droit pour couper. Les sous-titres, mots et événements suivants se déplacent avec l’audio. C’est utile lorsqu’une voix TTS enchaîne trop vite deux phrases.
  • Audio effects : courbe de volume, fondus, normalisation, compresseur, limiteur, noise gate, filtres, égaliseur, téléphone/radio, hauteur, intonation, panoramique, étouffement à distance et réverbération. Dessinez où appliquer l’effet, réglez comment avec les curseurs, puis cliquez sur Apply effects. L’aimant aligne les points sur la valeur de base, zéro et leurs voisins ; maintenez Alt pour les placer librement. L’original est conservé pour garder les effets modifiables. Flatten les rend définitifs, Discard les retire tous.
  • Intonation : la mélodie de la voix apparaît au-dessus. Dessinez dans la piste du bas le décalage positif ou négatif ; 0 conserve la voix. L’aimant suit le pas choisi, 0,5 st par défaut ; Alt permet un tracé libre. Le bouton vague lisse les nouveaux gestes sur la durée choisie ; zéro conserve le tracé exact. Le bouton droit rétablit la voix et Esc annule le geste. Les autres passages restent inchangés. Pitch décale tout un passage et montre la même mélodie. Quelques demi-tons, st, donnent généralement le meilleur résultat. Engine propose WORLD, naturel et par défaut, PSOLA, plus léger, et Classic, le plus rapide mais qui change aussi le timbre.

La courbe réduit ici le volume de certains passages. La forme d’onde conserve un repère temporel et les points règlent le gain. 0 dB conserve le volume original.

La courbe supérieure montre la mélodie détectée. La piste inférieure contient votre modification en demi-tons : une valeur positive monte la voix, une valeur négative la baisse et zéro garde l’original. Les deux restent séparées pour distinguer la voix initiale de vos changements.

Jouer des voicelines dans votre jeu

Préparer la scène

  1. Placez le prefab [SubVox Pro], dans SubVoxPro/Prefabs, une fois dans votre scène de démarrage. Il joue les voicelines et distribue leurs événements. Si vous l’oubliez, un lecteur par défaut est créé à la première lecture, avec un avertissement.

  2. Placez le prefab Subtitle Displayer : un panneau de sous-titres prêt à l’emploi en bas de l’écran, qui grandit avec les longues lignes et se masque entre elles. Adaptez police, couleur, position et taille, ou ajoutez le composant à votre Canvas et renseignez Subtitle Text, ainsi que Background pour masquer le fond.

    Avec UI Toolkit plutôt qu’un Canvas, utilisez le prefab Subtitle Document Displayer. Il affiche les mêmes textes, noms et styles dans un UI Document. Modifiez Subtitle Document.uss, dans SubVoxPro/Prefabs/UI Toolkit, ou ajoutez le composant à votre propre UI Document et indiquez le nom du Label à remplir et de l’élément à masquer.

Jouer une réplique depuis un script

Tout passe par SubVox. Les scripts prêts à copier sont dans SubVoxPro/Example/Snippets : attendre une réplique, réagir à un événement, changer de langue, proposer des options, afficher un historique, sous-titrer une vidéo. L’éditeur de code décrit chaque classe, méthode et réglage pendant la saisie. La référence complète est en ligne, avec une page par version, accessible aussi par Documentation ▸ Online dans le Hub.

using SubVoxPro;

SubVox.Play(myVoiceLine);            // lecture avec sous-titres synchronisés
SubVox.PauseAll();                   // jeu en pause
SubVox.ResumeAll();
SubVox.StopAll();                    // cinématique passée
SubVox.CurrentLanguage = "fr";       // sous-titres et doublages français, "" pour la source

Play renvoie la lecture de la réplique. Consultez son State, arrêtez-la ou attendez-la dans une coroutine :

yield return SubVox.Play(greeting);
yield return SubVox.Play(answer);

Sur Voice Line Manager, Subtitle Reveal Mode affiche la ligne entière, par défaut, les mots un à un ou le mode Karaoke, avec le mot prononcé en surbrillance. Les cinématiques Timeline le suivent aussi. Pour baisser la musique pendant la parole, renseignez deux snapshots d’Audio Mixer : Ducked Snapshot, musique baissée, et Normal Snapshot.

Voix en 3D et lectures simultanées

Ajoutez Voice Line Emitter à chaque personnage et réglez son AudioSource en 3D. Le son vient du personnage ; plusieurs personnages peuvent parler en même temps.

npc.GetComponent<VoiceLineEmitter>().Play(barkLine, EVoiceLinePriority.Low);

Les priorités protègent les répliques importantes. Sur un émetteur, une nouvelle réplique ne remplace la réplique actuelle que si elle est au moins aussi importante. À l’écran, le sous-titre de la plus importante gagne. EVoiceLinePlayMode.Queue attend le tour de la réplique ; EVoiceLinePlayMode.IfIdle ne joue que si l’émetteur est libre. Skip() termine immédiatement la réplique. Désactivez Show Subtitles pour les conversations de fond. VoiceLineCompleted et VoiceLineInterrupted signalent la fin ou l’interruption d’une lecture.

Bulles de dialogue. Sélectionnez un personnage et utilisez GameObject ▸ SubVox Pro ▸ Subtitle Bubble. Une bulle au-dessus de sa tête affiche uniquement ses répliques. Désactivez Show Subtitles sur son émetteur pour éviter de les afficher également en bas de l’écran.

Sans code

  • Voice Line Zone joue une réplique lorsque le joueur entre dans un trigger 2D ou 3D, une fois ou avec un délai de réutilisation. Play mode: Queue peut attendre la fin de la réplique actuelle. Le composant peut arrêter la réplique à la sortie du joueur et la rejouer à son retour.
  • Voice Line Play On Start joue une réplique au démarrage de l’objet, après un délai facultatif.
  • Voice Line Bank, dans Assets ▸ Create ▸ SubVox Pro ▸ Voice Line Bank, regroupe des répliques à choisir aléatoirement sans répétition immédiate, en mélangeant toutes les lignes, ou dans l’ordre. Placez la banque dans le champ Bank d’une zone ou de Play On Start.
  • Voice Line Sequence, dans Assets ▸ Create ▸ SubVox Pro ▸ Voice Line Sequence, définit un dialogue. Les répliques s’enchaînent automatiquement ou avec Advance() ; Previous() revient à la précédente. Jouez-la avec Voice Line Sequence Player, dont l’Inspector montre la progression en Play mode. Direction: Backward va de la dernière à la première. Si le personnage joue une réplique plus importante, la séquence attend, puis reprend après Resume Delay.

Chaque composant a un Emitter, vide pour utiliser celui par défaut, une Priority et une méthode Play() publique, utilisable depuis un bouton ou un UnityEvent.

Changer de langue

Le changement de langue remplace immédiatement les sous-titres affichés. Le doublage change à la réplique suivante, pour ne pas changer de langue au milieu d’une phrase.

  • Unity Localization : SubVox Pro suit automatiquement la langue de ce package s’il est installé. Pour gérer la langue vous-même, réglez Language Source sur Manual dans Voice Line Manager.
  • Langues proches : en l’absence de pt-BR, un joueur reçoit la traduction pt, et réciproquement.
  • Menu de langues : myVoiceLine.GetSubtitleLanguages() et GetAudioLanguages() listent les langues disponibles.

Options de sous-titres pour les joueurs

Reliez ces réglages à votre menu d’options. Tous les afficheurs les suivent immédiatement :

SubVox.SubtitlesEnabled = false;       // masquer les sous-titres sans arrêter les voix
SubVox.SubtitleScale = 1.5f;           // agrandir le texte
SubVox.BackgroundOpacity = 1f;         // fond opaque
SubVox.FadeDuration = 0.2f;            // durée des fondus
SubVox.RevealMode = EVoiceLineSubtitleRevealMode.Karaoke;

SubVox.History conserve les dernières lignes affichées, avec leur texte et leur speaker, pour votre historique.

Votre propre afficheur

Pour afficher autrement les sous-titres, abonnez-vous à SubVox.SubtitleUpdated. Cet événement donne le texte à chaque changement ; un texte vide signifie « effacer l’écran ». Lisez SubVox.CurrentSubtitle juste après l’abonnement pour récupérer une réplique déjà en cours. Les afficheurs intégrés le font à leur activation ou réactivation. Une bulle lit plutôt le sous-titre de son propre émetteur.

SubVox.DisplayedVoiceLine donne la voiceline choisie pour l’affichage global, y compris un clip Timeline. SubVox.PublishSubtitle(...) affiche votre propre texte, par exemple pour une vidéo. Ces publications sont ignorées pendant un clip SubVox Timeline actif, car ce clip possède l’affichage.

Pour adapter seulement un afficheur, dérivez votre script de sa classe et redéfinissez ComposeText ou SetVisible. Les autres composants peuvent être étendus de la même manière.

Lire l’audio avec FMOD, Wwise ou une vidéo

Importez l’audio et les doublages dans votre outil audio, puis faites suivre sa lecture par l’émetteur :

class FmodClock : IVoiceLineAudioClock
{
    public FMOD.Studio.EventInstance Instance;

    public float Time { get { Instance.getTimelinePosition(out int ms); return ms / 1000f; } }
    public bool IsPlaying { get { Instance.getPlaybackState(out var state); return state != FMOD.Studio.PLAYBACK_STATE.STOPPED; } }
}

emitter.PlayExternal(myVoiceLine, clock);
// démarrer ensuite l’audio d’emitter.CurrentAudioLanguage, "" pour la source

Mettre en pause ou arrêter l’émetteur ne touche qu’aux sous-titres et aux événements. Faites de même dans votre outil audio.

Déclencher du gameplay depuis une voiceline

Ouvrir une porte sur « Run! », secouer la caméra sur un cri : les événements se déclenchent à un instant précis.

  1. Passez la timeline en mode Events et cliquez sur + Event, ou faites un clic central sur la forme d’onde.
  2. Donnez-lui un signal, un petit asset réutilisable qui nomme l’événement, comme Camera Shake.
  3. Choisissez son déclenchement : début ou fin de la voix, temps précis, sous-titre ou mot. Dans ce dernier cas, il suit le mot si son timing change. Déplacez le diamant pour le recaler.

Trois façons d’y réagir :

  • Sans code : ajoutez Voice Line Event Receiver, choisissez le signal et raccordez un UnityEvent.

  • Avec un attribut : marquez une méthode de MonoBehaviour avec la constante générée, copiée depuis l’Inspector :

    [VoiceLineEvent(SubVoxEvents.CAMERA_SHAKE)]
private void Shake()
{
    // ...
}

    La Category facultative utilise / pour les niveaux, par exemple Camera/Effects produit SubVoxEvents.Camera.Effects.CAMERA_SHAKE. Les constantes se régénèrent à l’enregistrement, à la création, au renommage et à la suppression des signaux. Un renommage laisse volontairement les anciennes références en erreur de compilation pour vous permettre de les corriger. Les clés texte comme [VoiceLineEvent("Camera Shake")] restent prises en charge.

    [SubVox Pro] trouve automatiquement ces méthodes. Après une création d’objet à l’exécution, appelez VoiceLineEventDispatcher.Refresh().

  • En C# : SubVox.Subscribe(signal, MyMethod) appelle votre méthode à chaque signal. SubVox.Unsubscribe retire l’abonnement.

Un événement peut transporter un Payload, un asset transmis à la méthode qui accepte son type en paramètre, et être limité à une fois par lecture. Les événements ne s’exécutent qu’en Play mode, jamais pendant l’édition ou le déplacement manuel de la tête de lecture.

Timeline Unity

  1. Dans la Timeline Unity, choisissez Add ▸ VoiceLine Track.
  2. Glissez une voiceline sur la piste. Un clip de sous-titres apparaît avec son audio sur une piste séparée VoiceLine Audio.
  3. Reliez cette piste audio à un AudioSource, comme une Audio Track normale.
  4. Ajoutez un Subtitle Displayer à la scène, le plus vite avec son prefab.

Audio et sous-titres restent synchronisés, même pendant le déplacement manuel de la tête de lecture. Glisser une Voice Line Sequence dispose toutes ses répliques. Les événements jouent avec la voiceline. Pour les déplacer comme des marqueurs Timeline, faites un clic droit sur le clip puis SubVox Pro ▸ Bake Voice Events to Timeline.

La cinématique utilise le doublage de la langue active s’il existe. La langue est choisie au lancement de la Timeline. Le clip suit Subtitle Reveal Mode, sauf si vous cochez son Override Reveal Mode.

Un clip SubVox actif est prioritaire sur l’affichage global. Les autres voicelines continuent à jouer, mais leurs sous-titres ne peuvent pas remplacer ceux du clip, même pendant un blank ou avant son premier sous-titre. Les blanks intérieurs suivent normalement Keep Background Between Subtitles.

À la fin du clip ou à l’arrêt du director, l’affichage revient immédiatement à l’émetteur actif le plus prioritaire, à sa position actuelle, sans redémarrer son audio. Si aucun émetteur ne joue, le panneau se masque. Lorsque plusieurs pistes ou directors SubVox se chevauchent, le dernier clip entré possède l’affichage. La fin d’un autre clip ne l’efface pas. Mettre le director en pause conserve son sous-titre jusqu’à la reprise ou à l’arrêt.

Traiter plusieurs fichiers à la fois

Tools ▸ SubVox Pro ▸ Batch Processing transforme plusieurs fichiers audio ou .srt en voicelines.

  1. Glissez les fichiers, ou utilisez Add files… ou Add folder….
  2. Activez Transcription, Translation et Dubbing selon vos besoins. Réglez-les une fois pour tout le lot ; chaque fichier peut avoir ses propres langues.
  3. Vérifiez Estimated cost, puis cliquez sur Batch. Le bouton reste grisé et explique ce qui manque tant que le lot n’est pas prêt.

Chaque fichier devient une voiceline. Le lot effectue une étape pour tous les fichiers avant de passer à la suivante, par exemple toutes les transcriptions puis toutes les traductions. Cela accélère les moteurs locaux. Vous pouvez annuler et exporter un rapport ; relancer Batch reprend chaque fichier à son point d’arrêt.

Chatterbox, doublage local dans 21 langues

  • 24 voix fournies, 12 féminines et 12 masculines, téléchargées avec le modèle.
  • Chatterbox default voice.

Certaines langues sont plus fiables que d’autres : précision par langue.

Qwen3, timing local des mots

Choisissez Word timing: Qwen3 local dans Transcription ou Dubbing et cliquez sur Install…. Ensuite, chaque Split et chaque doublage sont automatiquement alignés mot par mot. Langues : chinois, cantonais, anglais, français, allemand, italien, japonais, coréen, portugais, russe et espagnol, sur des audios jusqu’à 5 minutes.

Traduction humaine avec Google Sheets

Partagez vos lignes avec des traducteurs dans une feuille Google Sheets, puis récupérez leur travail.

Configuration initiale

  1. Dans Google Cloud, sur https://console.cloud.google.com, créez un projet et activez Google Sheets API. Dans OAuth consent screen, choisissez External et ajoutez vous-même et les traducteurs aux Test users. Créez un OAuth client ID de type Desktop app, puis copiez Client ID et Client secret.
  2. Créez une feuille Google Sheets vide. Copiez son ID dans l’URL, entre /d/ et /edit, et partagez-la avec les traducteurs avec le rôle Editor.
  3. Dans Unity, ouvrez Tools ▸ SubVox Pro ▸ Google Sheets Localization, collez les trois valeurs, cliquez sur Connect, puis connectez-vous dans le navigateur.

Utilisation quotidienne

Les traducteurs remplissent les colonnes de langues et marquent les lignes reviewed ou final. Sync with Sheet montre chaque différence entre Unity et la feuille. Vous choisissez quoi conserver avant toute écriture. Les colonnes de clés sont verrouillées : seules les traductions peuvent être modifiées. reviewed apparaît en ambre et final en vert ; les traductions vides sont teintées. Chaque voiceline a une ligne de titre sombre. Le + / − dans la marge gauche replie ou déplie ses lignes.

Une ligne créée uniquement dans la feuille n’est pas importée, car il lui manque un timing, et n’est jamais supprimée sans confirmation. Duplicate, une ligne en double, et Removed, une ligne supprimée dans Unity, ont Drop comme choix par défaut pour les nettoyer en une synchronisation. Keep conserve une ligne dans la feuille. Le bouton à côté de Spreadsheet ID ouvre la feuille dans le navigateur.

Réglages

Dans Tools ▸ SubVox Pro ▸ Settings :

  • API Keys : une clé par service, stockée uniquement sur cet ordinateur, jamais dans le projet ou le build. L’œil affiche ou masque une clé ; la croix rouge la retire.
  • Preferences : Show CPS, Custom inspectors et Auto blanks on new lines.
  • Data folder : destination des nouvelles voicelines, speakers et doublages.
  • Model catalog : catalogue de modèles IA mis à jour en ligne. Manage models ajoute un modèle absent.
  • Local models & services : état Ready ou Not installed, options comme le GPU et l’expressivité Chatterbox, installation ou configuration, et nettoyage des clones ElevenLabs.

Dépannage

  • Un moteur local ne charge pas et indique une DLL manquante : installez le dernier Microsoft Visual C++ Redistributable x64, puis redémarrez Unity.
  • Un téléchargement s’est arrêté : une recompilation ou le passage en Play mode l’a interrompu. Rouvrez la même fenêtre pour reprendre.
  • Gemini ralentit ou arrête le doublage : l’offre gratuite limite les requêtes par minute et par jour. SubVox Pro attend et réessaie. Per speaker et All together envoient moins de requêtes. Activer la facturation du projet Google augmente les limites.
  • Aucun microphone sur macOS : autorisez Unity dans Réglages Système ▸ Confidentialité et sécurité ▸ Microphone.
  • Aucun sous-titre en jeu : vérifiez qu’un Subtitle Displayer est présent, que son texte est assigné et que Show Subtitles est activé sur l’émetteur qui joue la voiceline.
