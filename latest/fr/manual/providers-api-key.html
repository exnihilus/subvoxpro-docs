Après l’enregistrement d’une clé

Le panneau affiche API Ready lorsqu’une clé valide est détectée. Si un appel échoue, vérifiez que la clé a été copiée en entier, qu’il reste du crédit ou du quota sur le compte, et que votre machine a accès au réseau. Clear API Keys, dans Tools ▸ SubVox Pro ▸ Settings, efface toutes les clés enregistrées sur cet ordinateur.
