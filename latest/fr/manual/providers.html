SubVox Pro : configuration des fournisseurs

SubVox Pro n’inclut aucune clé API. Chaque service utilise votre propre clé, à coller dans Tools ▸ SubVox Pro ▸ Settings ou dans le panneau du fournisseur de la fenêtre SubVox Pro. Les clés sont enregistrées uniquement dans les préférences Unity de votre ordinateur, EditorPrefs, jamais dans le projet, ses commits ou ses builds. Les mentions des tiers détaillent les conditions.

Les offres gratuites et les tarifs changent régulièrement. Les chiffres ci-dessous reprennent le guide anglais et ses conditions de septembre 2026. Vérifiez toujours l’offre actuelle sur le site du fournisseur. Les noms des boutons restent ceux de leurs interfaces afin de faciliter le suivi des captures.

Bonnes pratiques

Une clé API est un mot de passe de service en ligne. Traitez-la comme un secret, même pour un test.

  • Une clé par outil ou projet facilite sa révocation sans casser les autres outils.
  • Ne collez jamais de clé dans un script, une scène, un prefab, un message de support, Discord, une issue GitHub ou un commit. SubVox Pro la stocke dans EditorPrefs, uniquement sur votre machine.
  • Copiez immédiatement les clés affichées une seule fois. Sauvegardez-les dans un gestionnaire de mots de passe si nécessaire. Si vous perdez une clé, révoquez-la et créez-en une autre.
  • Limitez les permissions aux fonctions nécessaires : STT pour la transcription, traduction, TTS pour le doublage.
  • Choisissez une expiration adaptée. Courte pour des tests, plus longue pour la production. Certains services autorisent les clés sans expiration.
  • Fixez un budget, un quota ou une alerte de facturation, si le service le permet, pour prévenir les boucles accidentelles et les imports répétés.
  • Remplacez une clé potentiellement exposée dans une capture, un commit, un message ou un build. Révoquez-la sur le site du service, puis enregistrez sa remplaçante dans SubVox Pro.
  • Ne partagez pas une clé personnelle dans l’équipe. Utilisez des comptes individuels ou une clé gérée par l’équipe selon les possibilités du service.
  • Effacez les clés inutilisées avec Clear API Keys dans Settings, notamment après un test sur une machine partagée.

Où coller votre clé dans SubVox Pro

Deux emplacements équivalents enregistrent la clé dans EditorPrefs, sur cet ordinateur seulement. Tools ▸ SubVox Pro ▸ Settings réunit tous les fournisseurs. Collez chaque clé dans sa ligne ; le champ masque sa valeur. STT, TR et TTS indiquent transcription, traduction et doublage. Clear API Keys les efface toutes.

Vous pouvez aussi ouvrir le panneau du fournisseur dans la fenêtre SubVox Pro, saisir la clé et cliquer sur Save. Le badge API Ready confirme l’enregistrement ; Clear la retire.

Fournisseurs de transcription

AssemblyAI

Utilisé pour : transcription avec timing par mot.

  1. Créez un compte, email ou SSO, sur https://www.assemblyai.com/dashboard/signup. Sans carte bancaire, environ 50 $ de crédits, soit 330 heures.
  2. Après vérification de l’email, ouvrez Manage ▸ API Keys.
  3. Copiez la Default API Key, ou cliquez sur Create new API key pour une clé dédiée.
  4. Nommez la nouvelle clé, par exemple SubVoxPro, puis cliquez sur Create.
  5. Copiez la clé dans sa ligne.
  6. Collez-la dans Settings ▸ AssemblyAI.

L’offre gratuite limite à deux projets et deux clés. Aide officielle.

Gladia

Utilisé pour : transcription.

  1. Inscrivez-vous sur https://app.gladia.io, avec email ou Google.
  2. Ouvrez API Keys dans la barre latérale.
  3. Créez au besoin une clé dédiée, avec un nom reconnaissable comme SubVoxPro. Copiez immédiatement sa valeur complète : la liste peut ensuite n’en afficher qu’une partie.
  4. Collez-la dans Settings ▸ Gladia.

Gratuit : 10 h/mois, au maximum 20 appels/heure et 3 simultanés. Aide.

Deepgram

Utilisé pour : transcription.

  1. Créez un compte sur https://console.deepgram.com/signup, sans carte bancaire. Le crédit de 200 $ expire un an après l’inscription.
  2. Ouvrez API Keys dans la console.
  3. Cliquez sur Create a New API Key.
  4. Nommez la clé et choisissez une expiration adaptée avec Set expiration. SubVox Pro n’impose pas de durée.
  5. Copiez le secret et conservez-le en lieu sûr : Deepgram ne peut plus le montrer ensuite.
  6. Collez-le dans Settings ▸ Deepgram.
Speechmatics

Utilisé pour : transcription.

  1. Créez un compte sur https://portal.speechmatics.com. Crédit gratuit unique de 100 $, sans carte.
  2. Ouvrez Manage ▸ API Keys dans le projet.
  3. Cliquez sur Create new key.
  4. Nommez-la puis cliquez sur Generate new key.
  5. Copiez la clé avant de fermer : elle ne sera plus affichée.
  6. Collez-la dans Settings ▸ Speechmatics.

Documentation d’authentification.

ElevenLabs

Utilisé pour : transcription Scribe et doublage TTS.

  1. Inscrivez-vous sur https://elevenlabs.io, email ou SSO, sans carte. Le quota gratuit est d’environ 10 minutes par mois, non commercial, avec attribution obligatoire. Un jeu publié nécessite une offre payante.
  2. Ouvrez Developers, qui regroupe API, journaux, webhooks et variables d’environnement.
  3. Ouvrez API Keys puis Create Key.
  4. Nommez la clé. Avec Restrict Key, mettez Speech to Text et Text to Speech sur Access.
  5. Copiez la valeur avant de fermer : la clé complète n’est affichée qu’une fois.
  6. Collez-la dans Settings ▸ ElevenLabs. La même clé sert à la transcription et au doublage.

L’API TTS utilise l’en-tête xi-api-key et POST /v1/text-to-speech/:voice_id. Référence.

Rev AI

Utilisé pour : transcription.

  1. Créez un compte sur https://www.rev.ai/auth/signup, sans carte, avec 5 h de crédit gratuit.
  2. Ouvrez Access Token, dans le menu ou sur https://www.rev.ai/access_token.
  3. Cliquez sur Generate si aucun token n’existe. Deux tokens actifs au maximum.
  4. Copiez immédiatement la valeur complète, affichée une seule fois. La liste ne garde ensuite qu’un aperçu.
  5. Collez-le dans Settings ▸ Rev AI.

Fournisseurs de traduction

DeepL

Utilisé pour : traduction automatique avec choix de formalité.

  1. Sur https://www.deepl.com/pro-api, choisissez Sign up for free dans Developer. Vérifiez votre email et votre carte bancaire. La vérification ne facture pas l’offre Developer, qui inclut un crédit unique de 1 000 000 de caractères.
  2. Ouvrez Account ▸ API Keys, https://www.deepl.com/your-account/keys, puis copiez Authentication Key.
  3. Collez-la dans Settings ▸ DeepL. SubVox Pro choisit automatiquement l’endpoint Free ou Pro.

Aide.

Google Cloud Translation

Utilisé pour : traduction automatique.

  1. Créez ou choisissez un projet sur https://console.cloud.google.com. Les nouveaux comptes disposent de 300 $ d’essai pendant 90 jours et Translation de 500 000 caractères gratuits/mois. Un compte de facturation reste nécessaire.
  2. Dans APIs & Services ▸ Library, activez Cloud Translation API avec Enable.
  3. Dans APIs & Services ▸ Credentials, choisissez Create credentials ▸ API key. Copiez la clé et, au besoin, limitez-la à Cloud Translation API.
  4. Collez-la dans Settings ▸ Google Translate.

Fixez un quota ou une alerte de budget avant l’épuisement du crédit d’essai.

OpenAI

Utilisé pour : transcription, traduction par modèle de langage, transfert des styles de mots et doublage TTS. Une seule clé couvre les trois fonctions.

  1. Créez un compte ou connectez-vous sur https://platform.openai.com.
  2. Ouvrez API Keys dans le projet.
  3. Cliquez sur Create new secret key.
  4. Nommez-la si nécessaire, vérifiez le projet et les permissions, puis cliquez sur Create secret key.
  5. Copiez immédiatement le secret : OpenAI ne l’affiche qu’une fois.
  6. Ajoutez des crédits depuis https://platform.openai.com/settings/organization/billing/overview. Vous pouvez aussi passer par le menu du compte, Organization settings ou Profile settings, puis Billing.
  7. Dans Billing, cliquez sur Add to credit balance. L’API consomme ce solde.
  8. Choisissez le montant et le paiement, puis Continue. Le minimum affiché est habituellement 5 $.
  9. Collez la clé dans Settings ▸ OpenAI et choisissez le modèle dans le panneau approprié. En Text-to-Speech, gpt-4o-mini-tts fournit 13 voix et suit les directions de jeu ; tts-1 est rapide et tts-1-hd privilégie la qualité. Ces deux derniers proposent 9 voix et ignorent les directions. En Speech-to-Text, choisissez OpenAI puis le modèle de transcription.

Timings de transcription :

  • gpt-transcribe, par défaut, gpt-4o-transcribe et gpt-4o-mini-transcribe donnent une excellente transcription mais sans timings par mot. SubVox Pro répartit les mots sur les segments, ou sur le clip complet s’il n’y en a pas. Les textes sont corrects, les timings estimés et ajustables sur la timeline.
  • whisper-1 fournit des timings de mots réels. SubVox Pro réapplique sa transcription ponctuée sur les mots, car ceux-ci sont renvoyés sans ponctuation.
  • AssemblyAI, Gladia, Deepgram, Speechmatics, ElevenLabs, Rev AI, Whisper local et Parakeet fournissent directement des mots ponctués et datés. Préférez-les lorsque le timing compte.

L’endpoint de transcription limite les envois à 25 Mo.

Pour le TTS, les règles OpenAI demandent d’indiquer aux joueurs que les voix sont générées par IA, par exemple dans les crédits ou sur la page du jeu. Tarifs API.

Anthropic, Claude

Utilisé pour : traduction par modèle de langage et transfert des styles de mots.

  1. Créez un compte ou connectez-vous sur https://console.anthropic.com.
  2. Achetez des crédits avant les requêtes. L’API est prépayée ; sans solde, elle échoue. Le montant initial proposé est souvent 5 $.
  3. Ouvrez API keys dans la console Claude.
  4. Cliquez sur Create key.
  5. Choisissez l’espace de travail, le nom facultatif, puis Add.
  6. Copiez la clé immédiatement : sa valeur complète ne sera plus consultable.
  7. Collez-la dans Settings ▸ Claude.
Google, Gemini

Utilisé pour : traduction par modèle de langage et doublage. L’option gratuite la plus simple, sans compte de facturation. Une clé couvre les deux fonctions.

  1. Connectez-vous avec Google sur https://aistudio.google.com.
  2. Ouvrez API keys, https://aistudio.google.com/app/apikey, puis Create an API key.
  3. Nommez la clé, choisissez ou créez un projet, puis créez-la.
  4. Copiez-la depuis son panneau de détails.
  5. La liste permet ensuite de copier la clé, consulter l’usage ou configurer la facturation.
  6. Collez-la dans Settings ▸ Gemini. Pour doubler, choisissez Gemini dans Text-to-Speech : 30 voix multilingues, comme Kore, Puck et Leda, avec directions de jeu. Modèles : gemini-3.1-flash-tts-preview, par défaut et le plus naturel ; gemini-2.5-flash-preview-tts, moitié moins cher en usage facturé ; gemini-2.5-pro-preview-tts, sans offre gratuite, nécessite la facturation.

Le gratuit ne demande aucune facturation, mais limite le débit. Consultez Rate limit dans AI Studio. Les limites TTS sont les plus strictes, quelques requêtes par minute et par jour. SubVox Pro attend et réessaie quand Google précise un délai, puis affiche un message clair lorsque le quota quotidien est épuisé. Activer la facturation augmente ces limites sans autre changement dans SubVox Pro. Les requêtes gratuites peuvent servir à améliorer les produits Google.

DeepSeek

Utilisé pour : traduction à faible coût, API compatible OpenAI.

  1. Créez un compte ou connectez-vous sur https://platform.deepseek.com.
  2. Ajoutez un solde avec Top up avant de commencer. Sans crédit, les requêtes échouent.
  3. Ouvrez API keys, https://platform.deepseek.com/api_keys, puis Create new API key. Nommez-la, par exemple SubVoxPro, et copiez-la immédiatement : affichage complet unique.
  4. Collez-la dans Settings ▸ DeepSeek, puis choisissez le modèle dans le panneau de traduction.

Tarifs.

Doublage par synthèse vocale

ElevenLabs TTS utilise la même clé que la transcription. Une clé restreinte nécessite Text to Speech: Access. Le clonage ElevenLabs, Instant Voice Cloning sur une offre payante, nécessite également Voices en écriture pour créer, retrouver et supprimer les clones. Gemini TTS utilise la clé Gemini, sans OAuth ni facturation, contrairement aux voix Gemini de Google Cloud ci-dessous. OpenAI TTS utilise sa clé OpenAI.

InWorld AI

Utilisé pour : génération d’audio doublé pour une piste traduite.

  1. Créez un compte sur https://studio.inworld.ai.
  2. Ouvrez API Keys dans votre espace de travail.
  3. Cliquez sur Generate new key.
  4. Donnez un nom reconnaissable. Choisissez Standard, sauf besoin spécifique d’une clé realtime-only, et conservez les permissions nécessaires au TTS.
  5. Copiez Basic (Base64). La clé reste copiable dans la liste.
  6. Collez-la dans Settings ▸ InWorld.

Gratuit : environ 70 minutes de TTS, une fois, avec licence commerciale. TTS Playground permet d’écouter les voix. Premiers pas.

Google Cloud Text-to-Speech

Utilisé pour : doublage d’une piste traduite. Une connexion couvre deux familles : les voix classiques, Standard, WaveNet, Neural2, Chirp/Chirp3-HD, sur Cloud Text-to-Speech API, et les voix Gemini, comme Leda, Achird et Aoede, multilingues avec direction libre, sur Vertex AI.

Ce fournisseur utilise OAuth, pas une clé API. Vertex AI exige la permission aiplatform.endpoints.predict : une clé API ne porte pas les droits IAM, contrairement au compte Google connecté s’il possède ou édite le projet. Une connexion suffit aux deux familles.

  1. Créez ou choisissez un projet sur https://console.cloud.google.com. Nouveau compte : 300 $ d’essai pendant 90 jours. Un compte de facturation reste obligatoire.
  2. Dans APIs & Services ▸ Library, activez Cloud Text-to-Speech API et, pour Gemini, Vertex AI API, aiplatform.googleapis.com, pas l’ancien AI Platform, ml.googleapis.com. Vertex AI est inutile si vous n’utilisez que les voix classiques.
  3. Dans OAuth consent screen, choisissez External pour User type / Audience et ajoutez votre compte aux Test users. Internal bloque les comptes Gmail personnels avec 403: org_internal.
  4. Dans Credentials ▸ Create credentials ▸ OAuth client ID, choisissez Desktop app et copiez Client ID et Client secret. Le client Desktop permet la connexion locale http://127.0.0.1, comme pour Google Sheets.
  5. Dans Text-to-Speech, choisissez Google Cloud, collez ces deux valeurs, puis Connect…. Connectez-vous dans le navigateur. L’avertissement d’application non vérifiée est normal en mode Testing : choisissez Continue. Le projet de quota/facturation est déduit du Client ID. Les identifiants et le refresh token restent dans les préférences de cet ordinateur.

Choisissez ensuite une voix. Les classiques apparaissent comme Tier Leaf (locale), par exemple Neural2 A (fr-FR). Les Gemini apparaissent comme Name · Gemini et ignorent le filtre de langue puisqu’elles sont multilingues. Le bouton bulle voice direction devient actif : décrivez le ton, par exemple really sad, close to mental breakdown. Cette indication est envoyée pour chaque ligne.

Les voix classiques utilisent le quota mensuel Cloud TTS, environ 1 M de caractères Neural2/WaveNet et 4 M Standard. Les voix Gemini et Chirp sont facturées via Vertex AI, à un autre tarif. Fixez une alerte de budget. Tarifs.

Azure AI Speech

Utilisé pour : doublage avec voix neuronales multilingues. Utilise clé d’abonnement et région, sans OAuth.

  1. Créez un compte sur https://azure.microsoft.com/free. Une carte vérifie l’identité, mais F0 limite l’usage au lieu de facturer : aucun débit sur cette offre.

  2. Dans https://portal.azure.com, cliquez sur Create a resource, recherchez Speech et choisissez la tuile Speech publiée par Microsoft, avec Create, pas une offre Marketplace Subscribe. Choisissez abonnement, groupe de ressources, Region, nom et Pricing tier F0 (free), puis Review + create. Notez la région.

    Lien direct vers la ressource Speech.

  3. Après déploiement, ouvrez Keys and Endpoint, copiez KEY 1 et notez Location/Region, par exemple westeurope.

  4. Collez la clé dans Settings ▸ Azure Speech. Dans Text-to-Speech, choisissez Azure et la même région.

La clé et la région doivent correspondre à la même ressource, sinon Azure renvoie 401. Choisissez le code court, westeurope ou eastus, pas le nom affiché comme « West Europe ».

F0 : environ 0,5 M de caractères TTS neuronaux par mois, uniquement pour l’évaluation. Les droits commerciaux sur l’audio nécessitent une ressource S0 payante avant de doubler un jeu publié. Tarifs.

Après l’enregistrement d’une clé

Le panneau affiche API Ready lorsqu’une clé valide est détectée. En cas d’échec, vérifiez que la clé a été copiée entièrement, que le compte dispose encore de crédits ou de quota, et que votre machine accède au réseau. Clear API Keys, dans Tools ▸ SubVox Pro ▸ Settings, efface toutes les clés enregistrées sur cet ordinateur.
