Namespace SubVoxPro.Timeline

Classes

VoiceLineAudioPlayableAsset

与原生 Audio Track 上的 VoiceLineClip 配对的音频剪辑。在编辑器中显示并预览源音频；若存在 CurrentLanguage 对应的配音，则播放该配音。语言在构建 Timeline 图时（即 PlayableDirector 开始播放时）读取，因此配音不会在过场动画中途切换。

VoiceLineClip

基于 VoiceLineData 资源的 Timeline 剪辑。将 VoiceLineData 拖放到 VoiceLineTrack 上会自动创建此类剪辑，其默认时长为该台词资源中最长音频的时长（源音频或配音）。若拖放的是 VoiceLineSequenceData，则由临时的 VoiceLineSequenceData 字段接收，再由剪辑编辑器为每个步骤创建一个剪辑（随后将该字段清空为 null）。

VoiceLineEventMarker

烘焙为 Timeline 标记的台词资源事件，通过 VoiceLineTimelineEventReceiver 触发。

VoiceLineEventTrack

包含由台词资源事件烘焙而成的标记的 Timeline 轨道。

VoiceLineTimelineEventReceiver

播放到标记时，在 SubVox 上触发烘焙后的台词资源事件。由烘焙操作添加到 PlayableDirector 上。

VoiceLineTrack

驱动台词资源字幕的 Timeline 轨道，与 PlayableDirector 的时钟同步。音频由配对的原生 Audio Track 播放（拖放时自动创建），因此此轨道仅通过 SubVox 发布字幕，供字幕显示组件获取。正在播放的剪辑具有显示优先权；剪辑结束后，恢复显示当前选中的台词播放源的字幕，不会重新开始播放其音频。
