在 TextMeshPro 文本（UI 或 3D）中显示 SubVox 发布的字幕，使用说话者的名称和字体，并遵循 SubVox 的显示设置（开启/关闭、大小、背景不透明度、淡入淡出）。无论播放来自台词播放源还是 Timeline，行为都相同。

ComposeText(SubtitleInfo)

字幕要显示的文本。默认根据 Speaker Name Mode 组合字幕文本与说话者姓名。重写此方法可修改文本，例如添加前缀或更改大小写。

protected virtual string ComposeText(SubtitleInfo subtitle_info)

参数

返回值

Examples

public sealed class UppercaseSubtitleDisplayer : SubtitleDisplayer
{
    protected override string ComposeText(SubtitleInfo subtitle_info)
    {
        return base.ComposeText(subtitle_info).ToUpperInvariant();
    }
}
