类 VoiceLineEmitter

SubVoxPro.dll

通过自身的 AudioSource 播放台词资源，每次播放一个，同时触发事件并显示同步字幕。为每个说话的角色添加一个此组件，并将其 AudioSource 设为 3D，即可从角色所在位置听到声音。多个台词播放源可以同时播放，VoiceLineManager 会显示正在播放的台词中最重要的台词的字幕。

Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)

播放一个台词资源（若存在 CurrentLanguage 对应的配音，则播放该配音）。此台词播放源已有台词正在播放时，由模式决定处理方式：Replace 在新台词的优先级不低于当前台词时替换当前台词（优先级较低时拒绝播放）；Queue 将新台词排在已等待的台词之后播放；IfIdle 拒绝播放。

PlayExternal(VoiceLineData, IVoiceLineAudioClock, EVoiceLinePriority, EVoiceLinePlayMode)

播放由你自行播放音频的台词资源（通过 FMOD、Wwise、视频等）：字幕和事件跟随 audio_clock，而非此台词播放源的 AudioSource；时钟停止播放时，台词播放完成。台词播放开始后，启动 CurrentAudioLanguage 对应的音频。规则与 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 相同；Pause()、Seek(float) 和 Stop() 仅影响字幕和事件，因此也需要控制外部音频。

public VoiceLinePlayback PlayExternal(VoiceLineData voice_line, IVoiceLineAudioClock audio_clock, EVoiceLinePriority priority = EVoiceLinePriority.Normal, EVoiceLinePlayMode mode = EVoiceLinePlayMode.Replace)
