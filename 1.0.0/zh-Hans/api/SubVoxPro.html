Classes

LanguageCodeAttribute

将字符串字段标记为语言代码，使 Inspector 显示语言下拉列表，列出项目的 VoiceLineData 台词资源中实际存在的语言及源语言，替代需要手动输入代码的自由文本字段。

LocalizedAudioTrack

台词资源在一种语言中的配音，具有独立的时间信息。

LocalizedSubtitleTrack

台词资源的字幕在一种语言中的翻译。

LocalizedVoiceLineEventBinding

特定于一份配音的事件位置。

MelodyVoiceModifier

在其播放源说出的每个音节（或词）上播放一个“动物森友会”风格的短促提示音，支持所有语言，无需生成任何内容：每个提示音跟随正在播放的音频（原声或配音）中人声的语调；当台词没有音频或人声不清晰时，则使用轻微的随机音高。将其添加到 VoiceLineEmitter 旁边，并为每个角色选择音域。

SpeakerData

具有名称和样式的说话者，可指定为字幕的说话者。每个说话者都是独立的资源，可在多个台词资源中复用；性别仅用于在编辑器的选择器中对说话者分组。

SpeakerLocalizedName

角色在某种语言中显示的名称。

SpeakerSelectorAttribute

标记 SpeakerData 字段，使 Inspector 显示与台词资源窗口相同的说话者选择弹出窗口（说话者按性别分组，包含 none 选项和 new speaker 快捷入口），替代默认的对象引用字段。

SubVox

SubVox Pro 的 API 入口：播放台词资源，设置语言和字幕显示方式，并触发全局事件（字幕、台词资源、台词资源事件）。所有播放源均遵循这些设置：包括 VoiceLineEmitter 组件和 Timeline 集成。

SubVoxEvents

为本项目生成的台词资源事件键。

SubtitleBubbleDisplayer

单个角色的对话气泡：仅显示其 VoiceLineEmitter 播放的台词，例如显示在 NPC 头顶上方，同时屏幕底部的字幕显示组件继续显示对话。设置与 SubtitleDisplayer 相同。关闭台词播放源的 Show Subtitles，即可仅在气泡中显示其台词。

SubtitleDisplayer

在 TextMeshPro 文本（UI 或 3D）中显示 SubVox 发布的字幕，使用说话者的名称和字体，并遵循 SubVox 的显示设置（开启/关闭、大小、背景不透明度、淡入淡出）。无论播放来自台词播放源还是 Timeline，行为都相同。

SubtitleDocumentDisplayer

在其 UnityEngine.UIElements.UIDocument 的 UI Toolkit UnityEngine.UIElements.Label 中显示发布于 SubVox 的字幕，包含说话者姓名，并使用 UI Toolkit 字体。它是 SubtitleDisplayer 对应的 UI Toolkit 组件：说话者姓名显示模式、富文本样式及显示设置均与之相同。

VoiceLineBankData

一组可互换的台词资源，例如守卫的游戏短台词：每次播放按 Order 选择其中一个。此资源仅保存台词资源；下一次选择哪个由 SubVox Pro 在运行时跟踪。

VoiceLineData

台词资源：包含源音频和字幕、翻译、配音、说话者及事件。在 SubVox Pro 窗口中创建和编辑；在代码中只读。

VoiceLineDataEvent

携带台词资源的 UnityEvent 类型，公开此类型以便在 Inspector 中显示。

VoiceLineEmitter

通过自身的 AudioSource 播放台词资源，每次播放一个，同时触发事件并显示同步字幕。为每个说话的角色添加一个此组件，并将其 AudioSource 设为 3D，即可从角色所在位置听到声音。多个台词播放源可以同时播放，VoiceLineManager 会显示正在播放的台词中最重要的台词的字幕。

VoiceLineEventAttribute

台词资源中信号键与此键匹配的事件触发时，调用标记的方法。该方法所属的组件需由 VoiceLineEventDispatcher 缓存，或与 VoiceLineEventListener 位于同一 GameObject 上。方法返回 void，不接受参数，或接受一个 VoiceLineEventContext 参数，或接受一个与事件附带数据类型相同的参数。键匹配时忽略大小写、空格和标点：“Camera Shake”可匹配“camera-shake”。

VoiceLineEventBinding

事件在台词资源中的位置：一个锚点加上一个偏移量。

VoiceLineEventContext

触发的事件的全部信息：台词资源、信号、事件附带数据，以及触发时间和位置。

VoiceLineEventCue

添加到台词资源上的事件：一个信号、触发位置以及可选的事件附带数据。

VoiceLineEventDispatcher

当相应信号触发时，调用已加载场景中带有 VoiceLineEventAttribute 的方法。在启动场景中添加此组件（[SubVox Pro] 预制体已包含此组件）。

VoiceLineEventListener

当具有匹配信号键的台词资源事件触发时，调用此游戏对象上各组件中带有 VoiceLineEventAttribute 的方法。跳过已禁用的组件。

VoiceLineEventReaction

VoiceLineEventReceiver 的一个响应：一个信号、一条可选的台词资源，以及应调用的方法。

VoiceLineEventReceiver

当台词资源事件触发时，调用在 Inspector 中设置的 UnityEvent：每个信号对应一个响应，可选择将响应限制于一个台词资源。

VoiceLineEventSignalData

一种可复用的事件类型（例如“Camera Shake”），可放置在台词资源上；代码通过 Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)、接收器或带有 VoiceLineEventAttribute 的方法响应此类事件。

VoiceLineEventUnityEvent

携带 VoiceLineEventContext 的 UnityEvent，在 Inspector 中显示。

VoiceLineManager

为 SubVox 提供支持的场景组件：保存 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 使用的 2D VoiceLineEmitter（用于旁白、对话），统一暂停或停止所有台词播放源，在语音播放期间执行音乐音量闪避（ducking），即暂时降低音乐音量，并发布当前播放中最重要的台词的字幕。先按优先级选择；优先级相同时，选择最近开始播放的台词。

VoiceLinePlayOnStart

当此对象启动（或重新启用）时，经过可选的延迟后自动播放一条台词资源。通常用于关卡开场旁白或开场白。Play() 保持为 public 以便手动复用。

VoiceLinePlayback

一次台词资源播放请求，由 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 和 Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) 返回：通过 State 跟踪其状态、停止播放，或使用 yield return 在协程中等待其完成。

VoiceLineSequenceData

可复用的有序台词资源列表，用于依次播放。此资源仅保存定义（包含哪些台词资源，以及每一步如何进入下一步）；场景中的 VoiceLineSequencePlayer 在运行时驱动序列，使多个播放器可以安全地复用同一序列。

VoiceLineSequencePlayer

运行时逐行播放VoiceLineSequenceData文件。 每个步骤可在当前行播放完毕后（可选延迟）自动前进，或通过Advance()手动前进——该事件可与任何UnityEvent、交互或UI按钮绑定——而Previous()则可返回上一行。步骤按Direction的顺序播放。若台词播放源正忙而拒绝了某个步骤，该步骤将等待其空闲。提供UnityEvents以便场景逻辑无需代码即可响应，同时也提供相同的C#事件供代码使用。

VoiceLineSequenceStep

序列中的一个步骤：一个台词资源，以及播放后进入下一步的方式。

VoiceLineZone

当碰撞体进入此触发区域时，播放一条台词资源（或台词库中的下一条台词资源）。支持 2D 或 3D 碰撞体：只会触发与此对象上的碰撞体类型匹配的回调，因此一个组件即可支持这两种类型。可按图层和可选的标签进行筛选，设置仅播放一次或按冷却时间限制播放，选择台词播放源忙碌时的处理方式，还可在玩家离开时停止播放台词或让触发区域重新待命。Play() 是公共方法，其他系统（如交互系统、UI 按钮）均可通过 UnityEvent 复用它。

VoicePersonalityData

可复用的配音风格预设（包含名称和自由填写的配音指导）。它作为配音风格指令传递给支持此类指令的语音合成提供商（Google Gemini-TTS、InWorld），使同一角色在多个台词资源中都能以“平静”“愤怒”“耳语”等风格配音。说话者资源列出适用的配音风格预设，每条字幕可从中选择一个。
