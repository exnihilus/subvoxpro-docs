类 MelodyVoiceModifier

命名空间
SubVoxPro
程序集
SubVoxPro.dll

在其播放源说出的每个音节（或词）上播放一个“动物森友会”风格的短促提示音，支持所有语言，无需生成任何内容：每个提示音跟随正在播放的音频（原声或配音）中人声的语调；当台词没有音频或人声不清晰时，则使用轻微的随机音高。将其添加到 VoiceLineEmitter 旁边，并为每个角色选择音域。

public class MelodyVoiceModifier : MonoBehaviour
继承
object
MelodyVoiceModifier

Examples

MelodyVoiceModifier voice = _villager.GetComponent<MelodyVoiceModifier>();
voice.Mode = EVoiceLineMelodyMode.Replace;
voice.BasePitch = 5f;
_villager.GetComponent<VoiceLineEmitter>().Play(greeting);
