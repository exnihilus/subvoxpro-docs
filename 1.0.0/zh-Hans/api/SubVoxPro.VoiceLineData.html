GetSubtitleAt(float, string)

台词资源以指定语言播放时，在指定时间点（以秒为单位）显示的字幕。与 VoiceLineEmitter 显示的字幕相同（包括配音时间信息和 Auto blanks 效果），包含完整文本及样式。第一条字幕之前、停顿期间或清空字幕标记之后，字幕为空。

language_code string

返回值
