SubVox Pro — プロバイダー設定ガイド

SubVox ProにはAPIキーは一切付属していません。以下の各プロバイダーへのアクセスにはご自身のキーを使用します。このキーをTools ▸ SubVox Pro ▸ Settings（または SubVox Proウィンドウ内のプロバイダーパネル）に貼り付けます。キーは、お使いのマシンのUnityエディターの環境設定（EditorPrefs）にのみ保存され、プロジェクトにコミットされることも、ビルドに含まれることもありません。各サービスの法的条件については、 Third-Party Notices.mdを参照してください。

⚠️ 無料枠や料金は頻繁に変更されます。以下の数値は執筆時点では正確でした。ご利用の際は、必ず各プロバイダーの料金ページで最新の提供内容を確認してください。

Chatterbox：各言語の信頼性

  • 信頼性が非常に高い：ポルトガル語、イタリア語、スペイン語、ヒンディー語、英語、ドイツ語、マレー語、ロシア語、オランダ語。

ベストプラクティス

APIキーはオンラインサービスのパスワードです。テスト目的でしか使用しない場合でも、機密情報として扱ってください。

  • ツールやプロジェクトごとに1つのキーを作成してください。専用のSubVoxProキーであれば、後で他のツールの動作を妨げることなく、簡単に失効させられます。
  • APIキーをソースファイル、シーン、プレハブ、サポートへのメッセージ、Discord、GitHubのイシューやコミットに貼り付けないでください。 SubVox ProはキーをUnityのEditorPrefsに、お使いのマシン上でのみ保存するため、Unityプロジェクトの一部にはなりません。
  • プロバイダーから「キーは一度だけ表示される」と通知された場合は、直ちにキーをコピーしてください。バックアップが必要な場合は、パスワードマネージャーに保存してください。キーを紛失した場合は、失効させて新しいものを作成してください。
  • 権限は必要最小限に設定してください。プロバイダーでキーの権限を制限できる場合は、 SubVox Proに必要な機能のみを有効にしてください。文字起こしプロバイダーでは音声認識、翻訳プロバイダーでは翻訳、 TTSは吹き替えにのみ使用します。
  • ワークフローに合わせた有効期限を設定してください。テストやデモでは、有効期限の短いキーの方が安全です。継続的な制作作業では、有効期限の長いキーの方が便利です。プロバイダーによっては、有効期限のないキーも利用できます。
  • プロバイダーが対応している場合は、予算、使用制限、または課金アラートを設定してください。意図しないループ処理や繰り返しのインポート、チームメンバーによる誤ったキーの使用で発生する予想外の費用を防ぐのに役立ちます。
  • キーが漏洩した可能性がある場合は、新しいキーに切り替えてください。スクリーンショット、コミット、チャットメッセージ、またはビルド成果物にキーが含まれていた場合は、プロバイダーのダッシュボードでそのキーを失効させ、新しいキーをSubVox Proに貼り付けてください。
  • 1つの個人用キーをチーム全体で共有しないでください。各チームメンバーは、プロバイダーの課金やアクセス管理の方法に応じて、各自のプロバイダーアカウント、またはチームで管理するキーを使用してください。
  • SubVox Proから未使用のキーを削除してください。共有マシンでのテストが終了したら、 Tools ▸ SubVox Pro ▸ SettingsにあるClear API Keysボタンを使用してください。

無料利用枠の早見表

SubVox Proは、無料アカウントでも有料アカウントでも同じように動作します。使用するキーもリクエストも同じです。無料プランで変わるのは、生成できる量と、一部のプロバイダーにおける生成結果の利用範囲だけです。

SubVox Proでのキーの貼り付け先

以下のいずれかのプロバイダーからキーを取得したら、SubVox Proでは、次の2か所のどちらからでもキーを保存できます。キーは、このマシン上のUnity Editorの環境設定（EditorPrefs）にのみ保存され、プロジェクト内には保存されません。

Tools ▸ SubVox Pro ▸ Settingsを開くと、すべてのプロバイダーを一覧表示するパネルが開きます。各キーを対応する行に貼り付けます（入力した値はフィールド上でマスク表示されます）。typeバッジのSTT（文字起こし）、TR（翻訳）、 TTS（吹き替え）を目安に、目的に対応するプロバイダーを探します。Clear API Keysを選択すると、このマシンからすべてのAPIキーが削除されます。

また、SubVox Proウィンドウ内のプロバイダーパネルに、直接キーを貼り付けることもできます。キーを入力して Saveをクリックすると、API Readyバッジが表示され、キーが受け入れられたことを確認できます（Clearを選択すると削除されます）。
