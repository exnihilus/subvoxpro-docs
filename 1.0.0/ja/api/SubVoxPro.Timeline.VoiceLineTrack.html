クラス VoiceLineTrack

名前空間
SubVoxPro.Timeline
アセンブリ
SubVoxPro.Timeline.dll

ディレクターのクロックに同期してボイスラインの字幕を制御するTimelineトラックです。オーディオは、ペアとなる標準のAudio Track（ドロップ時に自動作成）で再生されます。そのため、このトラックはSubVoxに字幕のみを配信し、各字幕表示コンポーネントが取得できるようにします。アクティブなクリップは字幕の表示で優先されます。クリップが終了すると、現在選択されているエミッターの字幕表示に戻り、オーディオは最初から再生し直されません。

[TrackColor(0.85, 0.55, 0.18)]
[TrackClipType(typeof(VoiceLineClip))]
public sealed class VoiceLineTrack : TrackAsset, ISerializationCallbackReceiver, IPropertyPreview
