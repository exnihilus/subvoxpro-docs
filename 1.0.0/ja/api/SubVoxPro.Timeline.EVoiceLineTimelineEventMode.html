列挙型 EVoiceLineTimelineEventMode

名前空間
SubVoxPro.Timeline
アセンブリ
SubVoxPro.Timeline.dll

Timelineクリップが、そのボイスラインのイベントをどのように発生させるか。

public enum EVoiceLineTimelineEventMode

フィールド

Embedded = 0

クリップ自体からイベントが発生します。

TimelineMarkers = 1

イベントはマーカーとしてベイクされており、代わりにそのマーカーからイベントが発生します。

Disabled = 2

イベントは発生しません。
