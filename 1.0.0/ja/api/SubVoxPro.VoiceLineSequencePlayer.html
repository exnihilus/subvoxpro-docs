クラス VoiceLineSequencePlayer

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

実行時にVoiceLineSequenceDataを1行ずつ再生します。 各ステップは、その行の再生が終了すると（オプションの遅延の後）、自動的に次のステップに進みます。また、Advance()（任意のUnityEvent、インタラクション、またはUIボタンに接続可能）を使用して手動で進めることもでき、Previous()で1行戻ることができます。ステップはDirectionの順序で再生されます。ビジー状態のエミッターによって拒否されたステップは、エミッターが空き状態になるまで待機します。シーンロジックがコードを記述せずに反応できるようUnityEventを公開しており、コード用には同じC#イベントも提供しています。

public class VoiceLineSequencePlayer : MonoBehaviour

object
