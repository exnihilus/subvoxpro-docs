Classes

LanguageCodeAttribute

文字列フィールドを言語コードとして指定します。Inspectorには、コードを手入力する自由記述フィールドの代わりに、プロジェクトのVoiceLineDataアセットに実際に存在する言語（ソース言語を含む）のドロップダウンリストが表示されます。

LocalizedAudioTrack

1つの言語で生成されたボイスラインの吹き替え音声です。独自のタイミングを持ちます。

LocalizedSubtitleTrack

ボイスラインの字幕を1つの言語に翻訳したものです。

LocalizedVoiceLineEventBinding

1つの吹き替えに固有のイベント位置。

SpeakerData

字幕に関連付けられる、名前とスタイルを持つ話者です。話者ごとに独立したアセットとして保存され、複数のボイスラインで再利用できます。性別は、エディターの選択画面で話者をグループ分けするためにのみ使用されます。

SpeakerLocalizedName

1つの言語で表示する話者の名前です。

SpeakerSelectorAttribute

SpeakerDataフィールドに付与すると、Inspectorに、既定のオブジェクト参照フィールドの代わりに、ボイスラインウィンドウと同じ話者選択ポップアップが表示されます。話者は性別ごとにグループ化され、「none」項目と「new speaker」ショートカットが含まれます。

SubVox

SubVox Proのコードからのエントリーポイントです。ボイスラインを再生し、言語と字幕の表示方法を設定し、グローバルイベント（字幕、ボイスライン、ボイスラインイベント）を発生させます。VoiceLineEmitterコンポーネントとTimeline統合を含む、すべての再生ソースがこの設定と動作に従います。

SubVoxEvents

このプロジェクト用に生成されたボイスラインイベントキーです。

SubtitleBubbleDisplayer

1人のキャラクター用の吹き出しです。画面下部の表示で会話の字幕を表示しながら、例えばNPCの頭上に、対象のVoiceLineEmitterの字幕のみを表示します。設定はSubtitleDisplayerと同じです。エミッターの「Show Subtitles」をオフにすると、その字幕を吹き出しにのみ表示できます。

SubtitleDisplayer

SubVoxで公開される字幕を、TextMeshProのテキスト（UIまたは3D）に、話者の名前とフォントを使用して表示します。SubVoxの表示設定（オン／オフ、サイズ、背景の不透明度、フェード）に従います。エミッターからの再生でもTimelineからの再生でも同様に動作します。

SubtitleDocumentDisplayer

自身のUnityEngine.UIElements.UIDocumentのUI Toolkit UnityEngine.UIElements.Labelに、SubVoxで公開された字幕を話者名とともに、UI Toolkitのフォントで表示します。SubtitleDisplayerのUI Toolkit版で、話者名の表示モード、リッチテキストのスタイル、表示設定は同じです。

VoiceLineBankData

衛兵がゲームプレイ中に発する短いセリフなど、互いに代替可能なボイスラインのセットです。再生のたびにOrderに従って1つ選択します。アセットにはボイスラインのみを保持し、次に再生するボイスラインは実行時にSubVox Proが管理します。

VoiceLineData

ソースオーディオと字幕、翻訳、生成された吹き替え音声、話者、イベントを含むボイスラインです。SubVox Proウィンドウで作成・編集します。コードからは読み取り専用です。

VoiceLineDataEvent

ボイスラインを渡すUnityEventです。Inspectorに表示されるように公開されています。

VoiceLineEmitter

自身のAudioSourceで、ボイスラインを1つずつ、イベントおよび音声と同期した字幕とともに再生します。発話するキャラクターごとに配置し、AudioSourceを3Dに設定すると、そのキャラクターの位置から声が聞こえます。複数のエミッターで同時に再生でき、VoiceLineManagerが再生中の最も優先度の高いボイスラインの字幕を表示します。

VoiceLineEventAttribute

シグナルのキーがこのキーと一致するボイスラインイベントが発生するたびに、この属性を付けたメソッドを呼び出します。メソッドは、VoiceLineEventDispatcherがキャッシュするコンポーネント、またはVoiceLineEventListenerと同じGameObject上のコンポーネントに属する必要があります。戻り値はvoidで、引数はなし、VoiceLineEventContext型、またはイベントに付随するデータの型のいずれかです。キーの照合では大文字と小文字、スペース、記号を区別しません。「Camera Shake」は「camera-shake」と一致します。

VoiceLineEventBinding

ボイスライン上のイベントの位置を、アンカーとオフセットで表します。

VoiceLineEventContext

発生したイベントに関する情報です。ボイスライン、シグナル、イベントに付随するデータ、発生時刻と場所を含みます。

VoiceLineEventCue

ボイスラインに配置するイベントです。シグナル、発生位置、および任意の付随データで構成されます。

VoiceLineEventDispatcher

シグナルが発生すると、読み込まれているシーン内で、そのシグナルに対応するVoiceLineEventAttributeが付いたメソッドを呼び出します。起動シーンに1つ追加します（[SubVox Pro]プレハブに含まれています）。

VoiceLineEventListener

シグナルキーが一致するボイスラインイベントが発生すると、このGameObject上の各コンポーネントのVoiceLineEventAttributeが付いたメソッドを呼び出します。無効なコンポーネントはスキップします。

VoiceLineEventReaction

VoiceLineEventReceiverの1つの反応です。シグナル、任意のボイスライン、および呼び出す対象で構成されます。

VoiceLineEventReceiver

ボイスラインイベントが発生した際に、Inspectorで設定されたUnityEventsを呼び出します。シグナルごとに1つの反応があり、必要に応じて1つのボイスラインに限定することも可能です。

VoiceLineEventSignalData

ボイスラインに配置する、再利用可能なイベントの種類です（例：「Camera Shake」）。コードは、Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)、レシーバー、またはVoiceLineEventAttributeが付いたメソッドを通じて、このシグナルに反応します。

VoiceLineEventUnityEvent

VoiceLineEventContextを渡すUnityEventです。Inspectorに表示されます。

VoiceLineManager

SubVoxの基盤となるシーンコンポーネントです。Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)がナレーションや会話の再生に使う2DのVoiceLineEmitterを保持し、すべてのエミッターを一括で一時停止または停止します。音声の再生中は音楽の音量を一時的に下げ、再生中のボイスラインのうち、優先度が最も高いものの字幕を公開します。同じ優先度の場合は、最も最近再生を開始したものを選びます。

VoiceLineMelodyVoice

エミッターが話す音節（または単語）ごとに「どうぶつの森」風の短いブリップ音を鳴らします。すべての言語に対応し、何も生成する必要はありません。各ブリップは再生中の音声（ソースまたは吹き替え）での声のイントネーションに沿い、音声がない、または声がはっきりしないラインでは軽いランダムな音程になります。VoiceLineEmitter の隣に追加し、キャラクターごとに音域を選んでください。

VoiceLinePlayOnStart

このオブジェクトが開始（または再有効化）された際、オプションの遅延時間を経て、ボイスラインを自動的に再生します。レベル導入部のナレーションや冒頭のセリフなどに適しています。Play()は、手動での再利用が可能となるようpublicのままにされています。

VoiceLinePlayback

Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)およびPlay(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode)が返す、ボイスラインの1回の再生リクエストです。Stateで状態を確認したり、再生を停止したり、コルーチン内でyield returnを使って終了を待機したりできます。

VoiceLineSequenceData

ボイスラインを順番に再生するための、再利用可能な順序付きリストです。このアセットには定義（どのボイスラインを再生するか、および各ボイスラインがどのように次のボイスラインへと移行するか）のみが含まれています。シーン内のVoiceLineSequencePlayerが実行時にこれを制御するため、複数のプレイヤー間で同じシーケンスを安全に再利用することができます。

VoiceLineSequencePlayer

実行時にVoiceLineSequenceDataを1行ずつ再生します。 各ステップは、その行の再生が終了すると（オプションの遅延の後）、自動的に次のステップに進みます。また、Advance()（任意のUnityEvent、インタラクション、またはUIボタンに接続可能）を使用して手動で進めることもでき、Previous()で1行戻ることができます。ステップはDirectionの順序で再生されます。ビジー状態のエミッターによって拒否されたステップは、エミッターが空き状態になるまで待機します。シーンロジックがコードを記述せずに反応できるようUnityEventを公開しており、コード用には同じC#イベントも提供しています。

VoiceLineSequenceStep

シーケンスの1つのステップです。ボイスラインと、その後のシーケンスの進め方を定義します。

VoiceLineZone

コライダーがこのトリガー領域に入ると、ボイスライン（またはバンク内の次のボイスライン）を再生します。2Dまたは3Dのコライダーに対応します。このオブジェクト上のコライダーの種類に対応するコールバックのみが呼び出されるため、1つのコンポーネントで両方に対応できます。レイヤーと任意のタグによるフィルター、1回限りの再生またはクールダウン時間を設けた再生、エミッターが再生中の場合の動作を設定できます。プレイヤーが領域を離れたときに、ボイスラインを停止したり、領域を再びトリガー可能にしたりする設定も可能です。Play()はpublicなので、他のシステム（インタラクションやUIボタンなど）からもUnityEventを通じて再利用できます。

VoicePersonalityData

名前と自由形式の演技指示を持つ、再利用可能な音声演技プリセットです。スタイル指示を受け付ける音声合成プロバイダー（Google Gemini-TTS、InWorld）に渡されます。これにより、多くのボイスラインで同じキャラクターを「calm」（穏やか）、「furious」（激怒）、「whispering」（ささやき）などの話し方で吹き替えできます。話者には適した音声演技プリセットが一覧として登録され、各字幕でその中から1つを選択できます。
