1人のキャラクター用の吹き出しです。画面下部の表示で会話の字幕を表示しながら、例えばNPCの頭上に、対象のVoiceLineEmitterの字幕のみを表示します。設定はSubtitleDisplayerと同じです。エミッターの「Show Subtitles」をオフにすると、その字幕を吹き出しにのみ表示できます。

public class SubtitleBubbleDisplayer : SubtitleDisplayer

SubscribeToSubtitles()

表示する字幕の受信を開始します。既定では、SubVoxで公開されるすべての字幕を受信します。UnsubscribeFromSubtitles()と併せてこのメソッドをオーバーライドすると、ShowSubtitle(SubtitleInfo)を通じて別のソースの字幕を表示できます。
