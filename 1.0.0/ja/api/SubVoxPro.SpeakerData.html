字幕に関連付けられる、名前とスタイルを持つ話者です。話者ごとに独立したアセットとして保存され、複数のボイスラインで再利用できます。性別は、エディターの選択画面で話者をグループ分けするためにのみ使用されます。

メソッド

GetDisplayName(string)

指定した言語で表示する名前です。Unity Localizationのエントリが設定され、パッケージがインストールされている場合は、そのエントリを使用します。それ以外は、LocalizedNamesの完全一致するエントリ、同じ基本言語のエントリ、DisplayNameの順に使用します。

public string GetDisplayName(string language_code)

パラメーター

language_code string

戻り値

string

Examples

string name = speaker.GetDisplayName(SubVox.CurrentLanguage);

ToRichText(string, string)

名前と任意の接尾辞（「:」など）を、TextMeshPro用のリッチテキストの色・太字・斜体タグで囲みます。接尾辞も名前と同じ色で表示されます。言語を指定した場合、名前にはGetDisplayName(string)の戻り値を使用します。

public string ToRichText(string suffix = "", string language_code = null)
