Namespace SubVoxPro.Timeline

Classes

VoiceLineAudioPlayableAsset

標準のAudio Track上でVoiceLineClipとペアになるオーディオクリップです。エディターでは元のオーディオを表示・プレビューし、CurrentLanguageの生成された吹き替え音声が存在する場合は、それを再生します。言語はTimelineグラフの構築時（ディレクターが再生を開始するとき）に読み取られるため、カットシーンの途中で吹き替え音声が切り替わることはありません。

VoiceLineClip

VoiceLineDataアセットに基づくTimelineクリップです。VoiceLineDataをVoiceLineTrackにドロップすると自動的に作成され、長さはデフォルトでボイスラインの最も長いオーディオ（元のオーディオまたは生成された吹き替え音声）に設定されます。代わりにVoiceLineSequenceDataをドロップすると、一時的なVoiceLineSequenceDataフィールドに格納され、クリップエディターによってステップごとに1つのクリップに展開されます。その後、フィールドはnullに戻されます。

VoiceLineEventMarker

Timelineマーカーとしてベイクされたボイスラインイベントです。VoiceLineTimelineEventReceiverを通じて発生します。

VoiceLineEventTrack

ボイスラインイベントからベイクされたマーカーを保持するTimelineトラックです。

VoiceLineTimelineEventReceiver

マーカーに到達すると、ベイクされたボイスラインイベントをSubVoxで発生させます。ベイク操作によってPlayableDirectorに追加されます。

VoiceLineTrack

ディレクターのクロックに同期してボイスラインの字幕を制御するTimelineトラックです。オーディオは、ペアとなる標準のAudio Track（ドロップ時に自動作成）で再生されます。そのため、このトラックはSubVoxに字幕のみを配信し、各字幕表示コンポーネントが取得できるようにします。アクティブなクリップは字幕の表示で優先されます。クリップが終了すると、現在選択されているエミッターの字幕表示に戻り、オーディオは最初から再生し直されません。
