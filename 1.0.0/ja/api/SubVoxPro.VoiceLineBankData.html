クラス VoiceLineBankData

名前空間
SubVoxPro

衛兵がゲームプレイ中に発する短いセリフなど、互いに代替可能なボイスラインのセットです。再生のたびにOrderに従って1つ選択します。アセットにはボイスラインのみを保持し、次に再生するボイスラインは実行時にSubVox Proが管理します。

public class VoiceLineBankData : ScriptableObject

object

[SerializeField] private VoiceLineBankData _guardBarks = null;

public void OnPlayerSpotted()
{
    _guardEmitter.Play(_guardBarks, EVoiceLinePriority.Low, EVoiceLinePlayMode.IfIdle);
}
