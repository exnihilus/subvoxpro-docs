SubVox Proのコードからのエントリーポイントです。ボイスラインを再生し、言語と字幕の表示方法を設定し、グローバルイベント（字幕、ボイスライン、ボイスラインイベント）を発生させます。VoiceLineEmitterコンポーネントとTimeline統合を含む、すべての再生ソースがこの設定と動作に従います。

プロパティ

AudioFollowsSubtitles

AudioLanguageがCurrentLanguageに追従しているかどうか（未設定、またはnullに戻した場合）。

public static bool AudioFollowsSubtitles { get; }

プロパティ値

bool

AudioLanguage

再生する吹き替え音声の言語コード（例：「ja」）です。ソースオーディオを使用する場合は空です。プレイヤーはある言語を聞きながら別の言語の字幕を読めます。設定するまではCurrentLanguageに追従し、nullを設定すると再び追従します。吹き替え音声は次のボイスラインから切り替わり、その言語の吹き替えがないボイスラインはソースオーディオを再生します。

public static string AudioLanguage { get; set; }

プロパティ値

string

Examples

SubVox.AudioLanguage = "";
SubVox.CurrentLanguage = "fr";

SubVox.AudioLanguage = null;

BackgroundOpacity

字幕の背後にあるボックスの不透明度です。0（完全に透明）から1（完全に不透明）までの値を指定します。nullの場合は、各字幕表示コンポーネントで設定された値を使用します。

public static float? BackgroundOpacity { get; set; }

プロパティ値

float?

CurrentLanguage

表示する翻訳と再生する生成された吹き替え音声の言語コード（例：「fr」）です。元の字幕とオーディオを使用する場合は空です。表示中の字幕は即座に切り替わり、吹き替え音声は次のボイスラインから切り替わります。

public static string CurrentLanguage { get; set; }

string

CurrentSubtitle

ブランクマーカー（blank）を含む、現在選択されている字幕です。ブランクマーカーは字幕のテキストを消します。字幕表示コンポーネントを有効化または再有効化した際に、この値を取得してください。

public static SubtitleInfo CurrentSubtitle { get; }

PublishSubtitle(SubtitleInfo)

ビデオカットシーンのテキストなどを、ボイスラインが公開した字幕と同様に、すべての字幕表示コンポーネントに表示します。次の字幕が公開されるまで表示されます。消去するには、空のSubtitleInfoを公開してください。アクティブなTimelineのボイスラインが優先されるため、そのクリップがアクティブな間は独自に公開した字幕は無視されます。

public static void PublishSubtitle(SubtitleInfo subtitle)

パラメーター

subtitle SubtitleInfo

Examples

SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, "Somewhere in the north, ten years ago."));
SubVox.PublishSubtitle(new SubtitleInfo("intro", 0f, string.Empty));

Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)

このシグナルを持つボイスラインイベントが発生するたびに、ハンドラを呼び出します。Unsubscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>) を使用して登録を解除します。通常は OnDisable 内で実行します。シグナルアセット自体は一切変更されません。

public static void Subscribe(VoiceLineEventSignalData signal, Action<VoiceLineEventContext> handler)

パラメーター

signal VoiceLineEventSignalData
handler Action<VoiceLineEventContext>

Examples

[SerializeField] private VoiceLineEventSignalData _cameraShake = null;

private void OnEnable() => SubVox.Subscribe(_cameraShake, Shake);
private void OnDisable() => SubVox.Unsubscribe(_cameraShake, Shake);

private void Shake(VoiceLineEventContext context)
{
    _camera.Shake(0.3f);
}

Unsubscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>)

Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>) で追加されたハンドラーへの呼び出しを停止します。
