クラス VoicePersonalityData

名前空間
SubVoxPro
アセンブリ

名前と自由形式の演技指示を持つ、再利用可能な音声演技プリセットです。スタイル指示を受け付ける音声合成プロバイダー（Google Gemini-TTS、InWorld）に渡されます。これにより、多くのボイスラインで同じキャラクターを「calm」（穏やか）、「furious」（激怒）、「whispering」（ささやき）などの話し方で吹き替えできます。話者には適した音声演技プリセットが一覧として登録され、各字幕でその中から1つを選択できます。

public class VoicePersonalityData : ScriptableObject
