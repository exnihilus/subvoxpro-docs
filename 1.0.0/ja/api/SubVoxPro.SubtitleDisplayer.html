クラス SubtitleDisplayer

名前空間
SubVoxPro
アセンブリ
SubVoxPro.dll

SubVoxで公開される字幕を、TextMeshProのテキスト（UIまたは3D）に、話者の名前とフォントを使用して表示します。SubVoxの表示設定（オン／オフ、サイズ、背景の不透明度、フェード）に従います。エミッターからの再生でもTimelineからの再生でも同様に動作します。

public class SubtitleDisplayer : MonoBehaviour

プロパティ

KeepBackgroundBetweenSubtitles

2つの字幕の間に置かれたブランクマーカー（blank）が字幕のテキストを消している間も、背景を表示したままにするかどうかを示します。

public bool KeepBackgroundBetweenSubtitles { get; set; }

プロパティ値

bool

SpeakerNameMode

話者名の表示方法です。非表示、字幕の前、字幕の上のいずれかです。

public ESpeakerNameMode SpeakerNameMode { get; set; }

プロパティ値

ESpeakerNameMode

メソッド

ClearSubtitle()

現在の字幕を画面から消します。

public void ClearSubtitle()

ComposeText(SubtitleInfo)

字幕として表示するテキストです。既定では、「Speaker Name Mode」に従って話者名を付けた字幕テキストを返します。このメソッドをオーバーライドすると、接頭辞の追加や大文字・小文字の変更など、テキストを変更できます。

protected virtual string ComposeText(SubtitleInfo subtitle_info)

パラメーター

subtitle_info SubtitleInfo

戻り値

string

Examples

public sealed class UppercaseSubtitleDisplayer : SubtitleDisplayer
{
    protected override string ComposeText(SubtitleInfo subtitle_info)
    {
        return base.ComposeText(subtitle_info).ToUpperInvariant();
    }
}

SetVisible(bool)

字幕ボックスを表示または非表示にします。字幕がある間は表示し、字幕の間は非表示にします。フェードの所要時間はFadeDurationです。このメソッドをオーバーライドすると、ボックスを独自の方法でアニメーションさせられます。

protected virtual void SetVisible(bool visible)

パラメーター

visible bool

ShowSubtitle(SubtitleInfo)

字幕を表示します。空の字幕の場合は表示を消します。

protected void ShowSubtitle(SubtitleInfo subtitle_info)

パラメーター

subtitle_info SubtitleInfo

SubscribeToSubtitles()

表示する字幕の受信を開始します。既定では、SubVoxで公開されるすべての字幕を受信します。UnsubscribeFromSubtitles()と併せてこのメソッドをオーバーライドすると、ShowSubtitle(SubtitleInfo)を通じて別のソースの字幕を表示できます。

protected virtual void SubscribeToSubtitles()

UnsubscribeFromSubtitles()

SubscribeToSubtitles()で受信を開始したソースからの受信を停止します。

protected virtual void UnsubscribeFromSubtitles()
