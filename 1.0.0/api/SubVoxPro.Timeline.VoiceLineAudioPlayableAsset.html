Class VoiceLineAudioPlayableAsset

Namespace
SubVoxPro.Timeline
Assembly
SubVoxPro.Timeline.dll

Audio clip paired with a VoiceLineClip on a native Audio Track. It shows and previews the source audio in the editor, and plays the dub of CurrentLanguage when one exists. The language is read when the Timeline graph is built (when the director starts playing), so a dub never switches in the middle of a cutscene.
