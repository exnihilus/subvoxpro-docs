Spielt Sprachzeilen nacheinander über eine eigene AudioSource ab, zusammen mit den zugehörigen Ereignissen und synchronisierten Untertiteln. Weisen Sie jedem sprechenden Charakter eine solche zu und stellen Sie deren „AudioSource“ auf „3D“ ein, um die Stimme von dort zu hören: Mehrere Emitter spielen gleichzeitig ab, und die VoiceLineManager zeigt den Untertitel der gerade abgespielten wichtigsten Zeile an.

PlayExternal(VoiceLineData, IVoiceLineAudioClock, EVoiceLinePriority, EVoiceLinePlayMode)

Spielt eine Sprachzeile ab, deren Audio Sie selbst abspielen (FMOD, Wwise, ein Video …): Die Subtitles und Events folgen der „audio_clock“ anstelle der „AudioSource“ dieses Emitters und enden, sobald die Wiedergabe der Uhr stoppt. Sobald die Wiedergabe beginnt, starten Sie das Audio von CurrentAudioLanguage. Es gelten dieselben Regeln wie bei Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode); Pause(), Seek(float) und Stop() wirken sich nur auf die Subtitles und Events aus, steuern Sie daher auch Ihr Audio entsprechend.

public VoiceLinePlayback PlayExternal(VoiceLineData voice_line, IVoiceLineAudioClock audio_clock, EVoiceLinePriority priority = EVoiceLinePriority.Normal, EVoiceLinePlayMode mode = EVoiceLinePlayMode.Replace)

Seek(float)

Verschiebt die aktuelle Voice Line um eine bestimmte Zeit in Sekunden. Ereignisse zwischen den beiden Zeitpunkten werden nicht ausgelöst. Hat keine Auswirkung auf eine Voice Line, die mit PlayExternal(VoiceLineData, IVoiceLineAudioClock, EVoiceLinePriority, EVoiceLinePlayMode) abgespielt wird: Springen Sie stattdessen in Ihrer Audiodatei, die Voice Line folgt dem Sprung.

Skip()

Beendet die aktuelle Voice Line sofort, als wäre sie bis zum Ende abgespielt worden: Die verbleibenden Events werden ausgelöst, das Event VoiceLineCompleted wird ausgelöst und die nächste Zeile in der Warteschlange wird gestartet. Für eine Schaltfläche „Dialog überspringen“.

public void Skip()

Stop()

Beendet die aktuelle Voice Line und leert die Warteschlange. Die verbleibenden Ereignisse (einschließlich „Voice End“) werden nicht ausgelöst, und anstelle von VoiceLineCompleted wird VoiceLineInterrupted ausgelöst.
