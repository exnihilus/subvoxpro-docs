Namespace SubVoxPro.Timeline

Classes

VoiceLineAudioPlayableAsset

Ein Audio-Clip, der mit einem VoiceLineClip auf einer nativen Audiospur verknüpft ist. Er zeigt das Quell-Audio im Editor an und ermöglicht eine Vorschau; außerdem wird das Dubbing von CurrentLanguage abgespielt, sofern eine vorhanden ist. Die Sprache wird beim Erstellen des Timeline-Diagramms (wenn der Regisseur die Wiedergabe startet) ausgelesen, sodass ein Dubbing niemals mitten in einer Zwischensequenz wechselt.

VoiceLineClip

Timeline-Clip, der auf einem VoiceLineData-Asset basiert. Durch das Ablegen eines „VoiceLineData“-Objekts auf einem VoiceLineTrack wird automatisch ein solcher Clip erstellt, dessen Length standardmäßig der des längsten Audioabschnitts der Sprachzeile (Source oder Dubbing) entspricht. Wird stattdessen ein VoiceLineSequenceData-Objekt abgelegt, wird dies durch das Feld VoiceLineSequenceData erfasst und vom Clip-Editor in einen Clip pro Schritt aufgeteilt (wobei das Feld anschließend wieder auf „null“ zurückgesetzt wird).

VoiceLineEventMarker

Ein Voice Line-Ereignis, das als Timeline-Marker eingebettet ist und über ein VoiceLineTimelineEventReceiver ausgelöst wird.

VoiceLineEventTrack

Timeline mit den Markern, die aus den Voice Line-Ereignissen generiert wurden.

VoiceLineTimelineEventReceiver

Löst in SubVox „Baked“-Voice Line-Ereignisse aus, sobald deren Marker erreicht wird. Wird durch die „Bake“-Aktion zum „PlayableDirector“ hinzugefügt.

VoiceLineTrack

Timeline-Spur, die die Subtitles zu den Sprachzeilen steuert und mit der Regietaktung synchronisiert ist. Die Audiowiedergabe erfolgt über eine zugehörige native Audio Track (die beim Drop automatisch erstellt wird), sodass diese Spur lediglich Subtitles auf dem SubVox veröffentlicht, die von jedem Display übernommen werden können. Ein aktiver Clip hat Anzeigepriorität; wenn er endet, kehrt der aktuell ausgewählte Emitter-Subtitel zurück, ohne dass die Audiowiedergabe neu gestartet wird.
