Der visuelle Stil wird auf ein einzelnes Wort einer Untertitelzeile angewendet, das anhand seines Wortindexes (der durch Leerzeichen getrennten Position in der Zeile) identifiziert wird. Er wird zusammen mit dem Asset serialisiert und zur Laufzeit als TextMeshPro-Rich-Text gerendert.
