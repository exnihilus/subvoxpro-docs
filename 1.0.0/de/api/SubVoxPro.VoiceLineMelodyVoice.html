Spielt bei jedem gesprochenen Wort seines Emitters einen kurzen Blip im „Animal Crossing“-Stil, in jeder Sprache und ohne etwas zu generieren: Jeder Blip folgt der Intonation des Wortes im abgespielten Audio (Quelle oder Synchronisation) und erhält eine leichte zufällige Tonhöhe, wenn die Zeile kein Audio oder keine klare Stimme hat. Fügen Sie ihn neben einem VoiceLineEmitter hinzu und wählen Sie eine Stimmlage pro Figur.

public class VoiceLineMelodyVoice : MonoBehaviour

object
VoiceLineMelodyVoice

Examples

VoiceLineMelodyVoice voice = _villager.GetComponent<VoiceLineMelodyVoice>();
voice.Mode = EVoiceLineMelodyMode.Replace;
voice.BasePitch = 5f;
_villager.GetComponent<VoiceLineEmitter>().Play(greeting);
