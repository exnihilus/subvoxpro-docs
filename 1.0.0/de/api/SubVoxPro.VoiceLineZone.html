Spielt eine Voice Line (oder die nächste Zeile einer Bank) ab, wenn ein Kollidierer diesen Trigger-Bereich betritt. Funktioniert mit einem 2D- oder einem 3D-Kollidierer: Es wird immer nur der Callback ausgelöst, der zu dem auf diesem Objekt vorhandenen Kollidierer passt, sodass eine einzige Komponente beide Fälle abdeckt. Filtern Sie nach Ebene und (optional) Tag, spielen Sie die Sprachzeile einmalig oder mit einem Cooldown ab, legen Sie fest, was geschieht, wenn der Emitter ausgelastet ist, und stoppen Sie optional die Sprachzeile oder aktivieren Sie die Zone erneut, wenn der Spieler den Bereich verlässt. Play() ist öffentlich, sodass jedes andere System (Interaktion, UI-Schaltfläche) es über ein UnityEvent wiederverwenden kann.
