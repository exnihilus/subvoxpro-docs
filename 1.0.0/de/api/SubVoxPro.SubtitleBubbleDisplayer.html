Eine Sprechblase für eine Figur: Zeigt nur die Zeilen ihres VoiceLineEmitter an, beispielsweise über dem Kopf eines NPCs, während die Anzeige am unteren Bildschirmrand den Dialog beibehält. Gleiche Settings wie bei SubtitleDisplayer. Deaktivieren Sie die Option „Show Subtitles“ des Emitters, um dessen Zeilen ausschließlich in der Sprechblase anzuzeigen.
