ScanScenesAutomatically

Wenn der Wert „true“ ist (Standard), durchsucht der Dispatcher die geladenen Szenen bei seiner Aktivierung und anschließend jede Szene beim Laden. Wenn der Wert „false“ ist, werden nur Komponenten aufgerufen, die an Register(MonoBehaviour) übergeben oder von Refresh() gefunden wurden.
