Joue un court blip sur chaque mot prononcé par son émetteur, à la « Animal Crossing », dans toutes les langues et sans rien générer : chaque blip suit l’intonation du mot dans l’audio joué (source ou doublage), avec une légère hauteur aléatoire quand la ligne n’a pas d’audio ou pas de voix nette. Placez-le à côté d’un VoiceLineEmitter et choisissez un registre par personnage.

public class VoiceLineMelodyVoice : MonoBehaviour

object
VoiceLineMelodyVoice

Examples

VoiceLineMelodyVoice voice = _villager.GetComponent<VoiceLineMelodyVoice>();
voice.Mode = EVoiceLineMelodyMode.Replace;
voice.BasePitch = 5f;
_villager.GetComponent<VoiceLineEmitter>().Play(greeting);
