Composant de scène derrière SubVox. Il porte l’émetteur 2D de Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode), gère la pause et l’arrêt globaux, baisse la musique pendant les dialogues et choisit le sous-titre affiché : priorité la plus élevée, puis lecture la plus récente.

Choisit, parmi les émetteurs qui jouent une réplique, celui dont le sous-titre sera affiché ; renvoie null s’il n’y en a aucun. Par défaut : priorité la plus élevée, puis réplique démarrée le plus récemment, en ignorant les émetteurs dont Show Subtitles est désactivé.
