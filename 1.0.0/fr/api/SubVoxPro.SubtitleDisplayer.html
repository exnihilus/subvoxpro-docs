Affiche les sous-titres publiés sur SubVox dans un texte TextMeshPro, UI ou 3D, avec le nom et la police du speaker. Suit les options globales : activation, taille, opacité du fond et fondu. Fonctionne avec les émetteurs comme avec Timeline.
