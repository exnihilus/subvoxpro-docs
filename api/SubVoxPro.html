Namespace SubVoxPro

Classes

LanguageCodeAttribute

Marks a string field as a language code. The inspector then shows a dropdown of the languages that actually exist in the project's VoiceLineData assets (plus the source language), instead of a free-text field where a code has to be typed by hand.

LocalizedAudioTrack

A dub of a voice line in one language, with its own timings.

LocalizedSubtitleTrack

The translation of a voice line's subtitles into one language.

LocalizedVoiceLineEventBinding

An event position specific to one dub.

SpeakerData

A named, styled speaker that subtitles can be attributed to. Each speaker is its own asset so it can be reused across voice lines; the gender is only used to group speakers in the editor picker.

SpeakerSelectorAttribute

Marks a SpeakerData field so the inspector shows the same speaker picker popup used by the voice line window (speakers grouped by gender, with a "none" entry and a "new speaker" shortcut) instead of the default object reference field.

SubVox

The code entry point of SubVox Pro: plays voice lines, sets the language and the subtitle reveal mode, and raises the global events (subtitles, voice lines, voice line events). Every playback source honors it: the VoiceLineEmitter components and the Timeline integration.

SubtitleBubbleDisplayer

A speech bubble for one character: shows only the lines of its VoiceLineEmitter, for example above the head of an NPC, while the bottom-of-screen display keeps the dialogue. Same settings as SubtitleDisplayer. Turn the emitter's Show Subtitles off to show its lines in the bubble only.

SubtitleDisplayer

Shows the subtitles published on SubVox in a TextMeshPro text (UI or 3D), with the speaker's name and font, and follows the display settings of SubVox (on/off, size, background opacity, fade). Works the same whether playback comes from the emitters or from Timeline.

SubtitleDocumentDisplayer

Shows the subtitles published on SubVox in a UI Toolkit UnityEngine.UIElements.Label of its UnityEngine.UIElements.UIDocument, with the speaker's name and UI Toolkit font. The UI Toolkit counterpart of SubtitleDisplayer: same speaker name modes, same rich text styling, same display settings.

VoiceLineBankData

A set of interchangeable voice lines, such as the barks of a guard: each play picks one following Order. The asset only holds the lines; which one comes next is tracked by SubVox Pro at runtime.

VoiceLineData

A voice line: its source audio and subtitles, translations, dubs, speakers and events. Created and edited in the SubVox Pro window; read-only from code.

VoiceLineDataEvent

UnityEvent carrying a voice line, exposed so it renders in the inspector.

VoiceLineEmitter

Plays voice lines through its own AudioSource, one at a time, with their events and synced subtitles. Put one on each character that speaks and set its AudioSource to 3D to hear the voice from there: several emitters play at the same time, and the VoiceLineManager shows the subtitle of the most important line playing.

VoiceLineEventAttribute

Calls the marked method whenever a voice line event whose signal has this key fires. The method belongs to a component cached by a VoiceLineEventDispatcher or sharing its GameObject with a VoiceLineEventListener, returns void and takes nothing, a VoiceLineEventContext, or the type of the event's payload. Keys ignore case, spaces and punctuation: "Camera Shake" matches "camera-shake".

VoiceLineEventBinding

Where an event sits on a voice line: an anchor plus an offset.

VoiceLineEventContext

Everything about an event that fires: the voice line, the signal, the payload, when and where.

VoiceLineEventCue

An event placed on a voice line: a signal, where it fires, and an optional payload.

VoiceLineEventDispatcher

Calls the VoiceLineEventAttribute methods of the loaded scenes when their signal fires. Add one to the startup scene (it is in the [SubVox Pro] prefab).

VoiceLineEventListener

Calls the VoiceLineEventAttribute methods of every component on this GameObject when a voice line event with the matching signal key fires. Disabled components are skipped.

VoiceLineEventReaction

One reaction of a VoiceLineEventReceiver: a signal, an optional voice line, and what to call.

VoiceLineEventReceiver

Calls UnityEvents set in the Inspector when voice line events fire: one reaction per signal, optionally limited to one voice line.

VoiceLineEventSignalData

A reusable kind of event (e.g. "Camera Shake") placed on voice lines; code reacts to it through Subscribe(VoiceLineEventSignalData, Action<VoiceLineEventContext>), a receiver or VoiceLineEventAttribute methods.

VoiceLineEventUnityEvent

UnityEvent carrying a VoiceLineEventContext, shown in the Inspector.

VoiceLineManager

The scene component behind SubVox: holds the 2D VoiceLineEmitter that Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) uses (narration, dialogue), pauses or stops every emitter at once, ducks the music while a voice plays, and publishes the subtitle of the most important line playing — highest priority first, then the most recently started.

VoiceLinePlayOnStart

Plays a voice line automatically when this object starts (or is re-enabled), after an optional delay. Typical for level-intro narration or an opening line. Play() stays public for manual reuse.

VoiceLinePlayback

One request to play a voice line, returned by Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode) and Play(VoiceLineData, EVoiceLinePriority, EVoiceLinePlayMode): follow its State, stop it, or wait for it in a coroutine with yield return.

VoiceLineSequenceData

A reusable, ordered list of voice lines to play one after another. This asset only holds the definition (which lines, and how each one advances to the next); a VoiceLineSequencePlayer in the scene drives it at runtime so the same sequence can be reused by several players safely.

VoiceLineSequencePlayer

Plays a VoiceLineSequenceData at runtime, one line at a time. Each step advances either automatically when its line finishes (after an optional delay) or manually via Advance() — which can be wired to any UnityEvent, an interaction or a UI button — and Previous() goes back one line. The steps play in the order of Direction. A step refused by a busy emitter waits for it to be free. Exposes UnityEvents so scene logic can react without code, and the same C# events for code.

VoiceLineSequenceStep

One step of a sequence: a line and how the sequence moves on after it.

VoiceLineZone

Plays a voice line (or the next line of a bank) when a collider enters this trigger. Works with a 2D or a 3D collider: only the callback matching the collider present on this object ever fires, so a single component covers both. Filter by layer and (optionally) tag, play once or on a cooldown, choose what happens when the emitter is busy, and optionally stop the line or re-arm the zone when the player leaves. Play() is public, so any other system (interaction, UI button) can reuse it through a UnityEvent.

VoicePersonalityData

A reusable voice style/personality preset (a name plus free-form delivery instructions). It is fed as a style prompt to text-to-speech providers that accept one (Google Gemini-TTS, InWorld), so the same character can be dubbed "calm", "furious", "whispering"… across many voice lines. Speakers list the personalities that fit them, and individual subtitle lines can pick one of those.

SubtitleWordStyle
